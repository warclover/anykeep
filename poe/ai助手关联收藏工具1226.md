## 一、功能概述

在 AI 助手底部工具栏最左侧增加一个附件按钮（+ 号），点击后弹出面板，允许用户：

1. **关联收藏**：默认显示最近 10 条，支持全库搜索
2. **上传文件**：让 AI 分析用户提供的外部文档
3. **附件上限**：最多 3 个附件（收藏 + 文件合计）

```typescript

const { attachments, clearAll } = useAttachmentManager();
```

### 2. 搜索模式切换

```typescript
// use-attachment-bookmarks.ts
const { data, isLoading } = useSWR(
```

```typescript
export function AttachmentPopover(props) {
```

```typescript
// 在选择/上传时检查
const canAddMore = attachments.length < ATTACHMENT_LIMITS.MAX_COUNT;
const remainingSlots = ATTACHMENT_LIMITS.MAX_COUNT - attachments.length;

// UI 提示
{!canAddMore && (
  <p className="text-sm text-orange-500">已达附件上限（3/3）</p>
)}
```
