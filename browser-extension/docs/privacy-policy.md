# AnyKeep 浏览器扩展隐私政策

**最后更新日期**: 2025年12月16日

## 概述

AnyKeep 浏览器扩展（以下简称"本扩展"）是由 AnyKeep 团队开发的内容收藏工具。本隐私政策说明了我们如何收集、使用和保护您的个人信息。

## 收集的信息

### 1. 页面元数据

当您使用本扩展收藏网页时，我们会收集以下信息：

- **页面 URL**: 您收藏的网页地址
- **页面标题**: 网页的标题
- **页面描述**: 网页的 meta 描述信息（如有）
- **封面图片 URL**: 网页的 Open Graph 图片地址（如有）
- **作者信息**: 网页声明的作者信息（如有）
- **发布时间**: 网页声明的发布时间（如有）
- **内容统计**: 估算的字数和图片数量

### 2. 认证信息

为了将收藏同步到您的 AnyKeep 账户，我们会在本地存储：

- **认证令牌 (Token)**: 用于验证您的身份
- **用户 ID**: 您的 AnyKeep 账户标识符
- **令牌过期时间**: 令牌的有效期

### 3. 离线数据

当您在离线状态下使用本扩展时，收藏的内容会临时存储在浏览器的 IndexedDB 中，待网络恢复后自动同步。

## 信息使用方式

我们收集的信息仅用于以下目的：

1. **保存收藏**: 将您收藏的内容保存到 AnyKeep 服务器
2. **身份验证**: 确保只有您可以访问您的收藏
3. **离线支持**: 在无网络时暂存收藏，联网后同步
4. **内容展示**: 在扩展弹窗中预览收藏内容

## 数据存储

### 本地存储

- **chrome.storage.local**: 存储认证信息和用户偏好
- **IndexedDB**: 存储离线收藏队列

### 云端存储

您的收藏数据存储在 Supabase 云服务（位于 AWS）中，受到以下保护：

- 传输加密 (HTTPS/TLS)
- 数据库行级安全策略 (RLS)
- 用户数据隔离

## 数据共享

我们**不会**将您的个人信息出售、交易或以其他方式转让给第三方。

以下情况除外：

- 您明确同意分享
- 法律要求披露

## 权限说明

本扩展请求以下浏览器权限：

| 权限            | 用途                      |
| --------------- | ------------------------- |
| `activeTab`     | 获取当前页面的 URL 和标题 |
| `storage`       | 存储认证信息和用户偏好    |
| `contextMenus`  | 提供右键菜单快捷收藏功能  |
| `notifications` | 显示保存成功/失败通知     |
| `<all_urls>`    | 从任意网页提取元数据      |

## 您的权利

您拥有以下权利：

### 1. 访问权

您可以随时在 AnyKeep 网站上查看您收藏的所有内容。

### 2. 删除权

您可以：

- 删除单个收藏
- 清空所有收藏
- 删除 AnyKeep 账户（将永久删除所有数据）

### 3. 导出权

您可以将收藏导出为标准格式（HTML/JSON）。

### 4. 撤销权

您可以随时：

- 登出扩展（清除本地认证信息）
- 卸载扩展（删除所有本地数据）

## 数据安全

我们采取以下措施保护您的数据：

- 所有通信使用 HTTPS 加密
- 认证令牌有过期机制
- 数据库使用行级安全策略
- 不存储您的密码

## Cookie 政策

本扩展**不使用** Cookie。

## 儿童隐私

本扩展不面向 13 岁以下的儿童。我们不会故意收集儿童的个人信息。

## 政策变更

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新"最后更新日期"。
