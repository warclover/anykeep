### 扩展名称

### 简短描述 (132 字符限制)

一键保存网页到 AnyKeep，AI 自动生成摘要和标签。支持微信公众号、B站、小红书等30+平台，离线可用。

### 详细描述

**AnyKeep - 智能内容收藏助手**

告别杂乱的浏览器书签，用 AnyKeep 统一管理您收藏的优质内容！

🎯 **核心功能**

• **一键收藏** - 点击扩展图标或使用快捷键 (Ctrl+Shift+S) 快速保存当前页面
• **右键菜单** - 右键点击页面或链接，选择"保存到 AnyKeep"
• **智能提取** - 自动获取标题、描述、封面图、作者等元数据
• **离线支持** - 无网络时也能收藏，联网后自动同步
• **跨设备同步** - 在任何设备上访问您的收藏

🌐 **支持 30+ 平台**

微信公众号 | B站 | 小红书 | 知乎 | 抖音 | 微博
掘金 | 简书 | CSDN | GitHub | YouTube | Twitter/X
Medium | Notion | 以及任何网页...

🤖 **AI 智能处理**

• 自动生成内容摘要
• 智能打标签分类
• 语义搜索快速定位

🔒 **安全可靠**

• 数据端到端加密传输
• 不收集任何个人隐私
• 开源透明

📱 **多端支持**

• Chrome / Edge 浏览器扩展
• Web 应用 (anykeep.app)
• 移动端 App (即将推出)

## 审核注意事项

### 权限说明

| 权限          | 用途说明                         |
| ------------- | -------------------------------- |
| activeTab     | 获取当前页面 URL 和标题用于收藏  |
| storage       | 存储用户认证信息和偏好设置       |
| contextMenus  | 提供右键菜单快捷收藏功能         |
| bookmarks     | 支持导入浏览器书签功能           |
| notifications | 显示保存成功/失败的桌面通知      |
| <all_urls>    | 从任意网页提取 Open Graph 元数据 |
