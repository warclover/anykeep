# AnyKeep 浏览器扩展 - 集成测试清单

## 认证流程

### 登录同步

- [ ] 从 Web 应用登录后，扩展自动识别登录状态
- [ ] 从扩展点击"前往登录"，跳转到 Web 应用登录页
- [ ] 登录成功后，扩展 popup 显示收藏界面
- [ ] 登出 Web 应用后，扩展自动变为未登录状态

### Token 管理

- [ ] Token 过期后，显示"登录已过期"提示
- [ ] 过期状态下，显示"重新登录"按钮
- [ ] 点击重新登录，跳转到 Web 应用

---

## 收藏流程

### 基本收藏

- [ ] 点击扩展图标，显示当前页面信息
- [ ] 显示页面标题、URL、平台标签
- [ ] 点击收藏按钮，显示加载状态
- [ ] 收藏成功，显示成功动画和纸屑效果
- [ ] 3秒后自动恢复初始状态

### 右键菜单

- [ ] 右键点击页面，显示"保存此页面到 AnyKeep"
- [ ] 右键点击链接，显示"保存此链接到 AnyKeep"
- [ ] 点击菜单项，显示系统通知

### 快捷键

- [ ] 按 Ctrl+Shift+S (Mac: Cmd+Shift+S)
- [ ] 显示系统通知，确认保存结果
- [ ] 浏览器内部页面 (chrome://、about:) 显示不支持提示
