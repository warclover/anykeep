# Chrome Web Store 上架信息

## 基本信息

### 扩展名称

AnyKeep - 智能收藏助手

### 简短描述 (132字符以内)

一键保存网页到 AnyKeep，AI 自动生成摘要和标签，支持微信公众号、B站、小红书等平台

### 详细描述

AnyKeep 是一款智能内容收藏工具，帮助您统一管理来自各个平台的收藏内容。

**核心功能：**

- 一键收藏：使用快捷键 Ctrl+Shift+S 或右键菜单快速保存当前页面
- AI 智能处理：自动识别内容平台，生成摘要和标签
- 批量导入：支持将浏览器书签批量导入到 AnyKeep
- 多平台支持：微信公众号、B站、小红书、知乎、GitHub 等

**支持的平台：**

- 微信公众号 (mp.weixin.qq.com)
- 哔哩哔哩 (bilibili.com)
- 小红书 (xiaohongshu.com)
- 知乎 (zhihu.com)
- GitHub (github.com)
- YouTube (youtube.com)
- 掘金 (juejin.cn)
- CSDN (csdn.net)
- 简书 (jianshu.com)
- 抖音 (douyin.com)
- 微博 (weibo.com)
- 以及更多...

**使用方法：**

1. 安装扩展后，点击扩展图标登录 AnyKeep 账号
2. 浏览任意网页时，按 Ctrl+Shift+S 或点击扩展图标保存
3. 也可以右键点击页面选择"保存到 AnyKeep"
4. 在 AnyKeep 网页端查看和管理所有收藏

**隐私保护：**

- 我们只收集您主动保存的网页信息
- 不跟踪您的浏览历史
- 数据安全存储，支持账号数据导出

官网：https://anykeep.vercel.app

## 权限说明

- activeTab: 读取当前页面标题和 URL 以保存书签
- storage: 存储登录状态和设置
- contextMenus: 提供右键菜单功能
- bookmarks: 读取浏览器书签以支持批量导入
- notifications: 显示保存成功/失败通知
