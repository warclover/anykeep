# Chrome Web Store 上架清单

## 扩展基本信息

### 名称
AnyKeep - 智能收藏助手

### 简短描述 (132 字符以内)
一键保存网页到 AnyKeep，AI 自动生成摘要和标签，支持微信公众号、B站、小红书等中文平台

### 详细描述
AnyKeep 是一款跨平台智能内容聚合工具，帮助你统一管理来自各个平台的收藏内容。

🚀 **核心功能**

• **一键收藏** - 右键菜单或快捷键 (Ctrl+Shift+S) 快速保存当前页面
• **智能识别** - 自动识别微信公众号、B站、小红书、知乎等中文平台
• **AI 处理** - 自动生成摘要和标签，告别手动整理
• **批量导入** - 支持从浏览器书签栏批量导入已有收藏
• **跨设备同步** - 登录账号后所有设备实时同步

📱 **支持的平台**

• 微信公众号 (mp.weixin.qq.com)
• 哔哩哔哩 (bilibili.com)
• 小红书 (xiaohongshu.com)
• 知乎 (zhihu.com)
• 抖音 (douyin.com)
• 微博 (weibo.com)
• 掘金 (juejin.cn)
• GitHub (github.com)
• YouTube (youtube.com)
• 以及更多...

⌨️ **快捷键**

• Ctrl+Shift+S (Windows) / Command+Shift+S (Mac) - 快速保存当前页面

🔒 **隐私与安全**

• 仅在你主动保存时访问页面内容
• 不收集任何浏览历史
• 数据存储在你的私有账户中
• 开源代码，透明可信

💡 **使用方法**

1. 安装扩展后点击图标
2. 登录或注册 AnyKeep 账号
3. 浏览任意网页，右键选择"保存到 AnyKeep"或使用快捷键
4. 访问 anykeep.app 查看和管理所有收藏

## 权限说明

### 使用的权限
| 权限 | 用途 | 为什么需要 |
|------|------|------------|
| activeTab | 获取当前页面信息 | 保存当前页面的标题和 URL |
| storage | 存储认证信息 | 保存登录状态和用户偏好 |
| contextMenus | 右键菜单 | 提供"保存到 AnyKeep"右键选项 |
| bookmarks | 读取浏览器书签 | 支持批量导入浏览器书签 |
| notifications | 系统通知 | 显示保存成功/失败的通知 |
| <all_urls> | 访问所有网站 | 支持从任意网站保存内容 |

## 隐私政策要点

1. **数据收集**：仅在用户主动保存时收集页面 URL 和标题
2. **数据存储**：用户数据存储在 Supabase 云服务
3. **数据共享**：不与第三方共享用户数据
4. **数据删除**：用户可随时删除账户和所有数据
5. **Cookie 使用**：仅用于身份验证
6. **分析工具**：不使用任何第三方分析工具

隐私政策完整文档：https://anykeep.app/privacy
