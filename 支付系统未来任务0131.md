## 一、已完成内容

### 1.1 数据库迁移（3 个文件，7 张表，6 个函数）

| 迁移文件                                        | 内容                                                            |
| ----------------------------------------------- | --------------------------------------------------------------- |
| `20260131000001_payment_subscription_plans.sql` | `subscription_plans` + `user_subscriptions` + `payment_records` |
| `20260131000002_payment_events_quota.sql`       | `payment_events` + `user_quota_usage` + `user_entitlements`     |
| `20260131000003_payment_orders_functions.sql`   | `payment_orders` + 6 个数据库函数                               |

**数据库表：**

| 表名                 | 用途                              |
| -------------------- | --------------------------------- |
| `subscription_plans` | 订阅计划配置（Free/Pro/Pro+/LTD） |
| `user_subscriptions` | 用户订阅记录                      |
| `payment_records`    | 支付流水记录                      |
| `payment_events`     | Webhook 事件（幂等性）            |
| `user_quota_usage`   | 配额使用量（按月）                |
| `user_entitlements`  | 用户权益快照（高性能查询）        |
| `payment_orders`     | 待支付订单（国内支付）            |

**数据库函数：**

| 函数名                          | 用途           |
| ------------------------------- | -------------- |
| `increment_quota_usage()`       | 配额增量更新   |
| `reset_daily_quota_if_needed()` | 每日配额重置   |
| `increment_daily_ai_calls()`    | AI 日调用计数  |
| `get_user_entitlement()`        | 获取用户权益   |
| `generate_order_no()`           | 生成订单号     |
| `create_default_entitlement()`  | 新用户默认权益 |

### 1.4 API 端点

```
src/app/api/payment/
├── checkout/route.ts                 # POST - 创建支付订单
├── subscription/route.ts             # GET/DELETE/PATCH - 订阅管理
```

| `/api/payment/subscription`         | DELETE | 取消订阅（期末生效）  |

| `/api/payment/webhook/lemonsqueezy` | POST   | LS Webhook 接收       |
| `/api/payment/webhook/yungouos`     | POST   | YunGouOS Webhook 接收 |

## 三、使用示例

### 3.1 页面级功能门控

```tsx
import { FeatureGate } from "@/components/payment";

export default function SynthesisPage() {
  return (
    <FeatureGate feature="synthesis">
      <SynthesisContent />
    </FeatureGate>
  );
}
```

### 3.2 API 级配额检查

```typescript
import { quotaService } from "@/lib/payment/services/quota.service";

export async function POST(req: Request) {
  const result = await quotaService.consumeAIQuota(userId, 1);
  if (!result.allowed) {
    return NextResponse.json({ error: result.reason }, { status: 429 });
  }
  // 执行业务逻辑...
}
```

### 3.3 客户端 Hook 使用

```tsx
import { useEntitlement, useQuota, useFeatureGate } from "@/lib/payment/hooks";

function MyComponent() {
  const { planTier, isPaid, isInTrial } = useEntitlement();
  const { aiRemaining, isAIExhausted } = useQuota();
  const { allowed } = useFeatureGate("tts");

  if (isAIExhausted) {
    return <UpgradePrompt feature="ai-calls-monthly" requiredPlan="pro" />;
  }

  // ...
}
```

### 3.4 开启试用

```typescript
// 客户端
const res = await fetch("/api/payment/trial", { method: "POST" });
const { data } = await res.json();
console.log("试用结束时间:", data.trialEndsAt);

// 服务端
import { trialService } from "@/lib/payment/services/trial.service";
await trialService.startTrial(userId);
```
