📦 核心组件详情

🎯 IntentRouter 路由

  • IntentClassifier - 意图分类 (search/manage/analyze/export/review)
  • ComplexityEvaluator - 复杂度评估 (simple/medium/complex)
  • ModeSelector - 模式选择决策

⚡ KnowledgeAgent 原子

  • 66 个 Tools (12 分类)
  • Claude API 调用
  • 工具结果整合
  • 即时响应

🎭 OrchestrationEngine 编排

  • 15 个编排 Skills
  • 多步骤流程执行
  • 进度追踪与报告
  • 交付物生成

📝 Formatters 输出

  • ListFormatter - 列表格式 (bullet/numbered/checkbox)
  • TableFormatter - 表格格式 (支持排序/分页)
  • ReportFormatter - 报告格式 (支持 TOC/引用)

✅ ConfirmationHandler 确认

  • 存储待确认操作
  • TTL 自动过期
  • 批量确认/取消
  • 操作回滚

💻 Frontend UI

  • useAIChat Hook - 聊天逻辑
  • AIMessage - 消息展示
  • AIDeliverableCard - 交付物卡片
  • AIProgressIndicator - 进度条
