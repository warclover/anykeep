设置页面重新设计方案
----------

根据探索结果，当前设置页面有 **18 个独立模块**，确实过于繁杂。我将其重新归类为 **6 大分组**，并采用**左侧导航 + 右侧内容**的经典布局。

* * *

📊 设置项重新归类
----------

| 分组           | 包含设置项                              | 优先级 |
| ------------ | ---------------------------------- | --- |
| **👤 账号与资料** | 账号信息、用户画像、兴趣领域                     | 高频  |
| **🎨 外观与显示** | 品牌色主题                              | 中频  |
| **🤖 AI 智能** | AI 功能开关、智能分类、摘要模式、托管模式、AI Provider | 核心  |
| **📦 内容管理**  | 网页快照配额、自动快照设置                      | 中频  |
| **🔗 平台连接**  | 微信/B站/小红书授权                        | 低频  |
| **🔔 通知设置**  | 邮件通知、应用内通知、消息分级                    | 中频  |
| **🔒 隐私安全**  | 数据加密、数据导出、账号删除                     | 低频  |
| **📋 历史与支持** | AI 操作历史、帮助反馈                       | 辅助  |

🎯 设计亮点
-------

### 1. **分层导航结构**

* **一级**: 6 大分组（账号、外观、AI、内容、平台、通知、隐私、历史）
* **二级**: 点击分组展开具体设置项
* **减少认知负担**: 从 18 个平铺模块 → 6+2 层级结构

### 2. **智能分组逻辑**

| 分组原则   | 说明                    |
| ------ | --------------------- |
| 高频优先   | 账号信息放最上面              |
| 功能聚合   | AI 相关 5 个设置合并为一组      |
| 场景驱动   | 通知设置合并（邮件 + 应用内 + 分级） |
| 危险操作下沉 | 删除账号放在隐私安全最底部         |

### 3. **响应式适配**

* **桌面端**: 左侧固定导航 + 右侧滚动内容
* **移动端**: 分组卡片列表 → 点击进入二级页

### 4. **快捷入口**

* 退出登录按钮固定在右上角（桌面）或底部（移动）
* AI 操作历史提供徽章显示未读数量
