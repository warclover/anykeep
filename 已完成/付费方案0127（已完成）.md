## 一、方案概述

### 1.1 设计目标

- **国内外兼容**：国内用户使用微信/支付宝，国际用户使用信用卡/PayPal
- **独立开发者友好**：无需企业资质即可启动，后续平滑升级
- **风险可控**：幂等性处理、资金安全、合规备案路径
- **用户体验优先**：支付流程顺滑，异常情况优雅降级

### 1.2 支付渠道选型

| 渠道 | 适用用户 | 费率 | 税务处理 | 资质要求 | 支付模式 |
|------|----------|------|----------|----------|----------|
| **Lemon Squeezy** | 国际用户 | 5% + $0.50 | MoR 全托管 | 无 | 订阅制（自动续费） |
| **YunGouOS** | 国内用户 | ~1% | 自��处理 | 个人可接入 | **时长卡（手动续费）** |

> **国内支付策略说明**：
> - 国内用户购买的是"1年会员时长"，而非自动续费订阅
> - 到期前通过微信模版消息/邮件提醒用户手动续费
> - 理由：个人签约模式下自动扣款技术复杂，且国内用户普遍反感自动扣款

### 1.3 定价策略

| 套餐 | 国内价格 | 国际价格 | AI 配额 | 存储配额 |
|------|----------|----------|---------|----------|
| **Free** | ¥0 | $0 | 20 次/月 | 100 MB |
| **Pro** | ¥99/年 | $14.99/年 | 500 次/月 | 5 GB |
| **Pro+** | ¥199/年 | $29.99/年 | 3000 次/月 | 20 GB |
| **LTD** | ¥499 (限量100) | $69.99 (限量100) | 500 次/月 | 20 GB |

> **定价说明**：
> - Pro+ 配额 3000 次/月 ≈ 每天 100 次，对正常用户等同于无限，但防住脚本滥用
> - 所有套餐设置 **200 次/日熔断阈值**，防止单日异常消耗
> - LTD (Lifetime Deal) 为终身买断，限量发售用于验证 PMF 和快速回笼资金
> - **LTD 风控策略**：LTD 享有 **Pro 级配额 (500次/月)**，而非 Pro+ 级，防止长期 AI 成本失控
> - LTD 话术：**"终身享受 Pro 会员的所有权益"**
> - 可选增值：AI 加油包 ¥19/1000次（用完可充值）

#### 1.5.2 权限检查 Hook

```typescript
// src/lib/payment/hooks/use-feature-gate.ts

import { useUserEntitlement } from './use-entitlement';
import { FEATURE_GATES, FeatureKey, PlanTier } from '../feature-gates';

interface FeatureGateResult {
  allowed: boolean;           // 是否允许使用
  limit: number | undefined;  // 数值限制（如果是配额型）
  planTier: PlanTier;         // 当前套餐
  requiredPlan: PlanTier;     // 需要的最低套餐（用于升级提示）
}

export function useFeatureGate(feature: FeatureKey): FeatureGateResult {
  const { entitlement, isLoading } = useUserEntitlement();
  const planTier = (entitlement?.plan_tier || 'free') as PlanTier;

  const config = FEATURE_GATES[feature];
  const value = config[planTier];

  // 判断是布尔型还是数值型
  const isBooleanGate = typeof value === 'boolean';

  // 计算需要的最低套餐
  const requiredPlan = isBooleanGate
    ? (Object.entries(config).find(([_, v]) => v === true)?.[0] as PlanTier) || 'pro'
    : 'pro';

  return {
    allowed: isBooleanGate ? value : true,
    limit: isBooleanGate ? undefined : (value as number),
    planTier,
    requiredPlan,
  };
}

// 便捷 Hook：检查是否为付费用户
export function useIsPaidUser(): boolean {
  const { entitlement } = useUserEntitlement();
  const tier = entitlement?.plan_tier;
  return tier === 'pro' || tier === 'pro_plus' || tier === 'lifetime';
}
```

#### 1.5.3 功能门控组件

```typescript
// src/components/payment/feature-gate.tsx

'use client';

import { ReactNode } from 'react';
import { useFeatureGate } from '@/lib/payment/hooks/use-feature-gate';
import { FeatureKey } from '@/lib/payment/feature-gates';
import { UpgradePrompt } from './upgrade-prompt';

interface FeatureGateProps {
  feature: FeatureKey;
  children: ReactNode;
  fallback?: ReactNode;  // 自定义降级 UI
  silent?: boolean;      // 静默模式：不显示升级提示，直接隐藏
}

export function FeatureGate({
  feature,
  children,
  fallback,
  silent = false,
}: FeatureGateProps) {
  const { allowed, requiredPlan } = useFeatureGate(feature);

  if (allowed) {
    return <>{children}</>;
  }

  if (silent) {
    return null;
  }

  if (fallback) {
    return <>{fallback}</>;
  }

  return <UpgradePrompt feature={feature} requiredPlan={requiredPlan} />;
}
```

#### 退款处理流程

**场景 A：国际版 (Lemon Squeezy) - 自动化**

```
用户发邮件要求退款
        ↓
管理员登录 LS 后台，点击 Refund
        ↓
LS 自动触发 subscription_payment_refunded Webhook
        ↓
AnyKeep 后端收到 Webhook，自动撤销权益
        ↓
(可选) 发送退款确认邮件
```

**场景 B：国内版 (YunGouOS/微信) - 半自动**

```
用户联系客服要求退款
        ↓
管理员在 YunGouOS/微信商户后台手动发起退款
        ↓
管理员执行 Admin SQL 或调用 Admin API 撤销权益
        ↓
(可选) 发送退款确认消息
```

#### Webhook 退款事件处理

```typescript
// src/app/api/webhooks/lemonsqueezy/route.ts

export async function POST(request: Request) {
  // ... 验签逻辑 ...

  const eventName = payload.meta.event_name;
  const customData = payload.meta.custom_data;
  const userId = customData?.user_id;

  // 处理退款事件
  if (eventName === 'subscription_payment_refunded') {
    console.log(`[Refund] Processing refund for user ${userId}`);

    // 1. 撤销权益 + 记录退款
    await supabase
      .from('user_entitlements')
      .update({
        plan_tier: 'free',
        valid_until: new Date().toISOString(),
        refund_count: supabase.rpc('increment', { x: 1 }),
        last_refunded_at: new Date().toISOString(),
        refund_reason: 'user_requested'
      })
      .eq('user_id', userId);

    // 2. 标记订单为已退款
    await supabase
      .from('payment_records')
      .update({ status: 'refunded' })
      .eq('provider_payment_id', payload.data.id);

    // 3. (可选) 发送邮件通知
    // await sendRefundConfirmationEmail(userId);

    return NextResponse.json({ received: true });
  }
}
```

#### 手动退款 SQL (国内用户)

```sql
-- 撤销指定用户的权益
-- 使用前替换 'TARGET_USER_ID' 为实际用户 ID

BEGIN;

-- 1. 降级为免费用户 + 记录退款
UPDATE user_entitlements
SET
  plan_tier = 'free',
  valid_until = NOW(),
  refund_count = COALESCE(refund_count, 0) + 1,
  last_refunded_at = NOW(),
  refund_reason = 'user_requested',
  updated_at = NOW()
WHERE user_id = 'TARGET_USER_ID';

-- 2. 更新订单状态
UPDATE payment_orders
SET
  status = 'refunded',
  metadata = metadata || '{"refunded_at": "' || NOW() || '"}'::jsonb
WHERE user_id = 'TARGET_USER_ID'
  AND status = 'paid'
ORDER BY created_at DESC
LIMIT 1;

COMMIT;

-- 验证结果
SELECT user_id, plan_tier, refund_count, last_refunded_at
FROM user_entitlements
WHERE user_id = 'TARGET_USER_ID';
```

#### 退款黑名单机制

```sql
-- 查询多次退款用户（疑似薅羊毛）
SELECT
  user_id,
  refund_count,
  last_refunded_at,
  CASE
    WHEN refund_count >= 3 THEN '🔴 黑名单'
    WHEN refund_count >= 2 THEN '🟡 观察名单'
    ELSE '🟢 正常'
  END as risk_level
FROM user_entitlements
WHERE refund_count > 0
```

### 4.2 Webhook 服务 (含幂等性)

```typescript
// src/lib/payment/services/webhook.service.ts

import { createClient } from '@/lib/supabase/server';
import { WebhookEvent, PaymentProvider } from '../types';
import { subscriptionService } from './subscription.service';
import { logger } from '@/lib/logger';

export class WebhookService {

  /**
   * 处理 Webhook 事件（带幂等性保障）
   */
  async handleWebhook(event: WebhookEvent): Promise<void> {
    const supabase = await createClient();

    // 1. 幂等性检查：如果事件已处理，直接返回
    const isProcessed = await this.isEventProcessed(event.provider, event.id);
    if (isProcessed) {
      logger.info('Webhook event already processed, skipping', {
        provider: event.provider,
        eventId: event.id,
      });
      return;
    }

    // 2. 记录原始事件（审计日志）
    await this.logEvent(event);

    // 3. 处理业务逻辑
    try {
      await this.processEvent(event);

      // 4. 标记为已处理
      await this.markEventAsProcessed(event.provider, event.id);

      logger.info('Webhook event processed successfully', {
        provider: event.provider,
        eventId: event.id,
        type: event.type,
      });
    } catch (error) {
      // 记录错误但不标记为已处理，允许重试
      await this.recordEventError(event.provider, event.id, error);

      logger.error('Webhook processing failed', {
        provider: event.provider,
        eventId: event.id,
        error,
      });

      // 重新抛出，让支付平台重试
      throw error;
    }
  }

  /**
   * 检查事件是否已处理
   */
  private async isEventProcessed(
    provider: PaymentProvider,
    eventId: string
  ): Promise<boolean> {
    const supabase = await createClient();

    const { data } = await supabase
      .from('payment_events')
      .select('processed')
      .eq('provider', provider)
      .eq('event_id', eventId)
      .single();

    return data?.processed === true;
  }

  /**
   * 记录事件
   */
  private async logEvent(event: WebhookEvent): Promise<void> {
    const supabase = await createClient();

    await supabase.from('payment_events').upsert({
      provider: event.provider,
      event_id: event.id,
      event_type: event.type,
      payload: event.data,
      processed: false,
    }, {
      onConflict: 'provider,event_id',
    });
  }

  /**
   * 处理具体事件
   */
  private async processEvent(event: WebhookEvent): Promise<void> {
    switch (event.type) {
      case 'subscription.created':
      case 'payment.succeeded':
        await this.handlePaymentSucceeded(event);
        break;

      case 'subscription.updated':
        await this.handleSubscriptionUpdated(event);
        break;

      case 'subscription.canceled':
        await this.handleSubscriptionCanceled(event);
        break;

      case 'subscription.expired':
        await this.handleSubscriptionExpired(event);
        break;

      case 'payment.refunded':
        await this.handlePaymentRefunded(event);
        break;

      case 'payment.failed':
        await this.handlePaymentFailed(event);
        break;

      default:
        logger.warn('Unknown webhook event type', { type: event.type });
    }
  }

  /**
   * 处理支付成功
   */
  private async handlePaymentSucceeded(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);
    const planId = this.extractPlanId(event);

    if (!userId || !planId) {
      throw new Error('Missing userId or planId in webhook data');
    }

    await subscriptionService.activateSubscription({
      userId,
      planId,
      provider: event.provider,
      providerSubscriptionId: event.data.subscription_id as string,
      providerCustomerId: event.data.customer_id as string,
    });
  }

  /**
   * 处理退款 - 立即撤销访问权限
   */
  private async handlePaymentRefunded(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);

    if (!userId) {
      throw new Error('Missing userId in refund webhook');
    }

    await subscriptionService.revokeSubscription(userId, 'refunded');

    // 可选：发送通知邮件
    // await notificationService.sendRefundNotification(userId);
  }

  /**
   * 处理订阅取消
   */
  private async handleSubscriptionCanceled(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);

    if (!userId) return;

    const reason = event.data.cancellation_reason as string || 'user_requested';

    await subscriptionService.markCanceled(userId, reason);
  }

  /**
   * 处理订阅过期
   */
  private async handleSubscriptionExpired(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);

    if (!userId) return;

    // 设置 7 天宽限期
    await subscriptionService.setGracePeriod(userId, 7);
  }

  /**
   * 处理支付失败
   */
  private async handlePaymentFailed(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);

    if (!userId) return;

    await subscriptionService.markPastDue(userId);

    // 可选：发送提醒邮件
    // await notificationService.sendPaymentFailedNotification(userId);
  }

  /**
   * 处理订阅更新（升级/降级）
   */
  private async handleSubscriptionUpdated(event: WebhookEvent): Promise<void> {
    const userId = this.extractUserId(event);
    const planId = this.extractPlanId(event);

    if (!userId || !planId) return;

    await subscriptionService.updatePlan(userId, planId);
  }

  /**
   * 标记事件为已处理
   */
  private async markEventAsProcessed(
    provider: PaymentProvider,
    eventId: string
  ): Promise<void> {
    const supabase = await createClient();

    await supabase
      .from('payment_events')
      .update({
        processed: true,
        processed_at: new Date().toISOString(),
      })
      .eq('provider', provider)
      .eq('event_id', eventId);
  }

  /**
   * 记录事件处理错误
   */
  private async recordEventError(
    provider: PaymentProvider,
    eventId: string,
    error: unknown
  ): Promise<void> {
    const supabase = await createClient();

    await supabase
      .from('payment_events')
      .update({
        error_message: error instanceof Error ? error.message : String(error),
        retry_count: supabase.rpc('increment_retry_count'),
      })
      .eq('provider', provider)
      .eq('event_id', eventId);
  }

  /**
   * 从事件数据中提取用户 ID
   */
  private extractUserId(event: WebhookEvent): string | null {
    // Lemon Squeezy: custom_data.user_id
    // YunGouOS: attach.user_id (JSON parsed)

    if (event.provider === 'lemonsqueezy') {
      return event.data.meta?.custom_data?.user_id as string || null;
    }

    if (event.provider === 'yungouos') {
      try {
        const attach = JSON.parse(event.data.attach as string);
        return attach.user_id || null;
      } catch {
        return null;
      }
    }

    return null;
  }

  /**
   * 从事件数据中提取计划 ID
   */
  private extractPlanId(event: WebhookEvent): string | null {
    if (event.provider === 'lemonsqueezy') {
      const variantId = event.data.variant_id as string;
      return this.mapVariantToPlan(variantId);
    }

    if (event.provider === 'yungouos') {
      try {
        const attach = JSON.parse(event.data.attach as string);
        return attach.plan_id || null;
      } catch {
        return null;
      }
    }

    return null;
  }

  private mapVariantToPlan(variantId: string): string | null {
    const mapping: Record<string, string> = {
      [process.env.LEMONSQUEEZY_VARIANT_PRO!]: 'pro',
      [process.env.LEMONSQUEEZY_VARIANT_PRO_PLUS!]: 'pro_plus',
    };
    return mapping[variantId] || null;
  }
}
```

### 4.3 配额服务 (优化版)

```typescript
// src/lib/payment/services/quota.service.ts

import { createClient } from '@/lib/supabase/server';
import { QuotaUsage } from '../types';

// 免费用户配额
const FREE_QUOTA = {
  aiCalls: 20,        // 每月 20 次
  aiCallsDaily: 50,   // 单日熔断阈值
  storageMb: 100,
  bookmarks: 100,
};

export class QuotaService {

  /**
   * 获取用户配额使用情况
   */
  async getQuotaUsage(userId: string): Promise<QuotaUsage> {
    const supabase = await createClient();
    const currentMonth = this.getCurrentMonth();

    // 并行获取订阅和使用量
    const [subscriptionResult, usageResult] = await Promise.all([
      this.getActiveSubscription(userId),
      supabase
        .from('user_quota_usage')
        .select('*')
        .eq('user_id', userId)
        .eq('month', currentMonth)
        .single(),
    ]);

    const subscription = subscriptionResult;
    const usage = usageResult.data;

    // 确定配额限制
    let aiLimit: number;
    let storageLimit: number;

    if (subscription && this.isSubscriptionActive(subscription)) {
      // 付费用户
      aiLimit = subscription.plan.ai_quota === -1 ? Infinity : subscription.plan.ai_quota;
      storageLimit = subscription.plan.storage_quota_mb;
    } else {
      // 免费用户或已过期
      aiLimit = FREE_QUOTA.aiCalls;
      storageLimit = FREE_QUOTA.storageMb;
    }

    const aiUsed = usage?.ai_calls_used || 0;
    const storageUsed = usage?.storage_used_mb || 0;

    return {
      aiCallsUsed: aiUsed,
      aiCallsLimit: aiLimit,
      storageUsedMb: storageUsed,
      storageLimitMb: storageLimit,
      isOverLimit: aiUsed >= aiLimit || storageUsed >= storageLimit,
    };
  }

  /**
   * 检查是否有足够配额
   */
  async checkQuota(userId: string, type: 'ai' | 'storage', amount: number = 1): Promise<{
    allowed: boolean;
    remaining: number;
    reason?: string;
  }> {
    const usage = await this.getQuotaUsage(userId);

    if (type === 'ai') {
      const remaining = usage.aiCallsLimit - usage.aiCallsUsed;
      if (remaining < amount) {
        return {
          allowed: false,
          remaining: Math.max(0, remaining),
          reason: usage.aiCallsLimit === FREE_QUOTA.aiCalls
            ? '免费配额已用完，升级 Pro 获取更多 AI 能力'
            : '本月 AI 配额已用完，��月自动重置',
        };
      }
      return { allowed: true, remaining };
    }

    if (type === 'storage') {
      const remaining = usage.storageLimitMb - usage.storageUsedMb;
      if (remaining < amount) {
        return {
          allowed: false,
          remaining: Math.max(0, remaining),
          reason: usage.storageLimitMb === FREE_QUOTA.storageMb
            ? '免费存储空间已满，升级 Pro 获取更多空间'
            : '存储空间已满，请清理或升级套餐',
        };
      }
      return { allowed: true, remaining };
    }

    return { allowed: true, remaining: Infinity };
  }

  /**
   * 消耗配额
   */
  async consumeQuota(userId: string, type: 'ai' | 'storage', amount: number = 1): Promise<boolean> {
    const check = await this.checkQuota(userId, type, amount);
    if (!check.allowed) {
      return false;
    }

    const supabase = await createClient();
    const currentMonth = this.getCurrentMonth();

    const field = type === 'ai' ? 'ai_calls_used' : 'storage_used_mb';

    // Upsert: 存在则增加，不存在则创建
    await supabase.rpc('increment_quota_usage', {
      p_user_id: userId,
      p_month: currentMonth,
      p_field: field,
      p_amount: amount,
    });

    return true;
  }

  /**
   * 获取活跃订阅（包含宽限��检查）
   */
  private async getActiveSubscription(userId: string) {
    const supabase = await createClient();

    const { data } = await supabase
      .from('user_subscriptions')
      .select(`
        *,
        plan:subscription_plans(*)
      `)
      .eq('user_id', userId)
      .in('status', ['active', 'past_due']) // 欠费状态仍允许使用
      .single();

    return data;
  }

  /**
   * 检查订阅是否有效（包含宽限期）
   */
  private isSubscriptionActive(subscription: any): boolean {
    if (subscription.status === 'active') {
      return true;
    }

    // 宽限期检查
    if (subscription.grace_period_end) {
      const graceEnd = new Date(subscription.grace_period_end);
      if (graceEnd > new Date()) {
        return true;
      }
    }

    return false;
  }

  private getCurrentMonth(): string {
    // 统一使用北京时间 (UTC+8) 作为计费周期，避免时区问题
    return new Intl.DateTimeFormat('en-CA', {
      timeZone: 'Asia/Shanghai',
      year: 'numeric',
      month: '2-digit'
    }).format(new Date()).slice(0, 7); // "2026-02"
  }
}

export const quotaService = new QuotaService();
```

```sql
-- 配额增量更新函数
CREATE OR REPLACE FUNCTION increment_quota_usage(
  p_user_id UUID,
  p_month TEXT,
  p_field TEXT,
  p_amount NUMERIC
)
RETURNS VOID AS $$
BEGIN
  INSERT INTO user_quota_usage (user_id, month, ai_calls_used, storage_used_mb)
  VALUES (p_user_id, p_month,
    CASE WHEN p_field = 'ai_calls_used' THEN p_amount ELSE 0 END,
    CASE WHEN p_field = 'storage_used_mb' THEN p_amount ELSE 0 END
  )
  ON CONFLICT (user_id, month)
  DO UPDATE SET
    ai_calls_used = CASE
      WHEN p_field = 'ai_calls_used'
      THEN user_quota_usage.ai_calls_used + p_amount
      ELSE user_quota_usage.ai_calls_used
    END,
    storage_used_mb = CASE
      WHEN p_field = 'storage_used_mb'
      THEN user_quota_usage.storage_used_mb + p_amount
      ELSE user_quota_usage.storage_used_mb
    END,
    updated_at = now();
END;
$$ LANGUAGE plpgsql;

-- 重试计数增量函数
CREATE OR REPLACE FUNCTION increment_retry_count()
RETURNS INTEGER AS $$
  SELECT COALESCE(retry_count, 0) + 1 FROM payment_events WHERE id = OLD.id;
$$ LANGUAGE sql;
```
