## 一、P0 缺失功能实现方案

> **重要性说明**：以下 P0 功能直接影响付费转化率和用户信任度，必须在 Phase 1 完成。

### 1.1 免费试用期功能

#### 设计目标

- 让用户在付费前体验 Pro 功能，降低决策门槛
- 无需绑定支付方式，降低心理负担
- 试用期结束自动降级，不产生费用

#### 试用规则

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 试用时长 | 7 天 | 行业标准，足够体验核心功能 |
| 试用等级 | Pro | 让用户感受付费价值 |
| 触发条件 | 新用户注册 | 自动开启试用 |
| 限制条件 | 每账号仅一次 | 防止反复注册薅羊毛 |
| 结束处理 | 自动降级到 Free | 无需用户操作 |

#### 数据库设计

```sql
-- 扩展 user_entitlements 表
ALTER TABLE user_entitlements ADD COLUMN IF NOT EXISTS
  trial_started_at TIMESTAMPTZ,           -- 试用开始时间
  trial_ends_at TIMESTAMPTZ,              -- 试用结束时间
  trial_used BOOLEAN DEFAULT FALSE,       -- 是否已使用试用
  trial_converted BOOLEAN DEFAULT FALSE;  -- 是否转化为付费

-- 索引
CREATE INDEX idx_user_entitlements_trial ON user_entitlements(trial_ends_at)
  WHERE trial_ends_at IS NOT NULL AND plan_tier = 'pro';
```

#### 核心服务

```typescript
// src/lib/payment/services/trial.service.ts

export class TrialService {
  private readonly TRIAL_DAYS = 7;

  async startTrial(userId: string): Promise<TrialResult> {
    const supabase = await createClient();

    // 检查是否已使用试用
    const { data: entitlement } = await supabase
      .from('user_entitlements')
      .select('trial_used')
      .eq('user_id', userId)
      .single();

    if (entitlement?.trial_used) {
      return { success: false, reason: 'TRIAL_ALREADY_USED' };
    }

    const trialEndsAt = addDays(new Date(), this.TRIAL_DAYS);

    await supabase
      .from('user_entitlements')
      .upsert({
        user_id: userId,
        plan_tier: 'pro',
        trial_started_at: new Date().toISOString(),
        trial_ends_at: trialEndsAt.toISOString(),
        trial_used: true,
        ai_quota_monthly: 500,
        storage_limit_mb: 5120,
      }, { onConflict: 'user_id' });

    return { success: true, trialEndsAt };
  }

  async processExpiredTrials(): Promise<number> {
    // 定时任务：批量降级过期试用用户
    const supabase = await createClient();

    const { data: expiredUsers } = await supabase
      .from('user_entitlements')
      .select('user_id')
      .eq('plan_tier', 'pro')
      .lt('trial_ends_at', new Date().toISOString())
      .is('valid_until', null);

    if (!expiredUsers?.length) return 0;

    await supabase
      .from('user_entitlements')
      .update({ plan_tier: 'free', ai_quota_monthly: 20, storage_limit_mb: 100 })
      .in('user_id', expiredUsers.map(u => u.user_id));

    return expiredUsers.length;
  }
}
```

### 1.2 自助退款申请入口

#### 设计目标

- 用户可在设置页面提交退款申请
- 提供结构化反馈表单，收集退款原因
- 后台审核后处理，非即时退款

#### 数据库设计

```sql
CREATE TABLE refund_requests (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  subscription_id UUID REFERENCES user_subscriptions(id),

  -- 申请信息
  reason TEXT NOT NULL,
  reason_detail TEXT,

  -- 金额信息
  original_amount INTEGER NOT NULL,
  refund_amount INTEGER,
  ai_usage_count INTEGER DEFAULT 0,
  usage_percentage NUMERIC(5,2),

  -- 状态管理
  status TEXT NOT NULL DEFAULT 'pending',  -- pending/approved/rejected/refunded

  -- 审核信息
  reviewed_by TEXT,
  reviewed_at TIMESTAMPTZ,
  rejection_reason TEXT,

  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- RLS
ALTER TABLE refund_requests ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own refund requests" ON refund_requests
  FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "Users can create refund requests" ON refund_requests
  FOR INSERT WITH CHECK (auth.uid() = user_id);
```

### 2.3 按比例退款计算

```typescript
function calculateRefundAmount(
  originalAmount: number,    // 原订单金额（分）
  totalDays: number,         // 订阅总天数
  usedDays: number,          // 已使用天数
  aiUsageCount: number,      // AI 使用次数
  aiQuota: number            // AI 配额
): number {
  // 1. 按天数计算基础退款
  const remainingDays = totalDays - usedDays;
  const baseRefund = originalAmount * (remainingDays / totalDays);

  // 2. 计算 AI 成本扣除（超过20%才扣）
  const usagePercentage = aiUsageCount / aiQuota;
  const AI_COST_PER_CALL = 5; // 5分/次
  const aiCostDeduction = usagePercentage > 0.2 ? aiUsageCount * AI_COST_PER_CALL : 0;

  // 3. 最终退款金额
  return Math.max(0, Math.round(baseRefund - aiCostDeduction));
}
```

### 2.4 升级/降级折算逻辑

#### 升级（立即生效）

```typescript
function calculateUpgradePrice(
  currentPlanPrice: number,
  newPlanPrice: number,
  remainingDays: number,
  totalDays: number
): number {
  const currentPlanRemaining = currentPlanPrice * (remainingDays / totalDays);
  return Math.max(0, newPlanPrice - currentPlanRemaining);
}
```

#### 降级（期末生效）

- 标记 `scheduled_plan_id` 和 `scheduled_change_at`
- 当期结束后自动切换套餐
