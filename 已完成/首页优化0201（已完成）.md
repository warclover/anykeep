### 第二阶段：数据获取优化（P0）

#### 2.1 创建 `/api/folders/with-stats` 聚合 API

**当前问题**:
```typescript
// 3次串行查询
const folders = await supabase.from("folders").select("*");
const bookmarks = await supabase.from("bookmarks").select("folder_id, created_at");
const recent = await supabase.from("bookmarks").select("*, folders(name)");
```

**优化方案**:
```sql
SELECT
  f.*,
  COUNT(b.id) as bookmark_count,
  COUNT(CASE WHEN b.created_at >= CURRENT_DATE THEN 1 END) as today_count,
  MAX(b.created_at) as last_bookmark_at
FROM folders f
LEFT JOIN bookmarks b ON b.folder_id = f.id AND b.deleted_at IS NULL
WHERE f.user_id = $1 AND f.deleted_at IS NULL
GROUP BY f.id
ORDER BY f.created_at DESC;
```

**预期收益**: 减少 67% 请求数

#### 2.2 创建 `/api/analytics/stats` 聚合 API

**当前问题**:
```typescript
// 全量查询所有书签
const { data: bookmarks } = await supabase.from("bookmarks").select("*");
// 客户端计算趋势、平台分布、标签频次等
```

**优化方案**:
```sql
-- 趋势数据
SELECT DATE(created_at) as date, COUNT(*) as count
FROM bookmarks WHERE user_id = $1 AND created_at >= NOW() - INTERVAL '30 days'
GROUP BY DATE(created_at);

-- 平台分布
SELECT platform, COUNT(*) as count
FROM bookmarks WHERE user_id = $1
GROUP BY platform;

-- 标签频次
SELECT unnest(tags) as tag, COUNT(*) as count
FROM bookmarks WHERE user_id = $1
GROUP BY tag ORDER BY count DESC LIMIT 20;
```

**预期收益**: 减少 80% 数据传输量

#### 2.3 统一使用 TanStack Query 缓存

**当前状态**:
| Hook | 缓存方案 |
|------|---------|
| useInitData | SWR |
| useFolders | SWR |
| useBookmarks | TanStack Query |
| useFoldersData | useState (无缓存) |
| useAnalyticsData | useState (无缓存) |

**目标**: 全部迁移到 TanStack Query

#### 2.4 添加 AbortController 请求中断

**目标**: 防止快速页面切换导致的竞态条件

### 第三阶段：渲染优化（P1）

#### 3.1 布局组件懒加载

**当前问题** (`src/app/(main)/layout.tsx`):
```tsx
<AppHeader />
<AppSidebar />
<MainContentWrapper>
  <MainContent>{children}</MainContent>
</MainContentWrapper>
<LayoutAIPanel />      // 可懒加载
<MobileBottomNav />    // 可懒加载
<FloatingActionMenu /> // 可懒加载
```

**优化方案**:
```tsx
import dynamic from 'next/dynamic';

const LayoutAIPanel = dynamic(() => import('@/components/layout/layout-ai-panel'), {
  ssr: false,
  loading: () => null,
});

const FloatingActionMenu = dynamic(() => import('@/components/fab/floating-action-menu'), {
  ssr: false,
  loading: () => null,
});
```

**预期收益**: 首屏 TTI 减少 30%

#### 3.2 添加 Suspense 边界

**优化方案**:
```tsx
<Suspense fallback={<LoadingSkeleton />}>
  <AsyncDataComponent />
</Suspense>
```

#### 3.3 移动/桌面条件渲染

**优化方案**:
```tsx
const isMobile = useMediaQuery('(max-width: 768px)');

{isMobile ? <MobileBottomNav /> : null}
```

#### 3.4 关键组件 React.memo

**目标组件**:
- AppSidebar

- BookmarkCard
- FolderItem
