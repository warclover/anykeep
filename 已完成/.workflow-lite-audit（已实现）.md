### 集成逻辑审查

**核心流程** (位于 `trigger-scheduler.ts:151-199`):

```typescript
if (scheduled.workflowId === "daily_digest") {
  try {
    // 1. 尝试执行 Lite 版本
    const liteResult = await runLiteTask(...);

    if (liteResult.success) {
      // 2. 成功 → 更新 DB 状态为 completed
      // 3. 返回 (跳过旧引擎)
      return { success: true, executionId: `lite-${scheduled.id}` };
    } else {
      // 4. Lite 报告失败 → 记录日志，继续执行旧引擎
      logger.error(..., "falling back");
    }
  } catch (error) {
    // 5. Lite 抛异常 → 记录日志，继续执行旧引擎
    logger.error(..., "falling back");
  }
}

// 6. 降级兜底：执行旧的 orchestrator.startWorkflow(...)
const execution = await this.orchestrator.startWorkflow(...);
```

**安全性评估** ✅

| **Lite 任务失败** | Try-Catch + 旧引擎兜底 | ✅ 零风险 |
| **旧引擎被误跳过** | ���在 `liteResult.success === true` 时返回 | ✅ 逻辑正确 |
