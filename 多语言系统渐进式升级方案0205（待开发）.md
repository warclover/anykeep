## 一、方案概述

### 1.1 背景分析

**当前状态**：

- ✅ 已有基础 i18n 架构（`src/lib/i18n/`）
- ✅ 翻译文件完整（355 个翻译键，中英双语）
- ✅ 7 个核心组件已迁移
- ✅ 543 个组件待迁移
- ❌ 无 URL 级别语言路由
- ❌ AI 摘要硬编码中文
- ❌ 服务端组件无 i18n 支持

**规划方案差异**：
原规划建议采用 next-intl 完整路由级方案（`[locale]` 目录结构），但评估发现：

- 工作量：4-5 周
- 风险：中-高（路由重构、Auth 冲突）
- 回滚难度：高

### 1.2 混合渐进式策略

```

│                    混合渐进式架构                                │
├─────────────────────────────────────────────────────────────────┤
```

| 优势         | 说明                         |
| ------------ | ---------------------------- |
| **风险可控** | 避免大规模路由重构           |

| **灵活调整** | 后续可决定是否升级路由级方案 |
| **向后兼容** | 现有组件无需修改             |

### 2.2 新增：服务端 i18n 支持

```typescript
// src/lib/i18n/server.ts (新增)
import { headers } from "next/headers";
import type { Locale, Messages } from "./types";

/**
 * 从请求头获取用户语言偏好
 * 优先级: Cookie > Header > 默认
 */
export async function getServerLocale(): Promise<Locale> {
  const headersList = await headers();
  const cookieLocale = headersList
    .get("cookie")
    ?.match(/anykeep-locale=([^;]+)/)?.[1];

  if (cookieLocale && (cookieLocale === "zh-CN" || cookieLocale === "en-US")) {
    return cookieLocale as Locale;
  }

  // 从 Accept-Language 检测
  const acceptLanguage = headersList.get("accept-language");
  if (acceptLanguage?.includes("en")) {
    return "en-US";
  }

  return "zh-CN";
}

/**
 * 服务端获取翻译文本
 */
export async function getServerMessages(locale?: Locale): Promise<Messages> {
  const targetLocale = locale || (await getServerLocale());
  const messages = await import(`@/lib/messages/${targetLocale}.json`);
  return messages.default as Messages;
}
```

### 4.5 语义别名注入

```typescript
// src/lib/classification/folder-matcher.ts
import { getFolderAliases } from "@/lib/i18n/folder-aliases";

export function matchFolder(query: string, folders: Folder[], locale: Locale) {
  const normalizedQuery = query.toLowerCase();

  for (const folder of folders) {
    // 直接匹配
    if (folder.name.toLowerCase().includes(normalizedQuery)) {
      return folder;
    }

    // 别名匹配（英文界面下的中文名称）
    const aliases = getFolderAliases(folder.name, locale);
    for (const alias of aliases) {
      if (alias.toLowerCase().includes(normalizedQuery)) {
        return folder;
      }
    }
  }

  return null;
}
```
