## 2. 竞品最佳实践模式

### 2.1 NotebookLM 最佳实践

**核心成功要素**:

| 模式             | 描述                                                  | AnyKeep 可借鉴点                        |
| ---------------- | ----------------------------------------------------- | --------------------------------------- |
| **多格式输出**   | 同一内容可生成：Deep Dive / Brief / Debate / Critique | 综述可选风格：概要 / 完整 / 对比 / 批判 |
| **实时交互**     | 可中断音频提问，AI 主持人实时回答                     | 综述生成中可插入问题                    |
| **引导式自定义** | 用户可指定"专注于 X 话题"或"面向 Y 受众"              | 创建时可输入"综述重点"和"目标读者"      |
| **源头锁定**     | 所有输出严格基于上传内容，无幻觉                      | 强调"仅基于您的收藏"，增强信任          |

**关键数据**:

- 72% 用户偏好 Audio Overview 而非静默阅读
- 仅 18% 用户对主持人角色感到困惑（说明双主持人设计直观）
- 100 个免费 Notebook，每个 50 个来源，每日 3 次音频生成

---

### 2.2 Elicit 最佳实践

**核心成功要素**:

| 模式                       | 描述                          | AnyKeep 可借鉴点             |
| -------------------------- | ----------------------------- | ---------------------------- |
| **99.4% 数据提取精度**     | 严格的引用到句子级别          | 共识/分歧点必须附带原文引用  |
| **Claims & Evidence 表格** | 结构化呈现主张和证据          | 共识区块改为表格形式         |
| **Living Reviews**         | 可随新论文更新综述            | **增量更新**功能对标         |
| **多格式导出**             | CSV/BibTeX/RIS 无缝衔接       | 增加 BibTeX 导出（学术用户） |
| **筛选透明**               | 显示每篇论文被筛入/筛出的原因 | 显示"为什么选中这条书签"     |

**关键数据**:

- 节省 80% 筛选时间
- 报告可包含最多 80 篇论文
- 1.38 亿论文 + 54.5 万临床试验

### 2.3 Consensus 最佳实践

**核心成功要素**:

| 模式                    | 描述                         | AnyKeep 可借鉴点               |
| ----------------------- | ---------------------------- | ------------------------------ |
| **Consensus Meter**     | Yes/No/Possibly/Mixed 可视化 | 🔴 **必须实现**：共识度可视化  |

| **可信来源锁定**        | 仅来自同行评审论文           | 强调"仅基于您的收藏"           |

**关键数据**:

- 节省 5-10 小时/周
- 2.2 亿论文库
- 使用 GPT-5 多代理系统

## 3. AnyKeep 补充建议

基于上述最佳实践，Master 建议在**原有 6 周计划**基础上，补充以下功能：

### 3.1 🔴 P0 补充项（强烈建议纳入）

#### [S1] 综述风格选择

**竞品参考**: NotebookLM 的 Deep Dive / Brief / Debate / Critique

**功能设计**:

在创建综述时，除了深度模式外，增加**风格选择**：

| 风格       | 描述         | 输出特点             |
| ---------- | ------------ | -------------------- |
| **概要式** | 快速了解要点 | 简洁要点列表         |
| **叙事式** | 像讲故事一样 | 自然段落，有起承转合 |
| **对比式** | 强调异同     | 突出共识与分歧       |
| **批判式** | 质疑论点     | 更多分歧和盲区分析   |

**UI 示意**:

```
┌─────────────────────────────────────────────────────────┐
│  选择综述风格                                           │
├─────────────────────────────────────────────────────────┤
│  ┌───────────┐  ┌───────────┐  ┌───────────┐            │
│  │ 📋 概要式  │  │ 📖 叙事式  │  │ ⚖️ 对比式  │            │
│  │ 快速要点   │  │ 故事叙述   │  │ 强调异同   │            │
│  └───────────┘  └───────────┘  └───────────┘            │
└─────────────────────────────────────────────────────────┘
```

**估算**: 0.5 周（主要是 Prompt 调整）

---

#### [S2] 自然语言触发综述

**竞品参考**: Consensus 的搜索框式入口

**功能设计**:

用户可以在 AI 对话中直接用自然语言触发综述：

```
用户: 帮我综述一下最近收藏的关于 AI Agent 的文章
AI: 我发现您有 12 篇关于 AI Agent 的收藏，要生成综述吗？
    [生成综述] [查看书签列表]
```

**技术实现**:

- 复用现有意图分类系统
- 新增 `create → synthesis` 意图类型
- 调用 `SynthesisRecommendService` 查找匹配书签

**估算**: 1 周

---

#### [S3] 综述进度中实时提问

**竞品参考**: NotebookLM 的 Interactive Mode

**功能设计**:

在综述生成过程中，用户可以：

1. 点击"问一个问题"按钮
2. 输入问题（如"重点关注商业化方面"）
3. AI 在后续步骤中考虑该问题

**UI 示意**:

```
┌─────────────────────────────────────────────────────────┐
│  正在生成综述                                           │
├─────────────────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓▓▓░░░░░░  65%  分析阶段                         │
│                                                         │
│  💡 生成中预览:                                         │
│  "根据您的收藏，AI Agent 领域主要讨论..."               │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 💬 有问题想问？输入后将影响后续分析              │    │
│  │ 例如: "重点关注实际应用案例"                     │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│  [🖐️ 问一个问题]                         [取消生成]     │
└─────────────────────────────────────────────────────────┘
```

**估算**: 1.5 周

#### [S5] 综述推荐气泡增强

**竞品参考**: Mem.ai 的 Related Notes + Consensus 即时发现

**现状**: 已有 `SynthesisRecommendBubble`，但功能较弱

**增强设计**:

1. **更智能的触发**:
   - 当用户连续收藏 3+ 篇同主题内容
   - 当用户浏览某标签/文件夹超过 30 秒
   - 每周定期推荐（可关闭）

2. **更丰富的预览**:
   ```
   ┌─────────────────────────────────────────────────────┐
   │  ✨ 发现可综述主题                                  │
   ├─────────────────────────────────────────────────────┤
   │                                                     │
   │  「AI 开发工具」                                    │
   │  12 篇收藏 · 来自 微信/B站/小红书                   │
   │                                                     │
   │  预估产出:                                          │
   │  • 3-5 个核心共识                                   │
   │  • 1-2 个观点分歧                                   │
   │  • 2 个知识盲区                                     │
   │                                                     │
   │  [📖 生成综述]  [👀 预览书签]  [❌ 忽略]             │
   └─────────────────────────────────────────────────────┘
   ```

**估算**: 1 周

## 4. 总结：增强路线图更新

### 4.1 原有计划 + 补充建议

| 阶段             | 原有内容                       | 补充建议                       | 总周期      |
| ---------------- | ------------------------------ | ------------------------------ | ----------- |
| **Phase 1**      | E1 来源选择器 + I1 创建页完善  | +S1 风格选择                   | **2.5 周**  |
| **Phase 2**      | E4 来源面板 + I2/I3 详情页增强 | +S4 来源透明度                 | **2 周**    |
| **Phase 3**      | E2 质量预检 + I4 生成体验      | +S3 实时提问                   | **2.5 周**  |
| **Phase 4**      | E3 盲区一键补充                | +S2 自然语言触发 + S5 推荐增强 | **3 周**    |
| **Phase 5** (新) | -                              | S6 综述对比                    | **1.5 周**  |
| **总计**         | 6 周                           | +5.5 周                        | **11.5 周** |

### 4.2 Master 建议的优先级排序

**如果只能选 3 个补充项**，Master 强烈建议：

| 排名 | 补充项              | 理由                           | 估算   |
| ---- | ------------------- | ------------------------------ | ------ |
| 1    | **S1 风格选择**     | 低成本高收益，仅需 Prompt 调整 | 0.5 周 |
| 2    | **S2 自然语言触发** | 降低使用门槛，对标 Consensus   | 1 周   |
| 3    | **S5 推荐增强**     | 主动发现价值，提升使用频率     | 1 周   |

**这 3 项可在原有 6 周计划内并行完成**（总增加约 2.5 周）。

### 4.3 差异化定位建议

基于竞品分析，AnyKeep 主题综述的**独特定位**应是：

```
NotebookLM: 学术研究 + 多模态输出 (音频/视频)
Elicit: 系统性文献综述 + 极高精度
Consensus: 科学共识查询 + 即时答案
─────────────────────────────────────
AnyKeep: 跨平台内容聚合 + 观点对抗分析 + 知识闭环
```

**核心差异化点**:

1. **跨平台**: 微信/B站/小红书等，非仅学术论文
2. **观点对抗**: 共识 + 分歧 + 盲区的四维分析（竞品均无）
3. **知识闭环**: 发现盲区 → 搜索 → 收藏 → 重新综述
