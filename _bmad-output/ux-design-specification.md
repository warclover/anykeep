# UX Design Specification - Thematic Synthesizer (主题合成器)

> **设计愿景**: 让用户从"收藏了就忘"转变为"知识复利"的主动管理者

---

## 1. Executive Summary

### 1.1 Project Vision

主题合成器是 AnyKeep 从"信息仓库"迈向"智慧大脑"的关键功能。它解决重度用户的核心痛点：**"看不过来"和"连不起来"**。

### 1.2 Target Users

| 用户类型   | 特征                | 核心需求             |
| ---------- | ------------------- | -------------------- |
| 职场白领   | 知识焦虑 + 行动意愿 | 快速整合行业信息     |
| 科研人员   | 深度分析需求        | 学术级观点对比       |
| 内容创作者 | 素材库庞大          | 发现观点冲突创作素材 |
| 备考学生   | 资料分散            | 知识盲区发现         |

### 1.3 Key Design Challenges

1. **信息过载感**：50+ 篇文章如何不让用户感到焦虑
2. **等待焦虑**：3-5 分钟生成时间如何让用户安心
3. **四维输出理解**：如何让用户快速理解概述/共识/分歧/盲区
4. **标注交互**：如何让高亮标注感觉自然直观

### 1.4 Design Opportunities

1. **流式体验**：渐进式显示四维输出，边生成边阅读
2. **冲突可视化**：将观点分歧转化为直观的对比视图
3. **AI 原生交互**：三模态入口体现 AI 主动能力
4. **知识发现感**：盲区提示创造"啊哈"时刻

## 2. Core User Experience

### 2.1 Defining Experience

> **"选择 → 等待 → 洞察"** — 用户选中一组收藏，看着 AI 逐步揭示观点冲突和知识盲区。

这就像打开一个智能信封，里面的内容逐渐浮现，每一个维度都带来新的认知。

**核心体验三要素**：

1. **选择的掌控感**：用户决定合成什么、多深度
2. **生成的透明感**：看到 AI 正在处理哪个维度
3. **洞察的惊喜感**：发现自己没注意到的观点冲突

### 2.2 User Mental Model

用户心智模型：**"专家秘书"**

- 用户想象 AI 像一个研究助理在帮他们整理资料
- 期望看到结构化的报告，而非杂乱的罗列
- 期望 AI 能发现他们没注意到的东西
- **关键洞察**：用户不要"另一个 AI 聊天"，要"专业整理能力"

### 2.3 Platform Strategy

| 平台            | 体验策略           | 交互特点           |
| --------------- | ------------------ | ------------------ |
| **Desktop Web** | 主力平台，完整功能 | 并排对比、深度阅读 |
| **Mobile Web**  | 阅读优先，生成次要 | 垂直滚动、折叠展开 |
| **Agent 对话**  | 嵌入式预览         | 卡片式、可展开     |

### 2.4 Success Criteria

| 体验指标       | 目标  | 衡量方式         |
| -------------- | ----- | ---------------- |
| 首次使用成功率 | > 80% | 完成首次综述生成 |
| 等待焦虑感     | 低    | 中途放弃率 < 10% |
| 结构理解度     | > 70% | 用户访问全部四维 |
| 标注参与率     | > 30% | 有标注行为的用户 |

### 2.5 Experience Principles

1. **渐进揭示 (Progressive Disclosure)**：四维输出逐步展开，不一次性压垮用户
2. **透明过程 (Transparent Process)**：让用户看到 AI 正在做什么
3. **冲突中立 (Neutral on Conflicts)**：展示分歧，不做判断
4. **用户掌控 (User in Control)**：深度选择、AI 推荐开关、中途取消

## 3. Desired Emotional Response

### 3.1 Primary Emotional Goals

| 情感目标   | 描述               | 设计实现                 |
| ---------- | ------------------ | ------------------------ |
| **掌控感** | 我决定合成什么     | 清晰的来源选择、深度选择 |
| **安心感** | 我知道 AI 在做什么 | 进度条、当前维度显示     |
| **洞察感** | 我发现了新东西     | 分歧高亮、盲区建议       |
| **成就感** | 我整理好了知识     | 完成动画、报告保存确认   |

### 3.2 Emotional Journey Mapping

```
触发时刻          生成过程              阅读时刻              复用时刻
   │                │                    │                    │
   ▼                ▼                    ▼                    ▼
┌────────┐    ┌────────────┐      ┌────────────┐      ┌────────────┐
│ 期待感 │───▶│  安心感     │ ───▶│  洞察感     │ ───▶│  成就感     │
│ "这能行"│    │ "正在处理中"│      │ "原来如此!"│      │ "我做到了" │
└────────┘    └────────────┘      └────────────┘      └────────────┘
```

### 3.3 Micro-Emotions

| 交互点   | 期望情感   | 避免情感       |
| -------- | ---------- | -------------- |
| 选择来源 | 清晰、简单 | 困惑、选择焦虑 |
| 等待生成 | 有趣、透明 | 焦虑、不确定   |
| 看到分歧 | 惊喜、好奇 | 信息过载       |
| 发现盲区 | 启发、动力 | 被批评感       |
| 标注内容 | 自然、流畅 | 繁琐、打断阅读 |

### 3.4 Emotional Design Principles

1. **等待不焦虑**：流式输出 + 进度反馈 + 预估时间
2. **冲突有价值**：分歧展示要有对比感，而非混乱感
3. **盲区是礼物**：知识盲区是发现机会，不是批评
4. **标注无负担**：一键高亮，可选备注

## 4. UX Pattern Analysis & Inspiration

### 4.1 Inspiring Products Analysis

| 产品               | 参考要素       | 学习点                 |
| ------------------ | -------------- | ---------------------- |
| **Notion AI**      | 流式生成体验   | 打字机效果、分段输出   |
| **Claude/ChatGPT** | 思考过程可视化 | "正在分析..."状态      |
| **Readwise**       | 高亮标注交互   | 选中即高亮、侧边栏备注 |
| **Obsidian**       | 结构化笔记展示 | 折叠/展开、层级清晰    |
| **Perplexity**     | 引用来源展示   | 内联引用、可点击来源   |

### 4.2 Transferable UX Patterns

#### 流式输出模式 (from Notion AI / ChatGPT)

- 打字机效果增加生成感
- 分段输出减少等待焦虑
- 可滚动查看已生成内容

#### 结构化阅读模式 (from Obsidian)

- 四维输出各自可折叠
- 层级缩进清晰
- 侧边导航快速跳转

#### 高亮标注模式 (from Readwise)

- 选中文本自动弹出高亮选项
- 多色高亮区分重要程度
- 标注列表侧边栏汇总

#### 来源引用模式 (from Perplexity)

- 共识/分歧中内联显示来源数量
- 点击展开来源详情
- 可跳转到原始书签

### 4.3 Anti-Patterns to Avoid

| Anti-Pattern   | 问题             | 替代方案            |
| -------------- | ---------------- | ------------------- |
| 全部一次性加载 | 信息过载         | 渐进式展开          |
| 模糊的进度条   | 不知道还要等多久 | 具体步骤 + 预估时间 |
| 纯文本分歧展示 | 难以对比         | 并排对比视图        |
| 强制阅读盲区   | 被打断感         | 折叠默认 + 提示徽章 |

### 4.4 Design Inspiration Strategy

**采用**：

- 流式打字机效果 (Notion AI)
- 折叠/展开结构 (Obsidian)
- 选中即高亮 (Readwise)
- 内联来源引用 (Perplexity)

**适配**：

- 四维输出需要独特的视觉区分
- 分歧展示需要并排对比能力
- 盲区需要建议导向的设计

**避免**：

- ChatGPT 式的无尽对话感
- 复杂的多级菜单
- 需要额外操作的标注流程

## 5. Design System Foundation

### 5.1 Design System Choice

**选择**: Shadcn UI + Tailwind CSS (AnyKeep 现有系统)

**理由**:

- 复用现有设计系统，保持一致性
- 组件化程度高，开发效率有保障
- 支持深度定制，满足四维输出特殊需求

### 5.2 Color System

#### 语义色彩映射

| 维度     | 颜色 | 色值          | 用途         |
| -------- | ---- | ------------- | ------------ |
| **概述** | 蓝色 | `slate-600`   | 中立、信息性 |
| **共识** | 绿色 | `emerald-600` | 认同、正面   |
| **分歧** | 橙色 | `amber-600`   | 警示、关注   |
| **盲区** | 紫色 | `violet-600`  | 发现、探索   |

#### 高亮颜色

| 类型     | 颜色         | 用途       |
| -------- | ------------ | ---------- |
| 默认高亮 | `yellow-200` | 普通标注   |
| 重要高亮 | `orange-200` | 重点内容   |
| 疑问高亮 | `blue-200`   | 待确认内容 |

#### 状态颜色

| 状态   | 颜色              | 场景          |
| ------ | ----------------- | ------------- |
| 生成中 | `blue-500` + 动画 | 进度指示      |
| 完成   | `green-500`       | 成功状态      |
| 错误   | `red-500`         | 失败状态      |
| 警告   | `amber-500`       | 超时/降级提示 |

### 5.3 Typography System

| 元素     | 字体           | 大小 | 行高 | 用途                |
| -------- | -------------- | ---- | ---- | ------------------- |
| 报告标题 | Inter Bold     | 24px | 1.3  | 综述主标题          |
| 维度标题 | Inter SemiBold | 18px | 1.4  | 概述/共识/分歧/盲区 |
| 正文     | Inter Regular  | 16px | 1.6  | 报告内容            |
| 来源引用 | Inter Medium   | 14px | 1.4  | 书签来源            |
| 辅助文字 | Inter Regular  | 12px | 1.5  | 时间、状态          |

### 5.4 Spacing & Layout Foundation

#### 间距系统 (8px 基准)

| Token     | 值   | 用途         |
| --------- | ---- | ------------ |
| `space-1` | 4px  | 紧凑间距     |
| `space-2` | 8px  | 基础间距     |
| `space-3` | 12px | 小组件内间距 |
| `space-4` | 16px | 标准间距     |
| `space-6` | 24px | 区块间距     |
| `space-8` | 32px | 大区块间距   |

### 5.5 Accessibility Considerations

| 要求       | 实现方式                 |
| ---------- | ------------------------ |
| 键盘导航   | Tab 顺序清晰、焦点可见   |
| 屏幕阅读器 | ARIA labels、语义化 HTML |
| 对比度     | 正文 4.5:1、大文本 3:1   |
| 高亮快捷键 | Cmd/Ctrl + H 快速高亮    |
| 折叠状态   | aria-expanded 正确标注   |

## 6. Component Design Specifications

### 6.1 Synthesis Entry Points

#### 6.1.1 文件夹/标签右键菜单项

```
┌─────────────────────────┐
│  📊 生成主题综述        │  ← 新增菜单项
│  ─────────────────────  │
│  📁 重命名              │
│  📤 导出                │
│  🗑️ 删除                │
└─────────────────────────┘
```

**交互规格**:

- 悬停显示 tooltip: "基于此文件夹/标签内的书签生成综述报告"
- 点击后跳转到生成引导页，预选当前文件夹/标签

#### 6.1.2 批量选中操作栏

```
┌─────────────────────────────────────────────────────────────┐
│  已选中 23 项    [📊 生成综述] [🏷️ 添加标签] [📁 移动] [🗑️ 删除] │
└─────────────────────────────────────────────────────────────┘
```

**交互规格**:

- 选中 ≥3 项时显示"生成综述"按钮
- 按钮状态: 禁用 (< 3 项) / 启用 / 生成中
- 点击后跳转到生成引导页，预选当前选中项

#### 6.1.3 AI 主动推荐气泡

```
                                    ┌────────────────────────────┐
                                    │  🎯 发现相似主题           │
                                    │                            │
                                    │  「AI 产品化」下有 35 篇    │
                                    │  相似内容，要生成综述吗？   │
                                    │                            │
                                    │  [试试看]    [暂不需要]    │
                                    │                            │
                                    │  □ 不再提示此类推荐        │
                                    └────────────────────────────┘
```

**交互规格**:

- 右下角弹出，非模态
- 5秒后自动淡出（如无交互）
- 可拖动位置、可关闭
- 频率限制: 每日最多 3 次
