## ✅ 修复的问题

### 1. NLU-01: 缺少"收藏"操作规则

**问题**: "把这篇文章收藏一下" 被识别为 `chitchat`

**修复**:

```typescript
// 添加精确的收藏规则
{
  pattern: /收藏.{0,2}(一下|下|它|这|起来)|保存.{0,2}(一下|下|它|这)|存下来?|加入收藏|添加到收藏|把.{0,5}收藏/,
  type: "action",
  subType: "save",
  weight: 55,
}
```

**结果**: ✅ 正确识别为 `action:save`

---

### 2. NLU-02: 复合指令优先级问题

**问题**: "把这篇标为'AI'，然后生成个摘要" 优先识别为 `create:digest` 而非 `action:tag`

**修复**:

```typescript
// 提高标签规则权重 50 → 75
{
  pattern: /添加.{0,3}标签|打标签|标记|标为|设为.{0,3}标签/,
  type: "action",
  subType: "tag",
  weight: 75,  // 原为 50，现高于摘要的 70
}
```

**结果**: ✅ 正确识别为 `action:tag`

---

### 3. NLU-06: 英文关键词不支持

**问题**: "帮我 summarize 一下这个 page" 被识别为 `chitchat`

**修复**:

```typescript
// 扩展摘要规则支持英文
{
  pattern: /摘要|总结|概括|速览|summarize|summary/i,
  type: "create",
  subType: "digest",
  weight: 70,
}
```

**结果**: ✅ 正确识别为 `create:digest`

---

### 4. NLU-11: B站搜索意图误判

**问题**: "找一下 B站 的收藏" 被识别为 `create:bilibili_transcript`

**修复**:

```typescript
// 收紧 B站字幕规则，必须明确包含字幕相关词
{
  pattern: /B站.{0,3}(字幕|文字稿|转文字)|bilibili.{0,3}(字幕|文字稿|转文字)|视频.{0,3}(字幕|文字稿)|提取.{0,3}字幕/i,
  type: "create",
  subType: "bilibili_transcript",
  weight: 86,
}
```

**结果**: ✅ 正确识别为 `query:search`

## ⚠️ 发现的问题

### 关键问题 (需优先修复)

1. **NLU-01: 缺少"收藏"操作规则**
   - 问题: "把这篇文章收藏一下" 被识别为 chitchat
   - 建议: 添加 `/收藏|保存|存下来/` 规则，映射到 `action:save`

2. **NLU-06: 英文关键词支持不足**
   - 问题: "summarize", "page" 等英文词未被识别
   - 建议: 扩展规则支持常见英文技术词汇

3. **NLU-02: 复合指令解析优先级**
   - 问题: 当同时包含标签和摘要时，优先识别摘要
   - 建议: 考虑多步骤意图拆分机制

4. **NLU-11: B站搜索意图误判**
   - 问题: "找一下 B站 的收藏" 被识别为 create
   - 建议: 调整 "找/查/搜" 规则权重

### 中等问题

5. **多语言混合支持**
   - 当前规则以中文为主，中英混合场景覆盖不足
   - 建议: 添加常见英文技术词汇的规则别名

## 💡 优化建议

### 短期改进 (1-2周)

1. **扩展意图规则集**

   ```typescript
   // 建议添加的规则
   { pattern: /收藏|保存|存下来/, type: "action", subType: "save", weight: 55 },
   { pattern: /summarize|summary/i, type: "create", subType: "digest", weight: 70 },
   { pattern: /page|页面/i, type: "query", subType: "content", weight: 40 },
   ```

2. **提升 LLM 兜底能力**
   - 对于规则匹配失败的场景，启用 LLM 分类器
   - 当前 LLM 兜底阈值 0.6 可降低到 0.5

3. **添加复合意图检测**
   - 检测包含多个动作的指令
   - 拆分为多步骤任务队列

### 中期改进 (1个月)

4. **增强多语言支持**
   - 添加常见英文技术词汇映射
   - 支持拼音输入识别

5. **完善实体提取**
   - 增加 URL、文件名等实体类型
   - 提升平台名称变体识别（B站/哔哩哔哩/bilibili）

### 长期改进

6. **端到端 RAG 测试**
   - 建立标准测试数据集
   - 测试幻觉率和来源准确性

7. **性能基准测试**
   - TTFT (首字延迟) 监控
   - Token 消耗分析
