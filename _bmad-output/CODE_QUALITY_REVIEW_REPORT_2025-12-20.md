## 1. 安全性审查报告

### 1.1 严重问题

#### 🔴 问题 #1: 环境变量泄露 (Critical)

**位置**: `c:\anykeep\.env.local`
**风险**: 攻击者可使用 Service Role Key 绕过所有 RLS 策略

**修复方案**:

```bash
# 1. 立即在 Supabase Dashboard 轮换所有密钥
# 2. 从 Git 历史移除敏感文件
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch .env.local" \
  --prune-empty --tag-name-filter cat -- --all
# 3. 强制推送
git push origin --force --all
```

#### 🔴 问题 #2: XSS 漏洞风险 (High)

**位置**: `src/components/snapshot/snapshot-viewer.tsx:497`
**问题**: `sanitizeHtmlImages` 仅移除图片，不防护 XSS

**修复方案**:

```bash
npm install isomorphic-dompurify
```

```typescript
import DOMPurify from "isomorphic-dompurify";

function sanitizeHtml(html: string): string {
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS: [
      "p",
      "br",
      "strong",
      "em",
      "h1",
      "h2",
      "h3",
      "ul",
      "ol",
      "li",
      "a",
      "code",
    ],
    ALLOWED_ATTR: ["href", "target", "rel", "class"],
  });
}
```
