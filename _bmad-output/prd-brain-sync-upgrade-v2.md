## 1. 背景与问题

### 1.1 现状分析

当前自习工坊基于 SM-2 间隔重复算法，提供基础的复习卡片功能。经过用户反馈和竞品分析，发现以下核心问题：

| 问题             | 描述                                | 用户感知                     |
| ---------------- | ----------------------------------- | ---------------------------- |
| **问题质量低**   | 生成的问题只是简单的定义/原因类问答 | "像小学生背单词，太幼稚"     |
| **缺乏思考引导** | 直接展示答案，无法促进深度思考      | "只是机械复习，没有真正理解" |
| **评估维度单一** | 只有"记住/模糊/忘记"三档            | "无法区分记住和理解"         |
| **孤立复习**     | 卡片与其他收藏无关联                | "碎片化，缺乏知识连接"       |

### 1.2 目标用户

**高认知群体**：有强烈自学意愿的知识工作者（产品经理、工程师、研究人员等）

**核心需求**：

- 需要深度理解，而非浅层记忆
- 希望建立知识关联，而非孤立碎片
- 追求学习效率，拒绝无意义的重复

### 1.3 竞品洞察

| 竞品      | 核心优势               | 可借鉴点             |
| --------- | ---------------------- | -------------------- |
| Readwise  | 被动推送 + 音频复习    | 降低启动成本         |
| RemNote   | 笔记即卡片，保留上下文 | 上下文增强           |
| Anki FSRS | 机器学习优化遗忘曲线   | 算法优化（未来考虑） |

## 2. 产品目标

### 2.1 核心目标

> **从"帮用户记住"升级为"帮用户真正理解"**

### 2.2 成功指标

| 指标             | 当前基线 | 目标                | 衡量方式          |
| ---------------- | -------- | ------------------- | ----------------- |
| 单次复习完成率   | ~60%     | ≥80%                | 完成/开始比例     |
| 用户理解深度反馈 | 无       | ≥50% 选择"有新理解" | 新评估维度统计    |
| 延伸阅读点击率   | 无       | ≥20%                | 关联收藏点击/展示 |
| 复习后 7 日留存  | ~30%     | ≥50%                | 7日内再次复习     |

### 2.3 非目标（边界约束）

以下功能**不在本次升级范围**，属于其他模块职责：

- ❌ 知识图谱可视化（属于知识萃取模块）
- ❌ 跨收藏综合报告（属于主题合成模块）
- ❌ 知识盲区发现（属于知识萃取模块）
- ❌ 被动推送/邮件通知（后续迭代）
- ❌ 多模态复习模式（后续迭代）

### 3.2 功能一：深度问题生成

#### 3.2.1 问题层次体系

基于布鲁姆认知分类法，将问题分为 4 个层次：

| 层次 | 类型       | 问题模式                   | 目的         |
| ---- | ---------- | -------------------------- | ------------ |
| L1   | understand | "用自己的话解释..."        | 检验真正理解 |
| L2   | apply      | "在...场景下如何应用"      | 理论到实践   |
| L3   | analyze    | "...的前提假设/局限是什么" | 批判性思考   |
| L4   | evaluate   | "与...相比，优劣是什么"    | 比较评价     |

#### 3.2.2 生成规则

每次生成复习卡片时：

- **必须包含** L1（理解）和 L2（应用）各至少 1 题
- **可选包含** L3（分析）和 L4（评价）
- **禁止生成** 可直接从原文复制答案的问题
- **禁止生成** 是非题、选择题、填空题、清单记忆题

#### 3.2.3 卡片结构

```typescript
interface FlashcardV2 {
  // 基础信息
  id: number;
  bookmarkId: number;
  bookmarkTitle: string;

  // 问题层面
  questionDepth: "understand" | "apply" | "analyze" | "evaluate";
  question: string; // 问题内容
  thinkingHint: string; // 思考方向提示（不是答案）

  // 答案层面
  keyPoints: string[]; // 参考要点（3-5个）
  sourceParagraph: string; // 原文相关片段

  // SM-2 参数（保留）
  status: "pending" | "learning" | "mastered";
  easeFactor: number;
  intervalDays: number;
  repetitions: number;
  nextReviewAt: Date;
}
```

### 3.3 功能二：思考式复习交互

#### 3.3.1 复习流程重设计

```
旧流程（浅层）:
问题 → [查看答案] → 记住/模糊/忘记

新流程（深层）:
问题 → 思考提示 → [我的理解] → [参考要点] → 理解深度自评
```

#### 3.3.3 评估维度升级

| 旧评估    | 新评估   | SM-2 映射 | 说明                       |
| --------- | -------- | --------- | -------------------------- |
| mastered  | 有新理解 | quality=5 | 深度理解，增加间隔         |
| fuzzy     | 巩固已知 | quality=4 | 已知内容强化，适度增加间隔 |
| forgotten | 仍不清楚 | quality=2 | 需要重新学习，缩短间隔     |
| -         | 跳过     | quality=3 | 不计入，保持当前间隔       |

### 3.4 功能三：延伸阅读推荐

#### 3.4.1 功能定位

- **目的**：在复习时提供相关收藏，辅助加深理解
- **边界**：不是知识发现，是复习的附属功能
- **数量**：每张卡片推荐 3 篇相关收藏

#### 3.4.2 推荐逻辑

优先级排序：

1. **向量相似度**：基于 embedding 的语义相似
2. **共同标签**：有相同标签的收藏
3. **同一文件夹**：在同一文件夹下的收藏

#### 3.4.3 界面设计

```
├─────────────────────────────────────────────────────────────┤
│ 📚 延伸阅读                                        [展开] │
├─────────────────────────────────────────────────────────────┤
│ 【展开后】                                                  │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 📄 {相关收藏标题1}                                      │ │
│ │    相关度：{共同标签：React, 性能优化}                  │ │
│ └─────────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 📄 {相关收藏标题2}                                      │ │
│ │    相关度：{内容相似}                                   │ │
│ └─────────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 📄 {相关收藏标题3}                                      │ │
│ │    相关度：{同一文件夹}                                 │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.4.4 交互规则

- 默认收起，不干扰复习主流程
- 懒加载：展开时才请求数据
- 点击跳转到书签详情页（新标签页打开）
- 记录点击行为用于后续优化

### 5.1 现有 API 修改

### 5.2 新增 API

| API                       | 方法 | 说明             |
| ------------------------- | ---- | ---------------- |
| `/api/brain-sync/related` | GET  | 获取相关书签推荐 |

**请求参数**：

```typescript
{
  bookmarkId: number; // 当前复习卡片对应的书签 ID
}
```

**响应格式**：

```typescript
{
  relatedBookmarks: {
    id: number;
    title: string;
    relevanceReason: string; // "共同标签：React" | "内容相似" | "同一文件夹"
    similarity: number; // 0-1
  }
  [];
}
```

## 6. 兼容性处理

### 6.1 旧卡片兼容

对于已存在的旧卡片（无 question_depth 等新字段）：

- 默认 `question_depth = 'understand'`
- 默认 `thinking_hint = null`（不显示思考提示）
- 默认 `key_points = [answer]`（用原答案作为要点）

### 6.2 渐进式迁移

- 旧卡片继续正常复习
- 新生成的卡片使用新结构
- 不批量迁移旧数据

| 风险                     | 影响             | 缓解措施                     |
