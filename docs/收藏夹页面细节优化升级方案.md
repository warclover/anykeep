# 收藏夹页面 UI/UX 细节优化升级方案

> 版本：v1.0
> 日期：2024-12-19
> 基于：交互体验升级方案 Phase 1-2 已实施
> 状态：待审核

---

## 一、方案概述

### 1.1 升级目标

在保持现有功能和布局不变的前提下，通过**50+ 处细节打磨**，将收藏夹页面的交互体验从「流畅」提升到「愉悦」。

### 1.2 设计理念

| 原则       | 说明                                     |
| ---------- | ---------------------------------------- |
| **一致性** | 所有相同类型的交互保持统一的反馈模式     |
| **预期性** | 用户操作前能预判结果，操作后立即获得反馈 |
| **渐进性** | 动画平滑渐进，不突兀、不跳跃             |
| **可逆性** | 所有状态变化都有清晰的恢复路径           |

### 1.3 改动范围

```
收藏夹页面组件结构：

folders-page-client.tsx      ← 双栏布局主组件
├── folder-nav-panel.tsx     ← 左侧导航面板 (12 处优化)
├── folder-content-area.tsx  ← 右侧内容区域 (15 处优化)
├── folder-card.tsx          ← 文件夹卡片 (18 处优化)
├── folder-action-menu.tsx   ← 操作菜单 (8 处优化)
└── dialogs/                 ← 对话框组件 (7 处优化)
    ├── create-folder-dialog.tsx
    ├── rename-folder-dialog.tsx
    ├── merge-folder-dialog.tsx
    └── delete-folder-dialog.tsx
```

## 二、导航面板优化 (FolderNavPanel)

### 2.1 滚动行为优化

**问题**：ScrollArea 滚动时无视觉反馈，用户不确定是否有更多内容。

**改进**：

```tsx
// folder-nav-panel.tsx - ScrollArea 增强

// 方案 A：顶部/底部渐变遮罩
<ScrollArea className="flex-1 relative">
  {/* 顶部渐变 - 有内容被遮挡时显示 */}
  <div
    className="sticky top-0 h-4 bg-gradient-to-b from-gray-50 to-transparent
    dark:from-gray-900 pointer-events-none z-10 opacity-0
    data-[scrolled=true]:opacity-100 transition-opacity duration-200"
  />

  <div className="p-2 space-y-1">{/* 导航内容 */}</div>

  {/* 底部渐变 - 有更多内容时显示 */}
  <div
    className="sticky bottom-0 h-4 bg-gradient-to-t from-gray-50 to-transparent
    dark:from-gray-900 pointer-events-none z-10"
  />
</ScrollArea>
```

**预期效果**：用户滚动时，渐变遮罩提示还有更多内容。

### 2.2 分组展开/折叠动画

**问题**：Collapsible 展开折叠过于生硬，缺乏弹性。

**改进**：

```tsx
// folder-nav-panel.tsx - GroupHeader 组件

  onClick={onToggle}
  className="flex-shrink-0 p-0.5 rounded hover:bg-gray-200 dark:hover:bg-gray-700

  data-[state=closed]:animate-collapsible-up">
```

**globals.css 新增动画**：

```css
/* 折叠面板动画 */
@keyframes collapsible-down {
  from {
    height: 0;
    opacity: 0;
  }
  to {
    height: var(--radix-collapsible-content-height);

  }
}
@keyframes collapsible-up {

    height: var(--radix-collapsible-content-height);

    height: 0;
    opacity: 0;

.animate-collapsible-down {
  animation: collapsible-down 200ms ease-out;
}
.animate-collapsible-up {
  animation: collapsible-up 150ms ease-out;
}
```

## 八、性能考量

### 8.1 动画性能优化

所有动画均遵循以下原则：

| 原则                         | 说明                   |
| ---------------------------- | ---------------------- |
| **仅使用 transform/opacity** | 避免触发重排（reflow） |
| **使用 will-change 谨慎**    | 仅在必要元素上使用     |
| **动画时长 ≤ 300ms**         | 避免用户等待感         |
| **支持 reduced-motion**      | 尊重用户偏好           |

### 8.2 CSS 变量化

所有时长和缓动函数使用 CSS 变量，便于统一调整：

```css
:root {
  /* 已在 Phase 1 定义 */
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
  --duration-fast: 100ms;
  --duration-normal: 150ms;
  --duration-slow: 200ms;
}
```
