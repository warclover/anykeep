# 微信公众号文章完整快照技术方案

> 调研日期：2025-12-21
> 调研目标：分析 YouMind 公众号快照功能实现原理，提供 AnyKeep 可用的技术方案

---

## 1. YouMind 产品分析

### 产品背景

YouMind 由前语雀创始人玉伯创建，是一款 AI 驱动的内容创作工具，通过 Chrome 浏览器插件实现网页内容的「Snip」收藏功能。

### YouMind 的技术推测（基于浏览器插件特性）

| 技术点       | 实现方式                                                             |
| ------------ | -------------------------------------------------------------------- |
| **内容获取** | Chrome Extension 在当前页面 DOM 中直接提取 `#js_content` 内容        |
| **图片处理** | 浏览器插件具有**同源上下文**，可直接访问已加载的图片，无需绕过防盗链 |
| **样式保存** | 提取行内样式 + computed styles，保留排版                             |
| **存储方式** | 将内容上传到 YouMind 云端服务器，图片下载后重新托管                  |

### 核心优势

浏览器插件在微信公众号页面运行时，图片已经正常加载（有正确的 Referer），插件可以直接获取图片的 `blob:` 或 `base64` 数据，**无需处理防盗链**。

---

## 2. 微信公众号图片防盗链机制

### 原理

微信图片服务器（`mmbiz.qpic.cn`）检查请求头中的 `Referer` 字段，如果不是来自微信域名，则返回「此图片来自微信公众平台，未经允许不可引用」的占位图。

### 绕过方案对比

| 方案                 | 原理                                           | 优点               | 缺点                           |
| -------------------- | ---------------------------------------------- | ------------------ | ------------------------------ |
| **① meta 标签**      | `<meta name="referrer" content="no-referrer">` | 最简单，一行代码   | 影响全局 Referer，破坏统计/SEO |
| **② Nginx 反向代理** | 服务端请求时移除 Referer                       | 稳定可控           | 需要自建服务器，有流量成本     |
| **③ 图片下载到本地** | 服务端用空 Referer 下载图片保存                | 完全可控，离线可用 | 需要存储空间                   |
| **④ 第三方代理**     | 使用 `wximg.cccyun.cc` 等代理                  | 无需自建           | 依赖第三方，不稳定             |
| **⑤ 浏览器插件**     | 直接获取已加载的图片数据                       | 无需处理防盗链     | 需要用户安装插件               |

### 推荐方案

对于 AnyKeep 这类收藏应用，建议采用 **方案③ 图片下载到本地** + **云存储（Supabase Storage）**，这样可以：

- 永久保存，不受微信删帖影响
- 完全离线可访问
- 无外部依赖

## 3. 技术实现方案

### 方案 A：服务端爬取（推荐）

**架构**：

```
用户提交 URL → Next.js API → 抓取文章内容 → 下载图片 → 存储到 Supabase
```

**核心代码示例**（Node.js/TypeScript）：

```typescript
// src/lib/wechat-article/crawler.ts
import * as cheerio from "cheerio";

interface WechatArticle {
  title: string;
  author: string;
  content: string;
  publishTime: string;
  images: { originalUrl: string; localPath: string }[];
}

export async function crawlWechatArticle(url: string): Promise<WechatArticle> {
  // 1. 获取文章 HTML（无需特殊 header，公众号文章 URL 公开可访问）
  const response = await fetch(url, {
    headers: {
      "User-Agent":
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    },
  });
  const html = await response.text();
  const $ = cheerio.load(html);

  // 2. 提取基本信息
  const title = $("#activity-name").text().trim();
  const author = $("#js_name").text().trim();
  const publishTime =
    $("#publish_time").text().trim() ||
    $('meta[property="article:published_time"]').attr("content") ||
    "";

  // 3. 提取正文内容（包含 HTML 结构和样式）
  const contentEl = $("#js_content");

  // 4. 处理图片（微信使用 data-src 懒加载）
  const images: { originalUrl: string; localPath: string }[] = [];
  contentEl.find("img").each((i, el) => {
    const $img = $(el);
    const dataSrc = $img.attr("data-src") || $img.attr("src");
    if (dataSrc && dataSrc.includes("mmbiz.qpic.cn")) {
      images.push({ originalUrl: dataSrc, localPath: "" });
      // 替换为占位符，后续下载后替换
      $img.attr("data-local-index", String(i));
    }
  });

  return {
    title,
    author,
    content: contentEl.html() || "",
    publishTime,
    images,
  };
}

// 下载图片（关键：不发送 Referer）
export async function downloadWechatImage(imageUrl: string): Promise<Buffer> {
  const response = await fetch(imageUrl, {
    headers: {
      "User-Agent":
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
      // 关键：不设置 Referer，或设置为空
      Referer: "",
    },
  });

  if (!response.ok) {
    throw new Error(`Failed to download image: ${response.status}`);
  }

  return Buffer.from(await response.arrayBuffer());
}
```

**图片存储到 Supabase**：

```typescript
// src/lib/wechat-article/image-storage.ts
import { createClient } from "@supabase/supabase-js";

export async function uploadImageToSupabase(
  imageBuffer: Buffer,
  fileName: string,
): Promise<string> {
  const supabase = createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.SUPABASE_SERVICE_ROLE_KEY!,
  );

  const { data, error } = await supabase.storage
    .from("article-images")
    .upload(`wechat/${fileName}`, imageBuffer, {
      contentType: "image/jpeg",
      upsert: true,
    });

  if (error) throw error;

  const { data: publicUrl } = supabase.storage
    .from("article-images")
    .getPublicUrl(`wechat/${fileName}`);

  return publicUrl.publicUrl;
}
```

### 方案 B：浏览器插件方案（类似 YouMind）

如果需要实现类似 YouMind 的完美快照效果，浏览器插件是最佳选择：

**Chrome Extension manifest.json**：

```json
{
  "manifest_version": 3,
  "name": "AnyKeep Article Saver",
  "permissions": ["activeTab", "scripting"],
  "host_permissions": ["https://mp.weixin.qq.com/*"],
  "content_scripts": [
    {
      "matches": ["https://mp.weixin.qq.com/*"],
      "js": ["content.js"]
    }
  ]
}
```

**content.js（内容脚本）**：

```javascript
// 在微信公众号页面中运行，可直接访问 DOM
async function captureArticle() {
  const article = {
    title: document.querySelector("#activity-name")?.textContent?.trim(),
    author: document.querySelector("#js_name")?.textContent?.trim(),
    content: document.querySelector("#js_content")?.innerHTML,
    images: [],
  };

  // 获取所有图片并转换为 base64
  const images = document.querySelectorAll("#js_content img");
  for (const img of images) {
    if (img.complete && img.naturalWidth > 0) {
      // 图片已加载，可以直接获取
      const canvas = document.createElement("canvas");
      canvas.width = img.naturalWidth;
      canvas.height = img.naturalHeight;
      const ctx = canvas.getContext("2d");
      ctx.drawImage(img, 0, 0);
      const base64 = canvas.toDataURL("image/jpeg", 0.9);
      article.images.push({
        originalSrc: img.dataset.src || img.src,
        base64: base64,
      });
    }
  }

  // 发送到后端 API
  await fetch("https://your-api.com/api/save-article", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(article),
  });
}
```

## 5. AnyKeep 集成建议

基于当前项目架构（Next.js + Supabase），建议分阶段实现：

### Phase 1：基础抓取

1. 创建 `src/lib/wechat-article/` 模块
2. 实现 URL 解析 + 内容提取
3. 图片下载 + Supabase Storage 存储
4. 内容 HTML 清洗 + 样式保留

### Phase 2：增强功能

1. 处理微信懒加载图片（需等待加载或解析 `data-src`）
2. 视频/音频内容处理
3. 原创标识、阅读原文链接保留
4. 评论区抓取（需要特殊处理）

### Phase 3：浏览器插件（可选）

1. 开发 Chrome Extension
2. 实现「一键保存」功能
3. 完美保留原始样式和图片
