# 智能列表菜单性能优化方案

> 创建日期：2025-12-21
> 更新日期：2025-12-21
> 状态：**Phase 1 & 2 已完成**
> 选定方案：D（混合策略）

## 问题分析

**当前痛点**：

1. 每次渲染菜单都要查询 7+ 个智能列表的 count
2. 部分查询条件复杂（如"最近一周"需要日期过滤）
3. 数据量大时查询延迟明显
4. 阻塞菜单渲染，影响用户体验

### Phase 1: 前端 SWR 缓存 + localStorage ✅ 已完成

**实现文件**：

- `src/lib/smart-list/cache.ts` - 缓存工具函数
- `src/hooks/data/use-smart-lists.ts` (v10.1.0) - 集成缓存
- `src/components/smart-list/smart-list-section.tsx` (v10.2.3) - UI 集成

**缓存配置**：

- 缓存新鲜期：**60秒** (CACHE_STALE_TIME)
- 最大有效期：**24小时** (CACHE_MAX_AGE)
- 存储位置：localStorage
- 存储键名：`anykeep_smart_lists_cache`
- 策略：stale-while-revalidate

**核心实现**：

```typescript
// src/lib/smart-list/cache.ts
export const CACHE_STALE_TIME = 60 * 1000; // 60秒内认为数据新鲜
export const CACHE_MAX_AGE = 24 * 60 * 60 * 1000; // 24小时后强制刷新

export function getSmartListCache(userId?: string): SmartListClient[] | null;
export function setSmartListCache(
  data: SmartListClient[],
  userId?: string,
): void;
export function isCacheFresh(): boolean;

// src/hooks/data/use-smart-lists.ts (v10.1.0)
// 首次挂载时读取缓存
const initialCacheRef = useRef<SmartListClient[] | null>(null);
if (!hasMountedRef.current && typeof window !== "undefined") {
  initialCacheRef.current = getSmartListCache();
}

// SWR 配置：使用缓存作为 fallbackData
const { data, error, isLoading, mutate } = useSWR(url, fetcher, {
  fallbackData: initialCacheRef.current ?? undefined,
  revalidateOnMount: !cacheFresh, // 缓存新鲜时跳过首次验证
});

// 数据更新后同步到 localStorage
useEffect(() => {
  if (data && data.length > 0) {
    setSmartListCache(data);
  }
}, [data]);
```

### Phase 2: 批量查询优化 ✅ 已完成

**实现说明**：
由于 `SmartListClient` 类型已包含 `bookmarkCount` 字段，智能列表数据与统计数字在**同一 API 请求**中返回，无需额外的批量统计 API。

**优化效果**：

- 单次 `GET /api/smart-lists` 请求返回所有数据 + 计数
- 结合 Phase 1 的 localStorage 缓存，首次渲染 **0ms 延迟**
- 后台静默刷新，用户无感知

**数据库表设计**：

```sql
-- 智能列表统计缓存表
CREATE TABLE smart_list_stats (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  list_type TEXT NOT NULL,  -- 'recent_week', 'high_value', 'unread', etc.
  count INTEGER NOT NULL DEFAULT 0,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),

  UNIQUE(user_id, list_type)
);

-- 索引
CREATE INDEX idx_smart_list_stats_user ON smart_list_stats(user_id);

-- RLS
ALTER TABLE smart_list_stats ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own stats" ON smart_list_stats
  FOR SELECT USING (auth.uid() = user_id);
```

**更新策略**：

- 定时任务批量刷新（每 5-10 分钟）
- 避免触发器开销影响主流程

## UI 层：渐进式渲染

```tsx
// 智能列表菜单项
function SmartListMenuItem({ type, label, icon }) {
  const { stats, isStale } = useSmartListStats();
  const count = stats?.[type];

  return (
    <div className="flex items-center justify-between">
      <span>
        {icon} {label}
      </span>

      {/* 数字显示：有缓存立即显示，否则显示占位符 */}
      <span
        className={cn(
          "text-sm tabular-nums",
          isStale && "opacity-50", // 过期数据半透明
        )}
      >
        {count !== undefined ? (
          count > 999 ? (
            "999+"
          ) : (
            count
          )
        ) : (
          <span className="w-6 h-4 bg-gray-200 rounded animate-pulse" />
        )}
      </span>
    </div>
  );
}
```
