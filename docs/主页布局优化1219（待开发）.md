## 二、核心优化建议

### 1. 内容区域布局优化 ⭐ 优先级：高

**问题**：当前快速添加区域 `max-w-2xl` 限制了宽度，与下方网格不协调

**建议方案**：

```
当前布局:
┌─────────────────────────────────────────┐
│ [快速添加 max-w-2xl] [按钮] [筛选]      │  ← 左对齐，宽度受限
├─────────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐            │  ← 网格铺满
│ │卡片│ │卡片│ │卡片│ │卡片│            │
│ └────┘ └────┘ └────┘ └────┘            │
└─────────────────────────────────────────┘

优化后布局:
┌─────────────────────────────────────────┐
│ [快速添加 flex-1] [筛选按钮组]          │  ← 全宽自适应
├─────────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐            │
│ │卡片│ │卡片│ │卡片│ │卡片│            │
│ └────┘ └────┘ └────┘ └────┘            │
└─────────────────────────────────────────┘
```

---

### 2. 侧边栏与内容区协同优化 ⭐ 优先级：高

**问题**：侧边栏折叠/展开时内容区有明显的 margin 过渡跳动

**建议方案**：

- 将 `margin-left` 过渡改为 `transform: translateX()`
- 使用 CSS Grid 替代 Flexbox 实现侧边栏布局
- 侧边栏折叠时内容区平滑扩展

```css
/* 建议的 Grid 布局 */
.app-layout {
  display: grid;
  grid-template-columns: var(--sidebar-width) 1fr;
  transition: grid-template-columns 200ms ease;
}

.app-layout.collapsed {
  --sidebar-width: 64px;
}

.app-layout.expanded {
  --sidebar-width: 280px;
}
```

### 4. 卡片网格间距优化 ⭐ 优先级：中

**问题**：`masonry.css` 中移动端使用 `column-gap` 瀑布流，桌面端使用 Grid，两者视觉间距不一致

**建议方案**：

```css
/* 统一间距变量 */
:root {
  --card-gap-mobile: 1rem;
  --card-gap-tablet: 1.25rem;
  --card-gap-desktop: 1.5rem;
}

/* 移动端和桌面端使用相同 gap 逻辑 */
.masonry-grid {
  gap: var(--card-gap-mobile);
}

@media (min-width: 768px) {
  .masonry-grid {
    gap: var(--card-gap-tablet);
  }
}
```

**相关文件**：`src/styles/masonry.css`

### 5. 内容区高度计算优化 ⭐ 优先级：中

**问题**：虚拟滚动高度使用硬编码 `calc(100vh - 280px)`，不够灵活

**建议方案**：

```typescript
// 使用 CSS 变量 + ResizeObserver 动态计算
const [contentHeight, setContentHeight] = useState<string>("100%");

useLayoutEffect(() => {
  const updateHeight = () => {
    const header = document.querySelector("[data-header]");
    const toolbar = document.querySelector("[data-toolbar]");
    const offset =
      (header?.clientHeight || 0) + (toolbar?.clientHeight || 0) + 32;
    setContentHeight(`calc(100vh - ${offset}px)`);
  };

  updateHeight();
  window.addEventListener("resize", updateHeight);
  return () => window.removeEventListener("resize", updateHeight);
}, []);
```

## 三、代码架构优化建议

### 6. HomePageClient 拆分 ⭐ 优先级：高

**问题**：`home-page-client.tsx` 860 行，职责过重

**建议拆分方案**：

```
home-page-client.tsx (860行)
    ↓ 拆分为
├── home-page-client.tsx (300行) - 主容器/状态协调
├── home-content-area.tsx (200行) - 内容渲染逻辑
├── home-banners.tsx (100行) - Banner 区域
├── home-loading-states.tsx (100行) - 加载/错误/空状态
└── hooks/
    ├── use-home-bookmarks.ts (150行) - 书签数据管理
    └── use-home-scroll.ts (50行) - 滚动容器管理
```

**相关文件**：`src/components/home/home-page-client.tsx`

**问题**：三个虚拟滚动组件（Grid/List/BrowserList）有重复逻辑

```typescript
interface VirtualScrollConfig {

  itemHeight: number;
  overscan: number;

const VirtualBookmarkContainer =
  createVirtualScroll<BookmarkWithFolder>(config);
```

## 四、新增功能建议

### 8. 添加「首屏快照」机制 ⭐ 优先级：中

**价值**：用户打开应用时立即看到上次的内容，而非骨架屏

```typescript
// 使用 IndexedDB 缓存首屏数据
const useFirstScreenCache = () => {
  const cacheKey = "home-first-screen";

  // 页面加载时读取缓存
  const cachedBookmarks = useMemo(() => readCache(cacheKey), []);

  // 数据更新后写入缓存
  useEffect(() => {
    if (bookmarks?.length) {
      writeCache(cacheKey, bookmarks.slice(0, 20));
    }
  }, [bookmarks]);

  return cachedBookmarks;
};
```
