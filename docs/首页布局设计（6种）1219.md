# AnyKeep 首页布局重构设计方案

> 文档版本：v1.0
> 创建日期：2025-12-19
> 状态：待审核

---

## 产品定位回顾

> **AnyKeep = AI 知识管家**
> 核心价值：**"收藏不再遗忘，知识自动整理"**
> 差异化：智能分类 + 防遗忘系统 + 意图式检索

### 目标用户

- 知识工作者、内容创作者、学习者

### 核心痛点

- 收藏后找不到
- 跨平台碎片化
- 链接失效

### 核心价值

- 无摩擦收集
- 意图式检索（语义搜索）
- 防遗忘机制
- AI 自动整理

---

## 方案 1：搜索优先布局（Search-First）

### 设计理念

既然"意图式检索"是核心价值，首页应该以搜索为绝对中心

### 布局示意

```
┌─────────────────────────────────────────────────────────────────┐
│ [Logo]                                    [通知] [头像]         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                                                                 │
│                        🔍 AnyKeep                               │
│         ┌─────────────────────────────────────────┐            │
│         │ 搜索你的记忆... "上周那个咖啡教程"      │            │
│         └─────────────────────────────────────────┘            │
│                                                                 │
│         [📱 微信] [📺 B站] [📕 小红书] [🌐 浏览器] [全部]      │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  最近收藏                                    查看全部 →         │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                 │
│  │ 缩略 │ │ 缩略 │ │ 缩略 │ │ 缩略 │ │ 缩略 │  ← 横向滚动     │
│  │  图  │ │  图  │ │  图  │ │  图  │ │  图  │                 │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘                 │
├─────────────────────────────────────────────────────────────────┤
│  💡 别忘了这些（7天未看）                                       │
│  ┌──────┐ ┌──────┐ ┌──────┐                                    │
│  │      │ │      │ │      │                                    │
│  └──────┘ └──────┘ └──────┘                                    │
├─────────────────────────────────────────────────────────────────┤
│  📂 智能分类                                                    │
│  [学习资料 23] [工作参考 15] [生活灵感 8] [待整理 5]           │
└─────────────────────────────────────────────────────────────────┘
```

### 核心特点

- 首屏 60% 空间留给搜索框
- 平台快捷筛选按钮
- 最近收藏横向滑动预览
- 防遗忘提醒区域
- 智能分类标签云

### 优缺点分析

| 优点                          | 缺点                    |
| ----------------------------- | ----------------------- |
| ✅ 强化"意图式检索"核心价值   | ⚠️ 首屏信息密度低       |
| ✅ 用户聚焦搜索，降低认知负担 | ⚠️ 需要用户主动搜索     |
| ✅ 简洁、现代、有记忆点       | ⚠️ 对"浏览型"用户不友好 |

### 适合场景

明确知道要找什么的用户

## 方案 2：时间线布局（Timeline）

### 设计理念

收藏是一种"记忆外包"，按时间线展示帮助用户回溯记忆

### 布局示意

```
┌─────────────────────────────────────────────────────────────────┐
│ [Logo] [🔍搜索]                           [+添加] [头像]        │
├────────────┬────────────────────────────────────────────────────┤
│            │                                                    │
│  📅 时间线 │  ═══════════════════════════════════════════════  │
│            │                                                    │
│  [今天]    │  ● 今天 12月19日                                   │
│  [昨天]    │  ├─ 10:30 ┌─────────────────────────────────┐     │
│  [本周]    │  │        │ 📺 Next.js 15 新特性解析        │     │
│  [本月]    │  │        │ B站 · 前端技术 · AI摘要...      │     │
│  [更早]    │  │        └─────────────────────────────────┘     │
│            │  │                                                 │
│  ────────  │  ├─ 09:15 ┌─────────────────────────────────┐     │
│            │  │        │ 📕 咖啡拉花入门技巧              │     │
│  📂 分类   │  │        │ 小红书 · 生活技能 · 3张图片     │     │
│  [全部]    │  │        └─────────────────────────────────┘     │
│  [学习]    │  │                                                 │
│  [工作]    │  ● 昨天 12月18日                                   │
│  [生活]    │  ├─ 22:00 ┌─────────────────────────────────┐     │
│  [待整理]  │  │        │ 📱 微信公众号文章...              │     │
│            │           └─────────────────────────────────┘     │
│  ────────  │                                                    │
│            │  ● 12月15日 周日                                   │
│  📊 统计   │  ├─ ...                                           │
│  本周 23条 │                                                    │
│  本月 89条 │  ═══════════════════════════════════════════════  │
│            │                                                    │
└────────────┴────────────────────────────────────────────────────┘
```

### 核心特点

- 左侧固定导航（时间快捷跳转 + 分类 + 统计）
- 右侧时间线流式展示
- 每条收藏显示时间戳
- 日期分组，强调"记忆时刻"

### 优缺点分析

| 优点                      | 缺点                  |
| ------------------------- | --------------------- |
| ✅ 帮助用户按时间回忆     | ⚠️ 信息密度较低       |
| ✅ 强调"收藏历程"情感价值 | ⚠️ 分类浏览效率低     |
| ✅ 符合"记忆外包"定位     | ⚠️ 大量收藏时滚动疲劳 |

### 适合场景

回忆型用户，"我上周看过一个视频..."

## 方案 3：仪表盘布局（Dashboard）

### 设计理念

首页是"知识管家"的控制中心，展示洞察、待办、统计

### 布局示意

```

│  │                 │ │                 │ │                 │   │
│  │    23 条        │ │    5 条         │ │    12 条        │   │
│  │   ↑ 15%        │ │  需要分类       │ │  7天未查看      │   │

│                                                                 │
├──────────────────────────────────┬──────────────────────────────┤
│  📥 最近添加                     │  💡 AI 洞察                   │
│  ┌────────────────────────────┐  │  ┌────────────────────────┐  │
│  │ Next.js 15 新特性     10:30│  │  │ 你最近对「前端技术」   │  │

│  ├────────────────────────────┤  │  │                        │  │

### 核心特点

- 数据驱动，突出"管家"角色

### 优缺点分析

| 优点                      | 缺点                    |
| ------------------------- | ----------------------- |
| ✅ 信息全面，一目了然     | ⚠️ 初期内容少时显得空洞 |
| ✅ 突出"智能管家"定位     | ⚠️ 视觉复杂度高         |
| ✅ 引导用户处理待整理内容 | ⚠️ 移动端适配困难       |

### 适合场景

重度用户、数据控、管理型用户

### 布局示意

```

│  │  咖啡拉花技巧       │   │  标签：[前端] [Next.js] [教程]     │

│  ┌────────────────────┐   │  本视频介绍了 Next.js 15 的三大    │

- 左侧紧凑列表（标题 + 来源 + 时间）
- 右侧详情面板（摘要 + 预览 + 操作）
- 键盘快捷键导航（↑↓ 切换，Enter 打开）
- 类似邮件客户端的高效体验

### 优缺点分析

| 优点                      | 缺点                    |
| ------------------------- | ----------------------- |
| ✅ 浏览效率极高           | ⚠️ 移动端无法使用此布局 |
| ✅ 无需打开新页面即可预览 | ⚠️ 视觉上较"工具化"     |
| ✅ 专业用户友好           | ⚠️ 学习曲线略高         |

### 适合场景

效率控、键盘党、专业用户

│  │ 15 特性  │   │ 新特性   │    │ 模板     │    │          │  │
│  │ B站      │   │ 掘金     │    │ 微信     │    │ 小红书   │  │

### 核心特点

- 多列看板，每列是一个分类/状态
- 卡片可拖拽移动
- 支持自定义列
- 直观的知识结构

### 优缺点分析

| 优点                  | 缺点                    |
| --------------------- | ----------------------- |
| ✅ 知识结构可视化     | ⚠️ 大量收藏时列会很长   |
| ✅ 拖拽整理直观       | ⚠️ 横向滚动在小屏不友好 |
| ✅ 符合"整理"心智模型 | ⚠️ 开发复杂度高         |

### 适合场景

整理控、视觉型用户、项目管理习惯者

## 推荐方案

### 首选：方案 3（仪表盘）+ 方案 1（搜索优先）混合

**理由**：

1. 仪表盘体现"管家"角色 - 统计、洞察、待处理
2. 搜索框保持突出位置 - 强化"意图式检索"
3. 防遗忘区域自然融入 - 核心差异化
4. 符合知识工作者心智模型

### 备选：方案 2（时间线）

**理由**：

1. 与竞品差异化明显
2. 强调"收藏历程"情感价值
3. 符合"记忆外包"定位
