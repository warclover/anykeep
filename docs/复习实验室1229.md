## 一、功能概述

### 1.1 核心价值主张

**问题**: 用户收藏了大量优质内容，但 60%+ 的收藏从未被重新访问，沦为「数字囤积症」。

**解决方案**: AI 不仅生成摘要，还根据内容自动生成 3-5 个关键问题 (Flashcards)。通过间隔重复算法，在收藏后的第 1、3、7 天以「快闪提问」方式帮助用户主动回忆，实现知识内化。

**价值**: 变「被动存储」为「主动吸收」，真正解决「收藏家」的知识焦虑。

### 1.2 设计原则

| 原则         | 说明                             |
| ------------ | -------------------------------- |
| **完全解耦** | 独立功能模块，用户可在设置中开关 |
| **零接管**   | 符合 AnyKeep「免打扰」设计初衷   |
| **按需触发** | 仅对「值得复读」标签的收藏启用   |
| **智能聚合** | 每周上限控制，避免复习疲劳       |

### 1.3 功能边界

**包含**:

- Flashcard 自动生成（3-5 个问答对）
- 1-3-7 天间隔重复调度
- 侧边栏「今日复习」入口
- 系统通知静默提醒
- 已内化/模糊/遗忘 三级反馈
- AI Agent 对话式复习
- 用户偏好配置

**不包含（v1.0）**:

- 语音交互复习
- 社交化复习打卡
- 跨设备同步提醒（依赖移动端实现）

## 二、触发条件与筛选规则

### 2.1 核心触发条件

> **关键决策**: 仅对用户主动标注「值得复读」标签的收藏启用复习功能

```
启用复习 = 用户开启功能 AND 书签包含「值得复读」标签
```

**设计理由**:

1. 尊重用户意图：用户主动标记表示「这个值得记住」
2. 避免无效复习：新闻、工具网站等不需要复习
3. 控制复习量：自然筛选出高价值内容
4. 降低 LLM 成本：仅对标记内容生成 Flashcards

### 2.2 标签识别规则

系统识别以下标签变体作为触发条件：

```typescript
const REVIEW_TRIGGER_TAGS = [
  "值得复读",
  "值得复习",
  "需要记住",
  "重要知识",
  "学习笔记",
  "worth-review",
  "to-memorize",
  "important",
];
```

### 2.3 Flashcard 生成时机

```
触发时机: 书签被添加「值得复读」标签时（静默后台生成）

流程:
1. 用户为书签添加「值得复读」标签
2. 系统检测到标签变更事件
3. 后台任务队列添加 Flashcard 生成任务
4. LLM 分析书签内容，生成 3-5 个问答对
5. 设置初始复习时间（D1 = 添加标签后 24 小时）
6. 静默完成，不打扰用户
```

## 三、间隔重复算法

### 3.1 基础调度：1-3-7 节奏

| 阶段 | 时间点          | 目的         | 说明           |
| ---- | --------------- | ------------ | -------------- |
| D1   | 标签添加后 24h  | 即时记忆巩固 | 短期记忆转中期 |
| D3   | 标签添加后 72h  | 中期记忆转存 | 强化神经连接   |
| D7   | 标签添加后 168h | 长期记忆锁定 | 进入长期存储   |
| D14+ | 根据反馈动态    | 持续巩固     | SM-2 算法接管  |

### 3.2 SM-2 算法实现

```typescript
/**
 * SuperMemo SM-2 算法
 * 根据用户反馈动态调整复习间隔
 */
export class SM2Algorithm {
  static calculate(params: {
    quality: number; // 回忆质量 0-5
    repetitions: number; // 连续正确次数
    easeFactor: number; // 难度因子
    interval: number; // 当前间隔（天）
  }): {
    interval: number;
    repetitions: number;
    easeFactor: number;
  } {
    const { quality, repetitions, easeFactor, interval } = params;

    // 质量 < 3 表示遗忘，重置
    if (quality < 3) {
      return {
        interval: 1,
        repetitions: 0,
        easeFactor: Math.max(1.3, easeFactor - 0.2),
      };
    }

    // 计算新的难度因子
    const newEaseFactor = Math.max(
      1.3,
      easeFactor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)),
    );

    // 计算新间隔
    let newInterval: number;
    if (repetitions === 0) {
      newInterval = 1;
    } else if (repetitions === 1) {
      newInterval = 3;
    } else if (repetitions === 2) {
      newInterval = 7;
    } else {
      newInterval = Math.round(interval * newEaseFactor);
    }

    // 限制最大间隔为 90 天
    newInterval = Math.min(newInterval, 90);

    return {
      interval: newInterval,
      repetitions: repetitions + 1,
      easeFactor: newEaseFactor,
    };
  }
}

// 用户反馈映射
const RESPONSE_TO_QUALITY = {
  mastered: 5, // 完美回忆
  fuzzy: 3, // 勉强回忆
  forgotten: 0, // 完全遗忘
};
```

### 3.3 容量控制与优先级

> **关键决策**: 每周复习上限 10 条（可配置），超出部分自动顺延

**优先级计算公式**:

```typescript
priority = (reviewValue * 0.4) + (forgettingRisk * 0.4) + (overdueDays * 0.2)

其中:
- reviewValue: 复习价值（基于内容深度、用户交互历史）
- forgettingRisk: 遗忘风险（基于 SM-2 算法预测）
- overdueDays: 逾期天数（超期越久优先级越高）
```

**顺延规则**:

1. 每周一计算本周复习队列（最多 10 条）
2. 超出部分按优先级排序进入「待复习池」
3. 用户完成本周任务后，可主动拉取更多
4. 下周自动补充新的待复习内容

### 4.2 反馈机制

| 反馈选项  | 含义               | 系统响应                         |
| --------- | ------------------ | -------------------------------- |
| ✅ 已内化 | 完全记得，无需提示 | 标记 `mastered`，移出复习队列    |
| 🤔 模糊   | 记得一点，但不完整 | 保持 `learning`，缩短下次间隔    |
| ❌ 遗忘   | 完全不记得         | 重置为 `pending`，从 D1 重新开始 |

```sql
-- 文件: supabase/migrations/2025XXXX_add_active_recall_tables.sql

-- ============================================
-- 1. Flashcards 表（核心）
-- ============================================
CREATE TABLE flashcards (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  bookmark_id BIGINT NOT NULL REFERENCES bookmarks(id) ON DELETE CASCADE,

  -- 问答内容
  question TEXT NOT NULL,
  answer TEXT NOT NULL,
  source_paragraph TEXT,  -- 原文核心段落引用

  -- 记忆状态
  status VARCHAR(20) DEFAULT 'pending',  -- pending | learning | mastered
  ease_factor DECIMAL(3,2) DEFAULT 2.5,  -- SM-2 难度因子 (1.3-2.5)
  interval_days INT DEFAULT 1,           -- 当前间隔天数
  repetitions INT DEFAULT 0,             -- 连续正确复习次数

  -- 调度时间
  next_review_at TIMESTAMPTZ,            -- 下次复习时间
  last_reviewed_at TIMESTAMPTZ,          -- 上次复习时间

  -- 元数据
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now(),

  -- 约束
  CONSTRAINT flashcards_unique UNIQUE (user_id, bookmark_id, question)
);

-- 索引优化
CREATE INDEX idx_flashcards_next_review
  ON flashcards(user_id, next_review_at)
  WHERE status != 'mastered';
CREATE INDEX idx_flashcards_bookmark ON flashcards(bookmark_id);
CREATE INDEX idx_flashcards_status ON flashcards(user_id, status);

-- ============================================
-- 2. 复习会话记录表
-- ============================================
CREATE TABLE review_sessions (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  flashcard_id BIGINT NOT NULL REFERENCES flashcards(id) ON DELETE CASCADE,

  -- 用户反馈
  response VARCHAR(20) NOT NULL,  -- mastered | fuzzy | forgotten
  response_time_ms INT,           -- 思考时间（毫秒）

  -- 算法参数变化
  prev_interval INT,
  new_interval INT,
  prev_ease DECIMAL(3,2),
  new_ease DECIMAL(3,2),

  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_review_sessions_flashcard ON review_sessions(flashcard_id);
CREATE INDEX idx_review_sessions_user_time ON review_sessions(user_id, created_at DESC);

-- ============================================
-- 3. 复习偏好设置表
-- ============================================
CREATE TABLE review_preferences (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,

  -- 功能开关
  enabled BOOLEAN DEFAULT false,

  -- 时间偏好
  preferred_day VARCHAR(10) DEFAULT 'monday',  -- 每周复习日
  preferred_time TIME DEFAULT '09:00',
  timezone VARCHAR(50) DEFAULT 'Asia/Shanghai',

  -- 容量控制

  -- 筛选条件
  included_folder_ids BIGINT[],    -- 仅这些文件夹（空=全部）
  excluded_folder_ids BIGINT[],    -- 排除这些文件夹

  -- 通知偏好
  notification_channel VARCHAR(20) DEFAULT 'sidebar',  -- sidebar | push | both

  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- ============================================
-- 4. 每周复习队列快照表
-- ============================================

  completed_ids BIGINT[] DEFAULT '{}',  -- 已完成的 IDs

CREATE INDEX idx_weekly_queue_user_week ON weekly_review_queue(user_id, week_start DESC);
```

### 8.1 Edge Function: 每周队列生成器

```typescript
// 文件: supabase/functions/generate-weekly-review-queue/index.ts

/**
 * 每周一凌晨运行，为所有启用复习功能的用户生成本周复习队列
 * Cron: 0 0 * * 1 (每周一 00:00 UTC)
 */

serve(async (req) => {
  const supabase = createClient(/* ... */);

  // 1. 获取所有启用复习功能的用户
  const { data: users } = await supabase
    .from("review_preferences")
    .select("user_id, weekly_limit, included_folder_ids, excluded_folder_ids")
    .eq("enabled", true);

  const weekStart = getWeekStart(new Date());
  const results = [];

  for (const user of users || []) {
    // 2. 查询该用户待复习的 Flashcards（优先级排序）
    const flashcards = await queryPendingFlashcards(user.user_id, {
      limit: user.weekly_limit,
      includedFolders: user.included_folder_ids,
      excludedFolders: user.excluded_folder_ids,
    });

    if (flashcards.length === 0) continue;

    // 3. 创建本周队列快照
    await supabase.from("weekly_review_queue").upsert({
      user_id: user.user_id,
      week_start: weekStart,
      flashcard_ids: flashcards.map((f) => f.id),
      completed_ids: [],
    });

    results.push({
      userId: user.user_id,
      queueSize: flashcards.length,
    });
  }

  return new Response(
    JSON.stringify({
      success: true,
      generatedQueues: results.length,
      weekStart,
    }),
  );
});
```

### 8.2 Edge Function: 复习通知发送器

```typescript
// 文件: supabase/functions/send-review-notifications/index.ts

/**
 * 每小时运行，检查是否有用户到达复习时间
 * Cron: 0 * * * * (每小时整点)
 */

serve(async (req) => {
  const supabase = createClient(/* ... */);
  const now = new Date();
  const currentDay = getDayName(now); // monday, tuesday, ...

  // 1. 查询当前时段需要通知的用户
  const { data: users } = await supabase
    .from("review_preferences")
    .select("user_id, preferred_time, timezone, notification_channel")
    .eq("enabled", true)
    .eq("preferred_day", currentDay);

  const notified = [];

  for (const user of users || []) {
    // 2. 检查是否在用户的首选时间窗口
    const userLocalTime = toTimezone(now, user.timezone);
    const preferredHour = parseInt(user.preferred_time.split(":")[0]);

    if (userLocalTime.getHours() !== preferredHour) continue;

    // 3. 检查本周是否已通知过
    const alreadySent = await checkNotificationSent(
      user.user_id,
      getWeekStart(now),
    );
    if (alreadySent) continue;

    // 4. 获取本周待复习数量
    const { data: queue } = await supabase
      .from("weekly_review_queue")
      .select("flashcard_ids, completed_ids")
      .eq("user_id", user.user_id)
      .eq("week_start", getWeekStart(now))
      .single();

    const pendingCount =
      (queue?.flashcard_ids?.length || 0) - (queue?.completed_ids?.length || 0);
    if (pendingCount === 0) continue;

    // 5. 发送通知
    await supabase.from("messages").insert({
      user_id: user.user_id,
      type: "review_reminder",
      level: "normal",
      title: "🧠 本周知识同步",
      content: `你有 ${pendingCount} 个知识点等待复习，开始同步你的脑回路吧！`,
      metadata: { pendingCount, weekStart: getWeekStart(now) },
    });

    notified.push(user.user_id);
  }

  return new Response(
    JSON.stringify({
      success: true,
      notifiedCount: notified.length,
    }),
  );
});
```

### 8.3 标签变更监听器

```typescript
// 文件: src/lib/ai-agent/tools/active-recall/services/tag-change-listener.ts

/**
 * 监听书签标签变更，触发 Flashcard 生成
 * 集成到现有的书签更新 API
 */

export async function onBookmarkTagsChanged(
  bookmarkId: number,
  userId: string,
  oldTags: string[],
  newTags: string[],
): Promise<void> {
  // 检查是否新增了「值得复读」标签
  const triggerTags = REVIEW_TRIGGER_TAGS;
  const wasTriggered = oldTags.some((t) =>
    triggerTags.includes(t.toLowerCase()),
  );
  const isTriggered = newTags.some((t) =>
    triggerTags.includes(t.toLowerCase()),
  );

  if (!wasTriggered && isTriggered) {
    // 新增触发标签，添加到后台生成队列
    await addToFlashcardGenerationQueue(bookmarkId, userId);
  } else if (wasTriggered && !isTriggered) {
    // 移除触发标签，可选：是否保留已生成的 Flashcards
    // 当前策略：保留，但不再调度复习
    await pauseFlashcardReviews(bookmarkId, userId);
  }
}
```
