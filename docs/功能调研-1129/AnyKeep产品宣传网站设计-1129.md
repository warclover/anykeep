# AnyKeep 产品宣传网站设计文档

**文档日期**：2025-11-29  
**文档版本**：V1.0  
**适用产品**：AnyKeep 官方网站  
**目标**：产品宣传、用户获取、品牌建设

---

## 1. 网站定位与目标

### 1.1 核心目标

1. **传达产品价值**：清晰说明 AnyKeep 是什么、解决什么问题
2. **展示核心功能**：突出跨平台收藏、AI 能力、学习闭环等差异化优势
3. **引导用户注册**：降低试用门槛，引导用户注册并体验产品
4. **建立品牌信任**：通过专业设计、用户案例、技术说明建立信任感

### 1.2 目标用户

- **主要用户**：重度知识工作者、内容从业者、学习型用户
- **次要用户**：对信息管理有需求的普通用户

### 1.3 设计风格

- **现代简约**：干净、专业、不花哨
- **技术感**：体现 AI 能力和技术实力
- **知识感**：符合「知识管理」的调性
- **中文友好**：针对中文用户优化

### 10.2 组件库组织（Component Library）

#### 10.2.1 基础组件（Base Components）

**按钮组件（Button Component）**：

- **变体（Variants）**：
  - Type: Primary / Secondary / Text
  - Size: Large / Medium / Small
  - State: Default / Hover / Active / Disabled
- **属性（Properties）**：
  - Text: 可编辑文本
  - Icon: 可选图标（左侧/右侧）
- **自动布局（Auto Layout）**：
  - 方向：水平
  - 内边距：根据 Size 变体自动调整
  - 间距：图标与文字 8px

**卡片组件（Card Component）**：

- **变体**：
  - Type: Standard / Feature / Pricing / Use Case
  - Elevation: S / M / L
- **属性**：
  - Content: 可替换内容区域
  - Padding: 可调整内边距
- **自动布局**：
  - 方向：垂直
  - 内边距：24px（Standard），32px（Feature）

**输入框组件（Input Component）**：

- **变体**：
  - State: Default / Focus / Error / Disabled
  - Size: Medium / Large
- **属性**：
  - Placeholder: 可编辑占位符
  - Value: 可编辑值
  - Icon: 可选图标（左侧/右侧）

#### 10.2.2 复合组件（Composite Components）

**导航栏组件（Navigation Component）**：

- **变体**：
  - Device: Desktop / Mobile
- **属性**：
  - Logo: 可替换
  - Links: 可编辑链接数组
  - CTA Button: 可替换按钮

**Hero 区域组件（Hero Component）**：

- **变体**：
  - Layout: Left-Right / Center / Mobile
- **属性**：
  - Title: 可编辑
  - Subtitle: 可编辑
  - Primary CTA: 可替换按钮
  - Secondary CTA: 可替换按钮
  - Hero Image: 可替换图片

**功能卡片网格（Feature Grid Component）**：

- **变体**：
  - Columns: 1 / 2 / 3
- **属性**：
  - Cards: 可添加/删除卡片实例

### 10.3 自动布局（Auto Layout）设置

#### 10.3.1 常用自动布局配置

**水平布局（Horizontal）**：

- **方向**：Horizontal
- **对齐**：Center（垂直居中）
- **间距**：根据上下文（8px / 16px / 24px）
- **内边距**：根据组件类型

**垂直布局（Vertical）**：

- **方向**：Vertical
- **对齐**：Left（水平左对齐）
- **间距**：根据上下文
- **内边距**：根据组件类型

**响应式容器（Responsive Container）**：

- **宽度**：Fill container（填充父容器）
- **最小宽度**：320px（移动端）
- **最大宽度**：1280px（桌面端）
- **内边距**：24px（桌面端），16px（移动端）

### 10.4 响应式设计实现

#### 10.4.1 断点框架（Breakpoint Frames）

**创建断点框架**：

- **Mobile Frame**：375px × 812px（iPhone 标准）
- **Tablet Frame**：768px × 1024px（iPad 标准）
- **Desktop Frame**：1280px × 720px（标准桌面）

#### 10.4.2 响应式组件设置

**使用 Constraints**：

- **水平约束**：
  - Left：固定左边距
  - Right：固定右边距
  - Left & Right：左右拉伸
  - Center：水平居中
  - Scale：按比例缩放
- **垂直约束**：
  - Top：固定上边距
  - Bottom：固定下边距
  - Top & Bottom：上下拉伸
  - Center：垂直居中
  - Scale：按比例缩放

**示例：Hero 区域响应式**：

- **桌面端**：左右两列，各 50% 宽度
- **移动端**：垂直堆叠，每列 100% 宽度
- **实现方式**：使用 Auto Layout + Constraints
