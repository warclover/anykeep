# AnyKeep 功能精简方案

> **版本**: 1.0.0
> **日期**: 2025-02-25
> **目标**: 基于用户画像分析，精简低价值功能，聚焦核心体验

---

## 一、精简策略总览

### 精简原则

1. **用户核心诉求是「存」和「找」**，不是「知识管理」
2. **AI 应该是隐形助手**，而不是需要用户主动学习的功能
3. **功能越多，认知负担越重**，必须做减法
4. **保留核心能力，移除独立页面**，让 AI 自动路由

### 精简分类

| 分类            | 处理方式                      | 数量 |
| --------------- | ----------------------------- | ---- |
| 🔴 **完全移除** | 删除页面、组件、API、数据库表 | 8 个 |
| 🟡 **隐藏入口** | 保留底层实现，移除导航入口    | 4 个 |
| 🟢 **保留优化** | 保留功能，优化体验            | 5 个 |

### 4.3 Skills 精简 → 5 个核心能力

| 当前         | 精简后           |
| ------------ | ---------------- |
