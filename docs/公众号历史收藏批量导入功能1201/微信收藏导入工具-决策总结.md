# 微信收藏导入工具 - 决策总结

**文档日期**: 2025-12-01
**状态**: 待决策（已搁置）

---

## 📊 分析结论

### 1️⃣ **技术可实现性：✅ 可行**

提供了三种实现方案：

**方案 A（推荐MVP）**：调用 PyWxDump.exe

- 开发时间：2-3 周
- 风险：低
- 成本：低

**方案 B（长期）**：用 Rust 复刻核心代码

- 开发时间：4-6 周
- 风险：中高（需逆向工程知识）
- 优势：完全自主可控

**方案 C（最简）**：直接依赖 PyWxDump Python 库

- 开发时间：1-2 天
- 缺点：体积大

### 2️⃣ **开源协议合规性：✅ 合规**

PyWxDump 使用 **MIT License**，允许：

- ✅ 商业使用
- ✅ 修改和分发
- ✅ 复刻核心代码

**唯一要求**：保留版权声明和许可证文本

### 3️⃣ **法律风险：⚠️ 可控但需谨慎**

| 风险类型       | 等级    | 应对措施                 |
| -------------- | ------- | ------------------------ |
| 违反微信ToS    | 🔴 高   | 用户协议 + 免责声明      |
| 个人信息保护法 | 🟡 中低 | 明确告知 + 用户授权      |
| 账号封禁       | 🟡 中   | 仅读本地数据，无网络请求 |

**竞品参考**：

- PyWxDump、WeChatMsg：有风险报道但仍正常运营
- 腾讯IMA、Cubox：使用官方API，无风险

---

## 🎯 最终建议：**平衡型方案**

### 分阶段实施路径

**阶段 0：评估阶段（1-2 周）**

- [ ] 咨询专业律师评估法律风险
- [ ] 小范围用户意愿调研
- [ ] 评估微信官方态度

**阶段 1：MVP 内测（3-4 周）**

- [ ] 使用方案 A（调用 PyWxDump）
- [ ] 完整的用户协议和免责声明
- [ ] 仅向前 100 名 Pro 用户开放
- [ ] 观察反馈和风险

**阶段 2：正式发布（如果 MVP 成功）**

- [ ] 逐步开放给所有 Pro 用户
- [ ] 持续监控法律风险
- [ ] 必要时切换到自研方案

**阶段 3：替代方案（如果风险过高）**

- [ ] 停止桌面工具
- [ ] 转向微信小程序分享方案（官方API，零风险）
