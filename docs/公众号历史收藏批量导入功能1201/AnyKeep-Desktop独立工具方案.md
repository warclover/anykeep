- 🔄 **自动同步**：本地提取 → 云端同步，全自动完成
- 📊 **数据预览**：导入前可预览和筛选数据
- 🎁 **Pro 专属**：提升 Pro 会员价值感

### 4.4 核心模块设计

#### OAuth 认证模块

**流程**：

```rust
// Rust 代码示例
use oauth2::{AuthorizationCode, TokenResponse};

pub async fn login_with_oauth() -> Result<String, Error> {
    // 1. 打开浏览器授权页面
    let auth_url = "https://anykeep.com/oauth/authorize";
    open::that(auth_url)?;

    // 2. 启动本地服务器监听回调
    let callback_url = "http://localhost:8888/callback";
    let code = listen_for_callback().await?;

    // 3. 交换 Access Token
    let token = exchange_code_for_token(code).await?;

    // 4. 验证会员身份
    let membership = verify_membership(&token).await?;

    if membership == "pro" {
        Ok(token)
    } else {
        Err(Error::NotProMember)
    }
}
```

#### 微信数据提取模块

**Rust 核心代码**：

```rust
use rusqlite::{Connection, OpenFlags};
use sqlcipher::Database;

pub struct WechatFavoriteExtractor {
    db_path: String,
    db_key: String,
}

impl WechatFavoriteExtractor {
    pub fn new() -> Result<Self, Error> {
        // 1. 检测微信是否运行
        let wechat_pid = detect_wechat_process()?;

        // 2. 获取数据库密钥（从进程内存读取）
        let db_key = extract_db_key_from_memory(wechat_pid)?;

        // 3. 找到 Favorite.db 路径
        let db_path = find_favorite_db_path()?;

        Ok(Self { db_path, db_key })
    }

    pub fn extract_favorites(&self) -> Result<Vec<Favorite>, Error> {
        // 1. 使用密钥解密数据库
        let conn = Database::open_with_key(&self.db_path, &self.db_key)?;

        // 2. 查询收藏表
        let mut stmt = conn.prepare("
            SELECT LocalId, Type, Title, Url, Desc, FavTime
            FROM Favorite
            WHERE Type = 1  -- 公众号文章
            ORDER BY FavTime DESC
        ")?;

        // 3. 提取数据
        let favorites = stmt.query_map([], |row| {
            Ok(Favorite {
                id: row.get(0)?,
                title: row.get(2)?,
                url: row.get(3)?,
                desc: row.get(4)?,
```

#### 数据同步模块

**Rust 代码**：

```rust
use reqwest::Client;
use serde::{Serialize, Deserialize};

pub struct DataSyncClient {
    client: Client,
    access_token: String,
}

impl DataSyncClient {
    pub async fn batch_import(
        &self,
        favorites: Vec<Favorite>,
        progress_callback: impl Fn(usize, usize)
    ) -> Result<ImportResult, Error> {
        let api_url = "https://anykeep.com/api/desktop/import/batch";

        // 分批上传（每批 50 条）
        let batch_size = 50;
        let mut succeeded = 0;
        let mut failed = 0;

        for (i, batch) in favorites.chunks(batch_size).enumerate() {
            let response = self.client
                .post(api_url)
                .bearer_auth(&self.access_token)
                .json(&batch)
                .send()
                .await?;

            if response.status().is_success() {
                succeeded += batch.len();
            } else {
                failed += batch.len();
            }

            // 更新进度
            progress_callback(i * batch_size + batch.len(), favorites.len());
        }

        Ok(ImportResult { succeeded, failed })
    }
}
```
