## 技术决策点

### 1. 向量嵌入模型选择

| 选项                          | 优点            | 缺点          | 推荐     |
| ----------------------------- | --------------- | ------------- | -------- |
| OpenAI text-embedding-3-small | 效果好，1536 维 | 需要 API 费用 | ✅       |
| OpenAI text-embedding-3-large | 效果最好        | 费用更高      | 备选     |
| 本地模型                      | 无费用          | 部署复杂      | 暂不考虑 |

### 2. 搜索策略

推荐使用**混合搜索**:

1. 先进行关键词匹配 (快速)
2. 同时进行语义搜索 (相关性)
3. 合并结果并去重排序

### 3. 向量生成时机

| 时机       | 优点       | 缺点         |
| ---------- | ---------- | ------------ |
| 创建书签时 | 实时可搜   | 增加创建延迟 |
| 异步队列   | 不影响创建 | 需要队列系统 |
| 批量定时   | 简单       | 有搜索延迟   |

**推荐**: 创建时异步生成，使用 Supabase Edge Function

| 风险             | 影响         | 应对措施           |
