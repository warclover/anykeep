# 📋 开发计划

本目录存放 AnyKeep 项目的所有开发计划、功能规划和产品路线图。

## 目录说明

### phases/

分阶段开发计划，如 Phase 1、Phase 2、Phase 3 等。

**存放内容**：

- Phase N 开发计划
- 阶段目标和里程碑
- 阶段技术方案

**命名示例**：

- `phase-1-plan.md`
- `phase-2-browser-bookmark.md`

---

### features/

单个功能的详细规划文档。

**存放内容**：

- 功能需求分析
- 技术实现方案
- 任务分解和时间估算

**命名示例**：

- `browser-bookmark-import-plan.md`
- `ai-summary-optimization-plan.md`
- `rating-payment-plan.md`

---

### current/

当前正在执行的计划文档。

**存放内容**：

- 当前迭代计划
- 正在开发的功能计划
- 活跃的开发文档

**使用说明**：

- 这里存放"热文档"，经常更新
- 功能完成后应移动到对应的 phases/ 或 features/ 目录

---

### roadmap/

产品路线图和长期规划。

**存放内容**：

- 产品路线图
- 季度/年度规划
- 功能优先级排序

**命名示例**：

- `2025-q1-roadmap.md`
- `mvp-roadmap.md`

---

### archived/

已完成或废弃的计划文档。

**存放内容**：

- 已完成的历史计划
- 被取消的功能计划
- 过时的规划文档

**归档规则**：

- 功能开发完成后，计划文档移至此处
- 保留用于历史追溯和经验总结

---

[关键实现步骤]

- [ ] 任务 1 - [预计时间]

## 5. 风险与挑战
