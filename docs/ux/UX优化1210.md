## 🔴 高优先级改善建议（P0）

### 1. 简化浏览器书签导入流程

**当前问题**：4 步骤导入流程对新用户过于复杂，容易中途放弃

**建议方案**：

```
当前：文件上传 → 预览 → 选项配置 → 执行
优化：文件上传（智能默认） → 一键导入（高级选项可展开）
```

**具体改进**：

- 合并预览和选项为可折叠面板
- 提供"快速导入"和"高级导入"两种模式
- 默认启用最常用选项（重复检测、保留文件夹结构）

---

### 2. 重构平台筛选器位置

**当前问题**：平台筛选器位于顶部导航，视觉层级不够突出，新用户常常忽略

**建议方案**：

- 移至侧边栏作为固定分类入口
- 或改为首页顶部的 Tab 式切换（参考 Apple Music 的分类导航）
- 添加平台图标增强可识别性

**视觉优化**：

```
┌─────────────────────────────────┐
│ 🏠 首页                         │
├─────────────────────────────────┤
│ ▼ 平台分类                      │
│   📱 全部 (128)                 │
│   💬 微信公众号 (45)            │
│   📺 B站 (32)                   │
│   📕 小红书 (28)                │
│   🌐 浏览器书签 (23)            │
└─────────────────────────────────┘
```

---

### 3. 首页加载优化

**当前问题**：首屏加载 2.5s+，用户感知较慢

**建议方案**：

- 实现骨架屏（Skeleton）动画，消除白屏感
- 首屏仅加载可见区域卡片（当前已加载 50 条，建议改为动态 12-16 条）
- 延迟加载非关键内容（AI 标签、相关推荐）

---

### 4. 删除操作确认强化

**当前问题**：批量删除操作缺乏足够的警告提示，容易误操作

**建议方案**：

- 添加二次确认对话框，显示将删除的具体数量
- 删除后显示 Toast 通知 + "撤销"按钮（5 秒内可恢复）
- 危险操作使用红色主题强调

---

## 🟠 中优先级改善建议（P1）

### 5. AI 标签与手动标签视觉区分

**当前问题**：用户无法区分哪些标签是 AI 生成的，哪些是自己添加的

**建议方案**：

```
AI 标签: 🤖 科技  📊 数据分析  （带 AI 图标 + 蓝色调）
手动标签: 工作  重要  稀饭       （绿色调 + 可编辑图标）
```

---

### 6. 搜索结果体验优化

**当前问题**：全文搜索与 AI 语义搜索切换时，结果变化无过渡动画，用户困惑

**建议方案**：

- 搜索结果添加类型标签（"关键词匹配" / "语义相似"）
- 语义搜索结果显示相似度分数（如 "92% 匹配"）
- 切换时添加淡入淡出过渡动画

---

### 7. 新用户引导优化

**当前问题**：首次使用缺乏功能引导，用户不知道从哪里开始

**建议方案**：

- 新用户首次进入时，显示功能导览（Product Tour）
- 空状态页面添加更有吸引力的插图 + 明确的行动按钮
- 首页空状态建议：
  ```
  ┌────────────────────────────────┐
  │      [精美插图]                 │
  │                                │
  │   开始你的收藏之旅 ✨           │
  │                                │
  │   [导入浏览器书签]  [添加收藏]  │
  └────────────────────────────────┘
  ```

---

### 8. 消息通知增强

**当前问题**：重要通知（如导入完成、AI 分类完成）容易被忽视

**建议方案**：

- 添加浏览器原生通知（需用户授权）
- 消息图标显示未读数量角标
- 重要通知使用 Toast 主动推送

---

## 🟡 低优先级改善建议（P2）

### 9. 键盘快捷键支持

| 快捷键         | 功能           |
| -------------- | -------------- |
| `Cmd/Ctrl + K` | 快速搜索       |
| `Cmd/Ctrl + N` | 新建收藏       |
| `Cmd/Ctrl + /` | 显示快捷键列表 |
| `J / K`        | 列表上下导航   |
| `Enter`        | 打开选中项     |

---

### 10. 深色模式对比度优化

**当前问题**：部分文本在深色模式下对比度不足，影响可读性

**建议方案**：

- 检查所有文本颜色是否符合 WCAG AA 标准（对比度 ≥ 4.5:1）
- 特别关注：灰色说明文字、禁用状态、placeholder

---

### 11. 操作撤销功能

**建议方案**：

- 实现全局操作历史栈（最近 10 个操作）
- 支持 `Cmd/Ctrl + Z` 撤销最近操作
- 覆盖范围：删除、移动、标签修改

---

### 12. 触控手势优化（移动端）

**建议方案**：

- 左滑收藏卡片：显示快捷操作（删除、移动）
- 长按卡片：进入批量选择模式
- 下拉刷新：更新收藏列表
