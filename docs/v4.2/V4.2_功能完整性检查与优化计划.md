## 🔴 代码质量问题

### 1. TypeScript 类型错误 (144 个)

**根本原因**: 数据库迁移后未重新生成 Supabase TypeScript 类型

**主要错误类别**:

| 错误类型      | 数量 | 根因                     |
| ------------- | ---- | ------------------------ |
| 缺失数据库列  | ~60  | 新增字段未同步到类型     |
| 缺失 RPC 函数 | ~25  | 新增函数未同步到类型     |
| 类型不匹配    | ~30  | 接口定义与实际使用不一致 |
| 其他类型问题  | ~29  | 类型断言/可选属性处理    |

**涉及文件 (按优先级)**:

1. `api/classification/classify/route.ts` - ClassificationResult 类型不匹配
2. `api/classification/cluster-confirm/route.ts` - 缺失 bookmark_ids、suggested_action 字段
3. `api/classification/cluster-suggestions/route.ts` - 缺失 bookmark_ids 字段
4. `api/cron/smart-sorting/route.ts` - 缺失 operation_snapshots 表类型
5. `api/settings/ai-folder/route.ts` - 缺失 RPC 函数类型
6. `api/folders/connections/route.ts` - 缺失 RPC 函数类型
7. `lib/chat/*.ts` - 缺失 chat_usage 表类型
8. `components/folder-evolution/*.tsx` - 日期处理类型问题
