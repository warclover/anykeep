- `src/hooks/use-evolution-reports.ts:89-115`

**问题**: `fetchXxx` 函数作为 `useEffect` 依赖，但每次渲染都重新创建

```typescript
// ❌ 当前代码 - 无限循环风险
const fetchClusters = useCallback(async () => {
  // ...
}, []); // 或依赖了会变化的值

useEffect(() => {
  fetchClusters();
}, [fetchClusters]); // fetchClusters 每次都是新的
```

**修复方案**:

```typescript
// ✅ 修复代码 - 方案1: 移除依赖
useEffect(() => {
  fetchClusters();
  // eslint-disable-next-line react-hooks/exhaustive-deps
}, []); // 仅在挂载时执行

// ✅ 修复代码 - 方案2: 使用 useRef
const fetchClustersRef = useRef(fetchClusters);
useEffect(() => {
  fetchClustersRef.current = fetchClusters;
});
useEffect(() => {
  fetchClustersRef.current();
}, []);
```

### 数据一致性问题

#### 7. 事务处理缺失

**影响文件**:

- `src/app/api/classification/pending-clusters/route.ts:199-238` (创建文件夹 + 移动书签)
- `src/app/api/classification/cluster-confirm/route.ts` (4步操作无事务)
- `src/app/api/cron/smart-sorting/route.ts` (创建 + 移动 + 快照 + 消息)

**问题**: 多步操作没有事务保护，部分失败会导致数据不一致

**修复方案**:

```sql
-- 创建 RPC 函数包装事务
CREATE OR REPLACE FUNCTION confirm_cluster_transaction(
  p_user_id UUID,
  p_folder_name TEXT,
  p_bookmark_ids BIGINT[]
) RETURNS JSON AS $$
DECLARE
  v_folder_id BIGINT;
BEGIN
  -- 创建文件夹
  INSERT INTO folders (user_id, name, is_system)
  VALUES (p_user_id, p_folder_name, false)
  RETURNING id INTO v_folder_id;

  -- 移动书签
  UPDATE bookmarks
  SET folder_id = v_folder_id, pending_cluster = false
  WHERE id = ANY(p_bookmark_ids);

  RETURN json_build_object('folder_id', v_folder_id);
END;
$$ LANGUAGE plpgsql;
```
