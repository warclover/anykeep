## 三、待修复问题

### 3.1 P1 高优先级（影响安全、性能、数据一致性）

#### P1-1: console.error 与 logger 混用

**问题**：22 处使用 console.error 而非 logger

**影响**：

- 日志无法统一收集
- 生产环境丢失堆栈信息
- 难以追踪问题

**涉及文件**：

- `config/debug-config-store.ts` (2 处)
- `services/job-queue.service.ts` (11 处)
- `services/operation-log.service.ts` (6 处)
- `services/smart-sorting.service.ts` (2 处)

**修复方案**：

```typescript
// 修改前
console.error("[OperationLogService] Failed:", error);

// 修改后
logger.error(
  { error: error instanceof Error ? error.message : String(error) },
  "[OperationLogService] Failed",
);
```

**工作量**：2 小时

#### P1-2: any 类型在核心服务

**问题**：`tiered-classification.service.ts` 使用 `SupabaseClient<any>`

// 修改前

import type { Database } from "@/types/supabase";
private supabase: SupabaseClient<Database>;

#### P1-4: N+1 查询问题

**问题**：InterestRepository 先查询再插入

**影响**：

- 两次数据库往返
- 竞态条件可能违反约束

**位置**：`interest.repository.ts` 第 42-91 行

**修复方案**：

```sql
-- 使用数据库 CHECK 约束
ALTER TABLE user_custom_interests
ADD CONSTRAINT check_max_interests
CHECK (
  (SELECT COUNT(*) FROM user_custom_interests WHERE user_id = NEW.user_id) < 20
);
```

或使用单次查询：

```typescript
const { data, error } = await this.supabase.rpc(
  "add_custom_interest_with_check",
  {
    p_user_id: userId,
    p_interest_name: input.interestName,
    p_max_count: CUSTOM_INTEREST_LIMITS.MAX_CUSTOM_INTERESTS,
  },
);
```

**工作量**：2 小时

#### P1-5: 并发安全问题

**问题**：兴趣数量检查与插入非原子操作

**影响**：

- 多请求并发可能超出限制
- 数据不一致

**修复方案**：使用数据库事务或唯一约束

```typescript
// 使用 PostgreSQL 的 INSERT ... ON CONFLICT
const { data, error } = await this.supabase
  .from("user_custom_interests")
  .upsert(
    { user_id: userId, interest_name: input.interestName },
    { onConflict: "user_id,interest_name", ignoreDuplicates: true },
  )
  .select()
  .single();
```

**工作量**：2 小时

#### P2-3: Repository 映射函数重复

**问题**：多个 Repository 有相似的 mapTo\* 函数

```typescript
// lib/supabase/mapper.ts
export function createMapper<T, R>(
  schema: z.ZodSchema<T>,
  transform: (t: T) => R,
) {
  return (data: unknown[]): R[] => schema.array().parse(data).map(transform);
}
```

#### P2-4: 日志级别不一致

**涉及文件**：

- `operation-log.service.ts`
- `report.service.ts`
- `cost-monitor.service.ts`

**修复方案**：提取基类

```typescript
// lib/supabase/base-service.ts
export abstract class SupabaseService {
  private _client: Awaited<
    ReturnType<typeof createServerSupabaseClient>
  > | null = null;

  protected async getClient() {
    if (!this._client) {
      this._client = await createServerSupabaseClient();
    }
    return this._client;
  }
}
```
