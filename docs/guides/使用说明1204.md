> 版本：V9.0
> 更新日期：2024-12-04

## 快速开始

### 30 秒上手

1. **注册账号** - 使用邮箱快速注册，或点击「体验演示账号」免注册体验
2. **添加第一条收藏** - 点击底部「+ 添加收藏」，粘贴链接即可
3. **自动处理** - AI 自动提取标题、摘要、标签，智能分类到文件夹
4. **随时查找** - 使用搜索或平台筛选快速找到你的收藏

### 核心功能一览

| 功能           | 说明                                              |
| -------------- | ------------------------------------------------- |
| 一键收藏       | 粘贴链接自动解析，支持微信、B站、小红书等主流平台 |
| AI 智能处理    | 自动生成摘要、标签，智能推荐分类                  |
| 浏览器书签导入 | 支持 Chrome/Edge/Firefox/Safari 书签批量导入      |
| 语义搜索       | 不记得关键词？用自然语言描述也能找到              |
| 多端同步       | 网页版、移动端数据实时同步                        |

## 登录与注册

### 注册新账号

1. 访问 AnyKeep 网站，点击「立即注册」
2. 输入邮箱地址和密码（至少 6 位）
3. 勾选「同意服务条款和隐私政策」
4. 点击「创建账号」
5. 查收验证邮件，点击链接完成注册

> 提示：如未收到邮件，请检查垃圾邮件箱

### 登录方式

AnyKeep 支持多种登录方式：

| 方式       | 操作步骤                                   |
| ---------- | ------------------------------------------ |
| 邮箱登录   | 输入邮箱和密码，点击「登录」               |
| 手机号登录 | 输入手机号，获取验证码，输入验证码登录     |
| 微信扫码   | 打开微信扫描二维码，确认授权               |
| 演示账号   | 点击「体验演示账号」，无需任何信息即可体验 |

### 主题切换

- 登录页面左上角有主题切换按钮
- 支持「浅色模式」和「深色模式」
- 设置会自动保存

## 收藏管理

### 添加收藏

**方法一：粘贴链接（推荐）**

1. 点击底部「+ 添加收藏」按钮
2. 在链接输入框粘贴 URL
3. 系统自动获取网页信息：
   - 标题
   - 描述/摘要
   - 封面图
   - 来源平台
4. （可选）选择文件夹、添加标签
5. 点击「创建收藏」

**方法二：分享到 AnyKeep**

1. 在微信/B站等 App 中打开内容
2. 点击「分享」
3. 选择「AnyKeep」或「复制链接」
4. 在 AnyKeep 中粘贴创建

**自动 AI 处理**：

- 创建后，AI 会在后台自动生成摘要和标签
- 如果检测到高置信度分类，会弹出通知建议移动到对应文件夹

### 编辑收藏

1. 点击收藏卡片进入详情页
2. 点击右上角「编辑」按钮
3. 修改标题、描述、文件夹、标签等
4. 点击「保存修改」

> 注意：原文链接不可修改

### 收藏卡片操作

点击收藏卡片右上角「...」菜单：

| 操作          | 说明                           |
| ------------- | ------------------------------ |
| 打开原文      | 新窗口打开原文，自动标记为已读 |
| 标记已读/未读 | 切换阅读状态                   |
| 添加/取消星标 | 标记重要收藏                   |
| 编辑          | 修改收藏信息                   |
| 删除          | 移到垃圾箱（可恢复）           |

### 收藏评级（V9.0）

- 收藏卡片底部显示 5 星评级
- 点击星星设置评级
- 5 星收藏自动进入「高价值」虚拟文件夹

### 批量操作

1. 点击菜单中的「批量选择」
2. 勾选需要操作的收藏
3. 使用工具栏进行批量操作：
   - **全选/反选**
   - **批量删除**
   - **批量移动到文件夹**

### 删除与恢复

**删除收藏**：

1. 点击收藏菜单「删除」
2. 确认删除
3. 收藏移到垃圾箱

**恢复收藏**：

1. 进入「垃圾箱」
2. 点击收藏的「恢复」按钮
3. 收藏回到原文件夹

**永久删除**：

1. 在垃圾箱点击「永久删除」
2. 确认后彻底删除，无法恢复

**清空垃圾箱**：

1. 进入垃圾箱
2. 点击工具栏「清空垃圾箱」
3. 所有垃圾将被永久删除

## 浏览器书签导入

### 支持的浏览器

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Apple Safari

### 导出书签文件

**Chrome / Edge**：

1. 打开浏览器，进入 `书签管理器`（快捷键 Ctrl+Shift+O）
2. 点击右上角「...」菜单
3. 选择「导出书签」
4. 保存为 HTML 文件

**Firefox**：

1. 打开「书签管理器」（快捷键 Ctrl+Shift+O）
2. 点击「导入和备份」
3. 选择「导出书签到 HTML」

**Safari**：

1. 菜单栏选择「文件」>「导出书签」
2. 保存为 HTML 文件

### 导入步骤

#### 步骤 1：上传文件

1. 在 AnyKeep 首页点击「导入浏览器书签」
2. 将导出的 HTML 文件拖拽到上传区
3. 或点击上传区选择文件
4. 等待系统解析

#### 步骤 2：预览与选择

1. 查看解析结果：
   - 检测到的浏览器类型
   - 书签总数
   - 文件夹结构
2. 在书签树中选择要导入的内容：
   - 点击文件夹前的箭头展开/折叠
   - 勾选/取消勾选书签
   - 使用「全选」「反选」快速操作
3. 点击「下一步」

#### 步骤 3：配置选项

| 选项           | 说明                     | 建议     |
| -------------- | ------------------------ | -------- |
| 自动创建文件夹 | 保留浏览器的文件夹结构   | 开启     |
| 启用 AI 分类   | 自动将书签分到合适文件夹 | 按需开启 |
| 保留原始时间   | 使用书签的原始添加时间   | 开启     |
| 目标文件夹     | 指定导入到某个文件夹     | 可选     |

#### 步骤 4：执行导入

1. 点击「开始导入」
2. 查看导入进度
3. 导入完成后查看结果统计：
   - 成功数量
   - 跳过数量（重复）
   - 失败数量

### 导入后查看

- 点击侧边栏「浏览器书签」查看所有导入的书签
- 自动使用紧凑列表视图
- 支持万级书签流畅滚动

### 导入历史

- 进入「设置」>「导入历史」
- 查看所有导入记录
- 可查看每次导入的详细统计

## 文件夹管理

### 浏览文件夹

访问「文件夹」页面（`/folders`）：

- **系统文件夹**：待整理（Inbox）- 存放未分类的收藏
- **分组显示**：按类别分组展示（工作、学习、生活、娱乐、其他）
- **统计信息**：每个文件夹显示收藏数量

### 创建文件夹

1. 点击「新建文件夹」按钮
2. 输入文件夹名称
3. （可选）选择分类
4. 点击「创建」

### 文件夹操作

点击文件夹卡片右上角菜单：

| 操作     | 说明                             |
| -------- | -------------------------------- |
| 重命名   | 修改文件夹名称                   |
| 合并     | 将此文件夹内容合并到另一个文件夹 |
| 删除     | 删除文件夹（可选择内容处理方式） |
| 查看收藏 | 跳转查看该文件夹的所有收藏       |

### 删除文件夹

删除时需要选择内容处理方式：

- **移到待整理**：文件夹内收藏移到 Inbox
- **直接删除**：文件夹和内容一起删除

## 搜索功能

### 基础搜索

1. 点击首页顶部搜索按钮，或访问「搜索」页面
2. 输入关键词
3. 按回车或点击搜索
4. 浏览搜索结果

### 搜索模式

**全文搜索（默认）**：

- 搜索标题、描述、摘要、标签中的关键词
- 速度快，适合精确查找

**AI 语义搜索**：

- 点击「AI 搜索」按钮启用
- 理解语义，找到相关内容
- 适合模糊记忆、概念查找

### 搜索技巧

| 语法     | 示例            | 说明               |
| -------- | --------------- | ------------------ |
| 多关键词 | `ai 编程`       | 包含 ai 或 编程    |
| 精确短语 | `"react hooks"` | 完整短语匹配       |
| 排除词   | `-deprecated`   | 排除包含该词的结果 |

### 热门标签

- 搜索页面显示热门标签
- 点击标签快速搜索相关内容

## 常见问题

### Q: 为什么网页信息获取失败？

**可能原因**：

1. 网页需要登录才能访问
2. 网站禁止爬取
3. 网络连接问题

**解决方法**：

- 手动填写标题和描述
- 确保链接可以在浏览器中正常打开

### Q: AI 摘要和标签没有生成？

**可能原因**：

1. AI 处理是异步的，需要等待几秒
2. 内容过短无法生成有效摘要

**解决方法**：

- 刷新页面查看是否已生成
- 点击「重新生成」手动触发

### Q: 浏览器书签导入很慢？

**说明**：

- 大量书签需要分批处理
- 系统会自动进行链接验证和元数据获取

**建议**：

- 耐心等待，可以查看进度条
- 如果书签数量过多（>5000），建议分批导入

### Q: 如何恢复误删的收藏？

**步骤**：

1. 进入「垃圾箱」
2. 找到误删的收藏
3. 点击「恢复」按钮

> 注意：垃圾箱内容 30 天后自动清理

### Q: 搜索找不到我的收藏？

**建议**：

1. 检查关键词是否正确
2. 尝试使用「AI 搜索」模式
3. 检查收藏是否在某个特定文件夹中

### Q: 如何导出我的所有收藏？

**步骤**：

1. 进入首页
2. 点击菜单「导出」
3. 选择导出格式（HTML/CSV/JSON）
4. 选择导出范围
5. 下载文件

### Q: 移动端如何使用？

**方式**：

1. **网页版**：直接在手机浏览器访问
2. **PWA**：在浏览器中选择「添加到主屏幕」
3. **App**：下载 Android/iOS 应用（开发中）
