# 推荐深化方向

## 1. AI 自动分类交互体验 ⭐⭐⭐

**路线图定位**： P0 核心功能（第 3 周目标）

**当前状态**：

✅ 智能分类系统 V2 已合并 (feature/intelligent-classification-v2)

✅ 收件箱分析 API 已实现 (/api/classification/inbox)

❌ 缺少：非阻塞式推荐 UI、用户反馈记录

**建议深化方向**：

| 项目           | 说明                                                             |
| :------------- | :--------------------------------------------------------------- |
| 轻量推荐卡片   | 收藏后底部 Toast：「💡 觉得可以放到【前端开发】」+ 同意/忽略按钮 |
| 用户偏好学习   | 记录接受/拒绝行为，逐步提高推荐准确率                            |
| 收件箱入口强化 | 首页添加「待整理」快捷入口，展示未分类数量                       |

**预期收益**： 真正兑现「Don't Organize. Just Keep.」的核心承诺

---

## 2. 卡片视觉层级与平台识别度 ⭐⭐⭐

**路线图定位**： P0 核心功能（第 1 周目标）

**当前状态**：

✅ 翻转卡片功能已实现

✅ 用途标签系统已完成

⚠️ 平台识别度不够强（微信/B站/小红书视觉区分不明显）

**建议深化方向**：

| 项目         | 说明                                               |
| :----------- | :------------------------------------------------- |
| 平台色条强化 | 右上角添加平台色条（微信绿、B站粉、小红书红）      |
| 信息层级优化 | 封面 > 平台标识 > 标题 > AI 摘要 > 标签 > 来源账号 |
| 来源账号显示 | 底部灰字显示「@公众号名称」「@UP主」等             |

**预期收益**： 用户 3 秒内能识别内容来源，提升首屏"灵感墙"体验

---

## 3. 浏览器扩展一键收藏体验 ⭐⭐

**路线图定位**： P0 核心功能（第 2 周目标）

**当前状态**：

✅ 分享目标 API 已实现 (/api/share-target)

⚠️ 浏览器扩展具体体验未验证

❌ 缺少：收藏成功的轻量反馈动效

**建议深化方向**：

| 项目          | 说明                                               |
| :------------ | :------------------------------------------------- |
| 扩展 MVP 打磨 | 点击图标 → 直接保存 → 浮层反馈（缩略图+标题+平台） |
| 成功动效      | 小动画 + 「已加入灵感墙」提示，强化愉悦感          |
| 错误兜底      | 解析失败时提供体面的默认卡片，避免残废卡片         |

**预期收益**： 收藏入口顺滑 → 用户留存率提升

| 3️⃣   | 浏览器扩展      | 收藏入口是增长关键               |
