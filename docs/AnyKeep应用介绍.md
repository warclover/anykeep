# AnyKeep - 智能内容聚合工具

> 一站式管理你的数字收藏，让知识触手可及

---

## 产品简介

AnyKeep 是一款**跨平台智能内容聚合工具**，帮助用户统一管理来自不同平台的收藏内容。无论是微信公众号文章、B站视频、小红书笔记，还是浏览器书签，都可以在 AnyKeep 中集中管理、智能整理、快速检索。

**核心理念**：让碎片化的信息变成系统化的知识资产。

---

## 核心功能

### 1. 内容收藏管理

| 功能               | 说明                                                     |
| ------------------ | -------------------------------------------------------- |
| **多平台支持**     | 支持微信、B站、小红书、知乎等主流平台内容收藏            |
| **浏览器书签导入** | 一键导入 Chrome/Edge/Firefox/Safari 书签，保留文件夹结构 |
| **文件夹管理**     | 自定义文件夹层级，灵活组织内容                           |
| **标签系统**       | 为内容添加多标签，支持批量标签管理                       |

### 2. AI 智能助手

内置 AI 知识助手，提供四大智能能力：

| 能力         | 功能描述                                      |
| ------------ | --------------------------------------------- |
| **知识回顾** | 智能复习收藏内容，生成记忆卡片，巩固知识点    |
| **洞察报告** | 分析收藏习惯、内容趋势，提供个性化洞察建议    |
| **智能整理** | 自动分类、去重、标签推荐，让收藏井井有条      |
| **数据导出** | 多格式导出（CSV/Markdown/Obsidian/JSON/HTML） |

### 3. 高效检索

- **全文搜索**：快速定位任意内容
- **标签筛选**：按标签组合过滤
- **平台分类**：按来源平台查看
- **时间排序**：按收藏时间浏览

### 4. 批量操作

- **批量选择**：支持 Shift 范围选择，快速选中多条内容
- **批量标签**：一次性为多条内容添加/移除标签
- **批量导出**：选择性导出指定内容

### 5. 数据分析

- **收藏统计**：内容数量、平台分布、标签使用
- **活跃度分析**：收藏频率趋势图
- **AI 使用统计**：Skills 调用次数与效果分析

## 使用场景

### 场景一：知识管理者

> "我每天会在各个平台收藏大量文章，但收藏后就再也找不到了..."

AnyKeep 帮助你：

- 统一管理所有平台收藏
- AI 自动分类打标签
- 定期知识回顾，避免「收藏=遗忘」

### 场景二：浏览器书签整理

> "我的书签栏已经有上千条书签，乱得不能再乱了..."

AnyKeep 帮助你：

- 一键导入全部书签
- 智能去重、失效检测
- 批量整理、重新分类

### 场景三：内容创作者

> "我需要把收藏的素材整理成文档..."

AnyKeep 帮助你：

- 按主题筛选内容
- 一键导出为 Markdown/Obsidian 格式
- 直接导入到你的写作工具
