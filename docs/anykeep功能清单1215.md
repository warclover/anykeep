# AnyKeep 功能清单

> 生成日期: 2025-12-15
> 版本: V4.2
> 分支: feature/classification-v4.2

---

## 产品定位

| 维度           | 描述                                          |
| -------------- | --------------------------------------------- |
| **一句话定位** | 跨平台智能内容聚合工具                        |
| **核心理念**   | **零整理、视觉优先、中文生态护城河**          |
| **目标用户**   | 重度使用微信/B站/小红书等中国平台的内容消费者 |
| **核心痛点**   | 各平台收藏分散、难以统一管理、找回困难        |
| **差异化定位** | "视觉收藏墙" vs Cubox 的"稀后阅读助手"        |
