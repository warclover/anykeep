## 测试类型

### 单元测试 (Unit Tests)

使用 Jest + React Testing Library 进行组件和函数测试。

**位置**: `src/**/*.test.ts` 或 `src/**/*.test.tsx`

**运行命令**:

```bash
npm run test          # 运行所有测试
npm run test:watch    # 监听模式
npm run test:coverage # 生成覆盖率报告
```

---

### 集成测试 (Integration Tests)

测试多个模块之间的交互。

**位置**: `src/**/*.integration.test.ts`

---

### E2E 测试 (End-to-End Tests)

使用 Cypress 或 Playwright 进行端到端测试。

**位置**: `e2e/` 或 `tests/e2e/`

## 测试最佳实践

### 单元测试原则

1. **测试行为，不测试实现**
2. **一个测试只验证一个场景**
3. **测试名称应清晰描述场景**
4. **使用 AAA 模式（Arrange-Act-Assert）**

### 测试命名规范

```typescript
describe("ComponentName", () => {
  it("should do something when condition", () => {
    // Arrange
    // Act
    // Assert
  });
});
```

### 测试覆盖率目标

- 核心功能: 80% 以上
- 工具函数: 90% 以上
- UI 组件: 70% 以上
