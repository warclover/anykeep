### 1.2 目标用户群体（6大分组）

**核心定位**：需要**大量阅读、学习、研究**的知识工作者

| 分组           | 用户群体                                 | 核心特征       | 阅读量级     | 优先级 |
| -------------- | ---------------------------------------- | -------------- | ------------ | ------ |
| **学术研究型** | 本科生、研究生、博士生、教师、科研人员   | 论文/教材/资料 | 50-200篇/月  | P0     |
| **内容创作型** | 科技/知识/技术博主、在线讲师、策展人     | 素材/选题/输出 | 100-500条/月 | P0     |
| **技术实践型** | 独立开发者、AI发烧友、安全研究员、架构师 | 技术/方案/代码 | 50-150篇/月  | P0     |
| **专业服务型** | 咨询顾问、分析师、律师、医学从业者、记者 | 行业/案例/报告 | 80-300篇/月  | P1     |
| **产品设计型** | 产品经理、UX研究员、游戏策划             | 用户/竞品/设计 | 60-200条/月  | P1     |
| **自我提升型** | 终身学习者、考证备考者、职业转型者       | 技能/知识/进度 | 40-150条/月  | P2     |
