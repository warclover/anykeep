## 二、发现的问题

### 2.1 🔴 严重问题 (P0)

#### 问题 1: html-sanitizer.ts SSR 兼容性问题

**文件**: `src/lib/utils/html-sanitizer.ts`

**现象**:

```
Error: ENOENT: no such file or directory, open 'C:\anykeep\.next\browser\default-stylesheet.css'
```

**根因分析**:

- `isomorphic-dompurify` 在 SSR 环境下使用 JSDOM
- JSDOM 尝试加载不存在的 default-stylesheet.css
- 导致整个模块加载失败，级联影响其他模块

**影响范围**:

- 微信文章阅读器组件 (`wechat-article-viewer.tsx`)
- 书签详情页 (`bookmark-detail-client.tsx`)

**修复建议**:
已实施惰性初始化修复，但需要进一步验证。建议：

1. 使用 `next/dynamic` with `ssr: false` 包裹使用 DOMPurify 的组件
2. 或者在服务端跳过 sanitization（后端已清理过）

---

#### 问题 2: useWechatArticleFeature 函数调用失败

**文件**: `src/components/bookmark/bookmark-detail-client.tsx:138`

**现象**:

```
TypeError: (0 , _lib_feature_flags__WEBPACK_IMPORTED_MODULE_28__.useWechatArticleFeature) is not a function
```

**根因分析**:

- 这是问题 1 的级联效应
- 当 html-sanitizer.ts 加载失败时，webpack 模块解析出错
- 导致 feature-flags 模块的导出也无法正确解析

**影响范围**:

- 所有微信平台的书签详情页无法访问
- 自动快照触发功能受影响

---

### 2.2 🟡 中等问题 (P1)

#### 问题 3: Hydration Mismatch 警告

**现象**:

```
Warning: Prop `aria-controls` did not match. Server: "radix-:Racukqj6:" Client: "radix-:R2cukqj6:"
Error: Hydration failed because the initial UI does not match what was rendered on the server.
```

**根因分析**:

- Radix UI 组件生成动态 ID
- 服务端和客户端生成的 ID 不一致
- 这是 Radix UI 的已知问题

**影响范围**:

- 控制台警告，不影响核心功能
- 可能导致轻微的 UI 闪烁

**修复建议**:

1. 使用 `useId()` hook 生成稳定 ID
2. 或者接受这个 hydration 警告（非阻塞）

---

#### 问题 4: Web Vitals 性能指标差

**现象**:

```
❌ LCP: 40012ms (poor)
❌ FCP: 24824ms (poor)
❌ TTFB: 24731ms (poor)
```

**根因分析**:

- 开发模式下首次编译时间长（13-35秒）
- 网络请求（Google Fonts）超时
- 模块数量多（5400+ modules）

**影响范围**:

- 仅影响开发环境
- 生产环境构建后应显著改善

---

### 2.3 🟢 轻微问题 (P2)

#### 问题 5: Google Fonts 加载失败

**现象**:

```
⨯ Failed to download `Inter` from Google Fonts. Using fallback font instead.
AbortError: The user aborted a request.
```

**根因分析**:

- 网络超时（可能是防火墙/网络问题）
- Next.js 会自动使用 fallback 字体

**影响范围**:

- 字体显示可能略有差异
- 不影响功能

---

#### 问题 6: Tailwind CSS 类名警告

**现象**:

```
warn - The class `ease-[cubic-bezier(0.32,0.72,0,1)]` is ambiguous and matches multiple utilities.
```

**影响范围**:

- 仅为警告，不影响功能
- 建议使用转义语法修复
