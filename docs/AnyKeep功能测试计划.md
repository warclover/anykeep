### 测试方法

1. **Playwright 浏览器自动化**
   - 使用 `browser_navigate` 访问页面
   - 使用 `browser_snapshot` 获取页面状态
   - 使用 `browser_click` / `browser_type` 模拟用户操作
   - 使用 `browser_console_messages` 检查错误

2. **检查项**
   - ✅ 页面是否正常加载
   - ✅ 功能是否按预期工作
   - ✅ UI 显示是否正确
   - ✅ 控制台是否有错误
   - ✅ 网络请求是否成功
