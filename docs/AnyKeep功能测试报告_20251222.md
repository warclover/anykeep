## 🐛 问题汇总

### 问题1: 会话过期 (AUTH-001) ✅ 已修复

- **严重程度**: 中等 ⚠️
- **复现步骤**: 长时间（约30分钟）测试操作
- **现象**: 页面跳转到登录页，显示"请先登录"，API返回401
- **修复方案** (V4.2.30):
  1. 将 Token 即将过期阈值从 60 秒增加到 300 秒（5分钟）
  2. 新增会话心跳检测机制（每4分钟检查一次）
  3. 页面从后台恢复时自动检查会话状态
  4. 网络恢复时自动检查会话状态
- **修改文件**:
  - `src/lib/auth/jwt-verifier.ts` - nearExpiry 阈值调整
  - `src/hooks/core/use-session-heartbeat.ts` - 新增会话心跳 hook
  - `src/components/providers/session-heartbeat-provider.tsx` - 新增心跳提供者
  - `src/components/providers/root-providers.tsx` - 集成心跳检测

### 问题2: React水合错误 (UI-001) ✅ 已修复

- **严重程度**: 轻微 ℹ️
- **页面**: /settings
- **现象**: 控制台显示"Hydration failed"错误
- **影响**: 不影响功能使用，仅开发环境警告
- **修复方案** (V4.2.30):
  - 修复 `useState(() => typeof window !== "undefined")` 导致的 SSR/CSR 不一致
  - 改为使用 `useState(false)` + `useEffect(() => setIsLoaded(true), [])`
- **修改文件**:
  - `src/hooks/core/use-color-theme.ts` - 修复 isLoaded 状态初始化
