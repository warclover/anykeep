## 1. 功能概述

### 1.1 背景与目标

AnyKeep 当前的数据导出功能较为基础，无法满足知识管理者和技术用户的核心需求：

**用户痛点**：

- 📊 **数据分析用户**：无法导出 CSV 在 Excel/表格中分析
- 📝 **笔记工具迁移**：Markdown 格式不兼容 Obsidian/Notion 的 Frontmatter
- 📁 **批量整理用户**：无法按文件夹/标签筛选导出
- 💾 **数据备份用户**：缺少定期自动备份能力

**设计原则**：

```
聚焦最高频 > 避免大而全
极致体验 > 功能堆砌
解耦设计 > 耦合实现
容错优先 > 理想路径
功能协调 > 重复建设 ✨ V2.1 新增
```

### 1.2 目标用户画像

| 用户类型   | 核心需求                | 频率  |
| ---------- | ----------------------- | ----- |
| 知识管理者 | 导出到 Obsidian/Notion  | 周/月 |
| 数据分析师 | CSV 导出做统计分析      | 月    |
| 技术用户   | JSON API 或批量导出备份 | 季度  |
| 普通用户   | 简单下载备份            | 年    |

## 2. 功能定位与边界 ✨ V2.1 新增

### 2.1 导出功能 vs 批量操作功能

| 维度         | 数据导出                           | 批量操作                       |
| ------------ | ---------------------------------- | ------------------------------ |
| **核心目标** | 数据提取与备份                     | 数据修改与整理                 |
| **操作性质** | 只读（不修改数据）                 | 读写（修改数据）               |
| **典型场景** | 导出到 Excel 分析、迁移到 Obsidian | 批量打标签、批量删除、批量移动 |
| **数据范围** | 全量/筛选/选中                     | 仅选中                         |
| **用户频率** | 低频（周/月/季度）                 | 中频（周/月）                  |

### 2.2 功能重合点分析

**重合点**：批量操作页面的「导出选中」功能

### 2.3 协调方案：统一组件 + 多入口

**核心原则**：`ExportDialogV2` 作为统一的导出执行组件，被不同页面复用

| 入口         | 位置                      | 传入数据               | 用户场景     |
| ------------ | ------------------------- | ---------------------- | ------------ |
| **导出页面** | `/export`                 | 根据筛选条件查询的书签 | 完整导出流程 |
| **批量操作** | `/batch` → 工具栏「导出」 | 当前选中的书签         | 快速导出选中 |
| **首页**     | `/home` → 更多「导出」    | 当前视图的书签         | 快捷操作     |
| **文件夹页** | 文件夹菜单「导出」        | 该文件夹的书签         | 按文件夹导出 |

### 3.2 ExportDialogV2 统一接口

```typescript
// src/components/export/export-dialog-v2.tsx

interface ExportDialogV2Props {
  /** 对话框开关 */
  open: boolean;
  onOpenChange: (open: boolean) => void;

  /** 模式：full = 完整筛选模式, selected = 选中模式 */
  mode: "full" | "selected";

  /** 选中模式时传入的书签列表 */
  bookmarks?: Bookmark[];

  /** 完整模式时的筛选参数（可选，用于预设筛选条件） */
  initialFilter?: ExportFilter;

  /** 导出成功回调 */
  onSuccess?: (result: ExportResult) => void;
}
```

## 5. 侧边栏集成方案 ✨ V2.1 新增

### 5.1 导航结构调整

**当前结构**：

```
首页 → 搜索 → 收藏夹 → 消息 → 数据 → 批量 → 设置
```

**调整后结构**（新增导出）：

```
首页 → 搜索 → 收藏夹 → 消息 → 数据 → 批量 → 导出 → 设置
```

**设计考量**：

- 「批量」和「导出」是数据管理的两个维度，放在「数据」之后
- 「设置」始终在最后
- 顺序符合用户心智：查看 → 整理 → 导出

| API                    | 用途           | 是否需要修改                  |

| `GET /api/folders`     | 获取文件夹列表 | ❌ 无需修改                   |
| `GET /api/user/export` | 全量数据导出   | ⚠️ 可选优化：支持更多筛选参数 |

### 12.3 国际化预留

| UI 文本  | 使用常量文件          |

| CSV 表头 | 支持配置中英文        |

### 12.4 解耦保证

| 保证项          | 实现方式                                                 |
| --------------- | -------------------------------------------------------- |
| 现有组件不修改  | 新建独立模块 `src/lib/export/`、`src/components/export/` |

```typescript
// src/lib/export/analytics.ts

export const EXPORT_ANALYTICS_EVENTS = {
  /** 访问导出页面 */
  PAGE_VIEWED: "export_page_viewed",

  /** 打开导出对话框 */
  DIALOG_OPENED: "export_dialog_opened",

  /** 选择导出格式 */
  FORMAT_SELECTED: "export_format_selected",

  /** 应用筛选条件 */
  FILTER_APPLIED: "export_filter_applied",

  /** 查看导出预览 */
  PREVIEW_VIEWED: "export_preview_viewed",

  /** 开始导出 */
  EXPORT_STARTED: "export_started",

  /** 导出完成 */
  EXPORT_COMPLETED: "export_completed",

  /** 导出失败 */
  EXPORT_FAILED: "export_failed",

  /** 取消导出 */
  EXPORT_CANCELLED: "export_cancelled",
} as const;

export interface ExportAnalyticsParams {
  /** 入口来源 */
  source?: "page" | "batch" | "home" | "folder" | "settings";
  /** 导出格式 */
  format?: ExportFormat;
  /** 导出数量 */
  count?: number;
  /** 筛选条件类型 */
  filterTypes?: string[];
  /** 耗时（毫秒） */
  duration?: number;
  /** 文件大小（字节） */
  fileSize?: number;
  /** 错误码 */
  errorCode?: ExportErrorCode;
}
```

### 14.2 埋点触发时机

| 事件               | 触发时机       | 关键参数                                  |

| `format_selected`  | 切换导出格式   | `format`                                  |
| `filter_applied`   | 应用筛选条件   | `filterTypes`                             |
| `preview_viewed`   | 查看预览       | `format`, `count`                         |
| `export_started`   | 点击开始导出   | `source`, `format`, `count`               |
| `export_completed` | 导出成功       | `format`, `count`, `duration`, `fileSize` |
| `export_failed`    | 导出失败       | `format`, `errorCode`                     |
| `export_cancelled` | 取消导出       | `format`, `count`                         |
