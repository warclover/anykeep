# 草稿工坊（Knowledge Studio v2）简化方案

**文档版本**: 0216  
**状态**: 待实施  
**模块**: knowledge-studio/v2

---

## 一、现状诊断

### 当前用户操作路径（10+ 步，跨 2 个页面）

```
页面1: /knowledge-studio/v2
  ① 浏览14个蓝图（5个分类Tab + 搜索框）
  ② 选择蓝图 → 点击"下一步"
  ③ 筛选平台（可选下拉）
  ④ 搜索素材（可选）
  ⑤ 选择2-5个素材 + AI素材推荐面板
  ⑥ 点击"开始生成" → 跳转页面2

页面2: /knowledge-studio/v2/[blueprintId]
  ⑦ Briefing问答向导（快速/详细双模式，逐题作答）
  ⑧ 大纲预览/编辑 + 模板管理 + 平台风格选择 + 时间估算
  ⑨ SSE流式生成（等待）
  ⑩ 结果页 + 6个后处理功能
     (精简/反馈迭代/导出/一稿多发/TTS/版本管理)
```

### 核心痛点

| #   | 痛点                 | 严重程度 | 说明                                                                             |
| --- | -------------------- | -------- | -------------------------------------------------------------------------------- |
| 1   | **跨页面流程断裂**   | 高       | 两个页面通过 sessionStorage 传递素材数据，刷新即丢失，体验脆弱                   |
| 2   | **选择过载**         | 高       | 14个蓝图 + 5个分类Tab + 搜索 → 用户面对「选择瘫痪」                              |
| 3   | **向导套向导**       | 高       | 主流程是向导，Briefing 又是一个子向导（快速/详细双模式、逐题翻页），嵌套令人疲惫 |
| 4   | **结果页功能堆砌**   | 中       | 精简、反馈、导出、一稿多发、TTS、版本管理——6 个按钮挤在一行，认知负荷大          |
| 5   | **大纲阶段功能分散** | 中       | 大纲编辑器 + 模板管理器 + 平台风格选择器 + 时间估算面板，4 个独立组件            |
| 6   | **版本管理过度设计** | 低       | 3 版本 + diff 对比 + 恢复——对「快速生成内容」的用户来说过于复杂                  |

---

## 二、简化设计原则

1. **一页完成**：消除跨页面跳转，所有流程在单页内完成
2. **Smart Default**：AI 自动推荐蓝图和素材，用户只需确认
3. **渐进披露**：核心操作一目了然，高级功能按需展开
4. **3 次点击生成**：选蓝图 → 确认素材 → 生成
5. **默认无干扰**：Briefing 放入设置，默认无需用户干预

## 三、简化方案（方案 A：单页三栏流式布局）

### 整体布局示意

```
┌─────────────────────────────────────────────────┐
│  知识工坊                                        │
├─────────────────────────────────────────────────┤
│  ❶ 选择蓝图 ──────────────────────── [已选: ✅] │
│  ┌──────────────────────────────────────────┐   │
│  │ [场景快速入口] 3-4个高频场景大按钮        │   │
│  │ (具体蓝图需根据实际使用数据确定)          │   │
│  │ [更多蓝图 ▼] 折叠展开完整列表            │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  ❷ 选择素材 ──────────────────────── [2/5 已选] │
│  ┌──────────────────────────────────────────┐   │
│  │ AI推荐素材（自动根据蓝图匹配3篇）        │   │
│  │ [手动选择更多 ▼]                          │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  ❸ 补充说明（可选）────────────── 默认折叠      │
│  ┌──────────────────────────────────────────┐   │
│  │ 一个文本框："有什么特别要求？"            │   │
│  │ (Briefing 详细设置移至「设置」中)         │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  [高级选项 ▼] 大纲预览、平台风格、长度等        │
│                                                  │
│        [🚀 一键生成]                             │
│                                                  │
│  ─── 生成结果 ───────────────────────────────── │
│  ┌──────────────────────────────────────────┐   │
│  │ (SSE 流式输出区域)                        │   │
│  │ [复制] [导出▼] [更多操作 ⋯]               │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 已确认的产品决策

| 决策项            | 结论                                                                           |
| ----------------- | ------------------------------------------------------------------------------ |
| **Briefing 向导** | 直接放入**设置**中，默认**无干扰用户模式**，无需用户干预；主流程不展示问答向导 |
| **大纲预览**      | 保留为**「高级选项」折叠展开**，不默认展示                                     |
| **版本管理**      | **移除**可接受，改为「重新生成」即可                                           |
| **场景快速入口**  | 3-4 个蓝图需**根据实际使用数据确定**（待数据支持后再定具体蓝图）               |

## 四、具体变更项

### 变更 1：合并双页为单页

| 项目     | 当前                               | 简化后               |
| -------- | ---------------------------------- | -------------------- |
| 页面数   | 2 个 (`/v2` + `/v2/[blueprintId]`) | 1 个 (`/v2`)         |
| 数据传递 | sessionStorage（脆弱）             | 组件内 state（可靠） |
| 路由跳转 | 选完素材跳页面                     | 同页滚动到下一步     |

### 变更 2：蓝图选择——场景化入口 + 折叠完整列表

| 项目      | 当前                       | 简化后                                |
| --------- | -------------------------- | ------------------------------------- |
| 默认展示  | 14个卡片 + 5个Tab + 搜索框 | 3-4个高频场景大按钮（数据确定后定稿） |
| 完整列表  | 始终可见                   | 「更多蓝图」折叠展开                  |
| 分类/搜索 | 顶部固定                   | 移入折叠区域内                        |

### 变更 3：素材选择——AI 推荐 + 一键确认

| 项目     | 当前               | 简化后                     |
| -------- | ------------------ | -------------------------- |
| 默认行为 | 用户手动从列表勾选 | AI 根据蓝图自动推荐 2-3 篇 |
| 手动选择 | 主流程             | 「手动选择更多」折叠展开   |

### 变更 4：Briefing——放入设置，默认无干扰

| 项目     | 当前                      | 简化后                                                 |
| -------- | ------------------------- | ------------------------------------------------------ |
| 主流程   | 多步问答向导（快速/详细） | **不展示**，默认无干扰                                 |
| 设置中   | 无                        | 提供「Briefing 偏好」：关闭 / 快速(2题) / 详细(全部题) |
| 可选补充 | 无                        | 主流程保留一个可选文本框：「有什么特别要求？」         |

### 变更 5：大纲——高级选项折叠

| 项目       | 当前               | 简化后                           |
| ---------- | ------------------ | -------------------------------- |
| 大纲编辑   | 独立步骤、始终可见 | **高级选项**内折叠展开，默认跳过 |
| 模板管理器 | 独立组件           | 移除或移入高级选项               |
| 平台风格   | 独立选择器         | 移入「高级选项」折叠区           |

### 变更 6：结果页操作——主操作 + 更多菜单

| 项目                         | 当前         | 简化后                        |
| ---------------------------- | ------------ | ----------------------------- |
| 精简 / 反馈 / 一稿多发 / TTS | 6 个按钮平铺 | 收进「更多操作 ⋯」下拉菜单    |
| 导出                         | 独立按钮     | **主操作**保留（复制 + 导出） |
| 版本管理                     | 独立面板     | **移除**，仅保留「重新生成」  |

### 变更 7：移除/降级功能汇总

| 功能                        | 处置                   | 理由           |
| --------------------------- | ---------------------- | -------------- |
| Briefing 多步向导（主流程） | **移至设置**，默认关闭 | 默认无干扰     |
| 大纲模板管理器              | 移除或移入高级选项     | 极低频         |
| 时间估算面板                | 内联到按钮上或移除     | 减轻噪音       |
| 版本管理（3版本+diff）      | **移除**               | 已确认可接受   |
| ContentDiffViewer           | **移除**               | 随版本管理移除 |
| DraftVersionPanel           | **移除**               | 同上           |

## 七、简化后用户路径小结

```
简化前: 10+ 步，2 个页面
简化后: 3 步为主路径，1 个页面

① 选蓝图（场景入口或展开选更多）
② 确认素材（AI 已推荐，可微调）
③ 点击「一键生成」

→ 结果同页流式展示
→ 复制/导出为主操作，「更多操作」收拢高级功能
→ Briefing 在设置中可选，默认无干扰

```
