# 智能分类调试工具 (Classification Debugger)

## 1. 概述

为了方便开发者调试 V3.0 版本的智能分类算法，验证不同参数对分类结果的影响，我们在项目中集成了「智能分类调试台」。该工具允许开发者在不修改代码的情况下，实时调整算法参数并测试分类效果。

**位置**：左侧菜单栏 -> 开发者工具 -> 智能分类
**路由**：`/classification-debugger`

## 2. 核心功能

### 2.1 算法参数配置

- **分层优化策略 (Tiered Optimization)**：开关控制。启用后，系统会优先使用 Tier 1 (快速匹配) 进行分类，减少 AI 调用成本。
- **高置信度阈值 (High Confidence Threshold)**：Tier 1 的通过阈值。超过此分数的书签将直接分类，跳过 AI 确认。
- **中置信度阈值 (Medium Confidence Threshold)**：Tier 2 的准入阈值。超过此分数但未达到高置信度的书签，将调用 AI 进行二次确认。

### 2.2 模拟测试

支持输入模拟的书签数据进行测试：

- **URL** (可选)
- **标题** (必填)
- **摘要**
- **标签**

提供「填充示例数据」功能，快速填入 GitHub Actions 相关的测试数据。

### 2.3 结果可视化

测试完成后，右侧面板将展示详细的分类报告：

- **最终决策**：显示操作类型 (如 `classify`, `suggest_create`, `inbox`) 和目标文件夹。
- **置信度仪表盘**：可视化展示最终置信度，以及向量匹配、历史匹配和 AI 评分的详细构成。
- **性能分析**：展示各层级 (Tier 1/2/3) 的命中情况。
- **成本节省**：计算 AI 调用节省率。
- **原始数据**：完整的 JSON 响应，便于排查问题。

## 3. 代码实现

### 3.1 核心文件结构

| 文件路径                                          | 说明                                                                         |
| :------------------------------------------------ | :--------------------------------------------------------------------------- |
| `src/app/(main)/classification-debugger/page.tsx` | 调试工具的前端主页面，包含 UI 交互和结果展示逻辑。                           |
| `src/app/api/classification/debug/route.ts`       | 专用的调试 API，支持接收前端传递的配置参数动态覆盖系统默认配置。             |
| `src/lib/classification/container.ts`             | 修改了容器类，暴露 `getV3Matchers()` 方法，以便调试 API 可以独立实例化服务。 |
| `src/components/layout/app-sidebar.tsx`           | 添加了侧边栏入口链接。                                                       |
| `src/contexts/navigation-context.tsx`             | 注册了新的页面路由 ID。                                                      |

### 3.2 关键代码片段

#### 调试 API 实现

API 接收自定义配置，并使用这些配置实例化 `TieredClassificationService`：

```typescript
// src/app/api/classification/debug/route.ts

// ... (验证逻辑)

// 使用自定义配置初始化服务
const service = new TieredClassificationService(
  supabase,
  matchers, // 从 container 获取
  aggregator,
  config, // 注入前端传递的配置
);

// 执行分类
const result = await service.classify(userId, bookmarkData, context);
```

## 4. 依赖库

- **Lucide React**: 用于界面图标展示 (BrainCircuit, Zap, Target 等)。
