## 📋 问题诊断

### 当前问题

1. **过度复杂**：V3/V4 使用了 7+ 个匹配器，但置信度计算结果相同（57%）
2. **未充分利用已有资源**：
   - `profile_embedding` - 已使用但效果不明显
   - `name_embedding` - **完全未使用**（冷启动问题未解决）
   - `top_tags` - 未充分利用
3. **用户需求不匹配**：
   - 大部分用户只建立少量文件夹（5-10个）
   - 用户希望 0 操心，全部交给 AI 自动创建和归类
   - 不需要复杂的权重调整、场景检测、A/B 测试

### 核心需求

- **简单匹配**：收藏的标题+标签 → 匹配文件夹向量 → 计算分数 → 归类
- **冷启动支持**：新建的空文件夹也能被匹配
- **自动创建**：如果没有匹配，AI 自动创建新文件夹
- **0 操心**：用户不需要手动选择或确认

---

## 🎯 优化目标

1. **简化架构**：从 7 层匹配器 → 1 个统一匹配器 + 标签增强
2. **解决冷启动**：利用 `name_embedding` 支持空文件夹匹配
3. **提升准确率**：标签增强 +5%~+15%
4. **降低复杂度**：移除动态权重、重排序、场景检测等复杂逻辑

| 原匹配器      | 状态                | 原因                              |

## 📐 技术实现

### 1. 统一向量搜索 SQL 函数（核心）

**文件位置**：`supabase/migrations/20251209_add_search_folders_unified.sql`

```sql
-- 统一搜索函数：合并 profile + name 向量匹配
CREATE OR REPLACE FUNCTION search_folders_unified(
  p_user_id UUID,
  p_embedding vector(1024),
  p_limit INT DEFAULT 5
)
RETURNS TABLE (
  folder_id BIGINT,
  folder_name TEXT,
  similarity FLOAT,
  match_type TEXT,
  bookmark_count INT,
  top_tags TEXT[]
) AS $$
BEGIN
  RETURN QUERY
  WITH all_matches AS (
    -- 有内容的文件夹：用 profile_embedding
    SELECT
      fp.folder_id,
      f.name AS folder_name,
      1 - (fp.profile_embedding <=> p_embedding) AS similarity,
      'profile'::TEXT AS match_type,
      fp.bookmark_count,
      fp.top_tags
    FROM folder_profiles fp
    JOIN folders f ON f.id = fp.folder_id
    WHERE fp.user_id = p_user_id
      AND f.deleted_at IS NULL
      AND f.is_system = FALSE
      AND fp.profile_embedding IS NOT NULL

    UNION ALL

    -- 空文件夹：用 name_embedding（冷启动支持）
    SELECT
      fp.folder_id,
      f.name AS folder_name,
      (1 - (fp.name_embedding <=> p_embedding)) * 0.85 AS similarity,
      'name'::TEXT AS match_type,
      0 AS bookmark_count,
      ARRAY[f.name]::TEXT[] AS top_tags
    FROM folder_profiles fp
    JOIN folders f ON f.id = fp.folder_id
    WHERE fp.user_id = p_user_id
      AND f.deleted_at IS NULL
      AND f.is_system = FALSE
      AND fp.profile_embedding IS NULL
      AND fp.name_embedding IS NOT NULL
  )
  SELECT * FROM all_matches
  WHERE similarity > 0.4
  ORDER BY similarity DESC
  LIMIT p_limit;
END;
$$ LANGUAGE plpgsql;
```

### 2. 简化分类服务

**文件位置**：`src/lib/classification/services/simple-classification.service.ts`

```typescript
/**
 * V4.1 简化分类服务
 *
 * 核心设计：
 * 1. 统一向量搜索（profile + name embedding）
 * 2. 标签增强（+5%~+15%）
 * 3. 单阈值决策（70%）
 * 4. AI 选择题模式
 */
export class SimpleClassificationService {
  private readonly AUTO_CLASSIFY_THRESHOLD = 70;

  async classify(
    userId: string,
    bookmark: BookmarkInput,
    embedding: number[],
  ): Promise<ClassificationResult> {
    // 1. 统一向量搜索（单次 SQL）
    const candidates = await this.searchFoldersUnified(userId, embedding);

    if (candidates.length === 0) {
      return this.aiCreateFolder(bookmark);
    }

    // 2. 标签增强（内存计算）
    const boostedCandidates = this.applyTagBoost(
      candidates,
      bookmark.tags || [],
    );
    boostedCandidates.sort((a, b) => b.score - a.score);
    const best = boostedCandidates[0];

    // 3. 简化决策
    if (best.score >= this.AUTO_CLASSIFY_THRESHOLD) {
      return {
        folderId: best.folderId,
        folderName: best.folderName,
        confidence: best.score,
        action: "classify",
        reason: this.buildReason(best),
      };
    }

    // AI 选择题
    return this.aiSelectFromCandidates(bookmark, boostedCandidates.slice(0, 3));
  }

  private applyTagBoost(candidates, bookmarkTags) {
    return candidates.map((c) => {
      const overlap = bookmarkTags.filter((tag) =>
        c.topTags.some((ft) => ft.toLowerCase().includes(tag.toLowerCase())),
      ).length;
      const boost = Math.min(
        Math.round(
          (overlap / Math.max(bookmarkTags.length, c.topTags.length)) * 15,
        ),
        15,
      );
      return { ...c, score: Math.min(c.score + boost, 100), tagBoost: boost };
    });
  }

  private async aiSelectFromCandidates(bookmark, candidates) {
    const prompt = `书签: "${bookmark.title}"
标签: ${bookmark.tags?.join(", ") || "无"}

选择最合适的文件夹（只回复数字）：
${candidates.map((c, i) => `${i + 1}. ${c.folderName}`).join("\n")}
0. 都不合适，创建新文件夹`;

    const choice = parseInt(await this.callAI(prompt), 10);
    if (choice === 0 || isNaN(choice)) return this.aiCreateFolder(bookmark);

    const selected = candidates[choice - 1];
    return {
      folderId: selected.folderId,
      folderName: selected.folderName,
      confidence: Math.min(selected.score + 10, 95),
      action: "classify",
      reason: `AI 选择: ${selected.folderName}`,
    };
  }
}
```
