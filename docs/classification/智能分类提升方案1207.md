# 智能分类能力提升方案

**文档版本**：v1.0  
**日期**：2025-12-07  
**背景**：当前项目主线为 "收藏 -> AI 摘要 -> 智能分类"。前两步表现良好，但 "智能分类" 能力较弱，经常分错或无法分类（直接进收件箱）。

---

## 1. 核心问题诊断

通过分析 `src/lib/classification` 源码，发现当前分类系统的三个瓶颈：

1.  **过度依赖检索（RAG 局限）**：
    - 当前逻辑：`Bookmark` -> `Vector Search` -> `Candidate Folders` -> `AI Pick One`。
    - **问题**：如果向量检索没找到正确的文件夹（例如 Title 写得含糊，或者该文件夹内数据太少），AI 拿到的选项全是错的，只能"矮子里拔将军"。

2.  **缺乏"上帝视角"（Context 缺失）**：
    - AI 只知道检索到的 3-5 个文件夹，不知道用户其实还有一个更完美的文件夹（因为没被检索到）。
    - 对于新用户（冷启动），没有历史数据，分类系统基本瘫痪。

3.  **推理层级过浅（Prompt 简单）**：
    - 当前的 Prompt 仅让 AI 做选择题，没有要求 AI 进行逻辑推理（Chain of Thought），导致 AI 容易被表面的关键词误导。

---

## 2. 技术升级方案 (Level 1 - Level 3)

### Level 1: Prompt 工程优化 (立即见效)

**目标**：不改代码逻辑，仅通过 Prompt 让 AI 变聪明。

**策略**：引入 **CoT (思维链)** 和 **反思机制**。

**新 Prompt 结构建议**：

```markdown
你是一个专业的知识管理专家。请分析以下内容，并将其归档到最合适的用户文件夹中。

【待分类内容】
标题：{{title}}
AI摘要：{{summary}}
AI标签：{{tags}}

【用户现有文件夹候选】
{{candidate_folders_with_descriptions}}

【思考步骤】

1. **分析本质**：这篇内容的核心主题是什么？（例如：是具体的技术教程，还是宏观的行业分析？）
2. **匹配度评估**：
   - 文件夹 A (React): 内容相关度 90%，用户常存此类内容。
   - 文件夹 B (Coding): 内容相关度 60%，太宽泛。
3. **决策**：选择最匹配的文件夹。如果没有合适的，请建议新建一个标准化的文件夹名称。

【输出格式 (JSON)】
{
"thought": "简短的思考过程...",
"folderId": 123 | null,
"suggestedNewFolder": "文件夹名" | null,
"confidence": 0-100
}
```

### Level 2: 引入"通用分类体系" (解决冷启动)

**目标**：解决新用户或新领域内容无法分类的问题。

**策略**：

1.  预设一套 **通用分类表**（20-30 个高频分类），如：
    - 技术/开发
    - 产品/设计
    - 商业/财经
    - 生活/健康
    - 工具/资源
2.  **双重映射逻辑**：
    - 第一步：AI 将内容归入 "通用分类"（如 "前端开发"）。
    - 第二步：查找用户是否有 "前端开发" 及其近义词（如 "Web", "Coding", "JS"）的文件夹。
    - 第三步：如果匹配成功 -> 归入；如果失败 -> **建议创建 "前端开发" 文件夹**。

**代码改动点**：

- 在 `src/lib/classification/constants.ts` 中定义 `UNIVERSAL_CATEGORIES`。
- 在 `AIRecommender` 中，如果找不到合适的 `folderId`，尝试匹配通用分类。

### Level 3: 反向语义检索 (大幅提升召回率)

**目标**：解决"明明有这个文件夹，却没被搜出来"的问题。

**策略**：

- **原流程**：User Query -> Vector Search -> Folders
- **新流程 (Query Expansion)**：
  1.  User Content -> AI Generate **Keywords** (e.g., 内容是关于 "useEffect"，AI 生成关键词 "React", "Frontend", "JavaScript")。
  2.  Use **Keywords** -> Vector Search -> Folders。
  3.  这样即使 Title 里没有 "React" 字眼，也能搜出 "React" 文件夹。

## 3. 交互体验升级 (Frontend)

提升智能分类不仅仅是后端准确率的问题，更是用户信任感的问题。

### 3.1 "待整理" 建议 (Smart Suggestions)

- **现状**：要么直接进文件夹（用户不知道分对了没），要么进收件箱（用户觉得 AI 没用）。
- **改进**：
  - 对于置信度 **60% - 85%** 的内容，放入收件箱，但**附带 AI 建议**。
  - **UI 表现**：收件箱列表项底部显示一个胶囊气泡 —— `💡 建议归入：产品设计 [确认] [拒绝]`。
  - **收益**：用户只需点击一下即可归档，同时每一次点击都是对模型的 **RLHF (反馈强化学习)** 训练数据。

### 3.2 文件夹"画像"可视化

- 在文件夹设置页，展示 AI 对该文件夹的理解：
  - "AI 认为此文件夹主要存放：**Vue.js, React, 前端框架** 相关内容。"
  - 让用户知道 AI 的"脑回路"，如果 AI 理解错了，用户可以手动修正描述。
