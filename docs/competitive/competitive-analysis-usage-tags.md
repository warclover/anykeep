# 用途标签功能竞品分析报告

> **分析日期**: 2025-12-04
> **分析目标**: 对比同类产品的标签/分类系统，寻找用途标签功能的借鉴点

---

| --------------- | ----------- | ---------------------------- | ------------------------------- |
| **Raindrop.io** | 书签管理    | 标签 + 收藏夹 + 筛选器       | ⚠️ 部分（收藏夹可作用途分类）   |

## 二、各产品详细分析

### 1. Raindrop.io（书签管理标杆）

**标签系统特点**：

- 支持为书签添加多个标签
- 标签 + 收藏夹双维度组织
- 支持嵌套收藏夹（最多3层）
- 强大的筛选器（按类型/标签/日期组合筛选）

**分类机制**：

```
收藏夹（文件夹概念）
  └── 书签
       └── 标签（多对多）
```

**亮点功能**：

- 🔥 **筛选器保存**: 可将复杂筛选条件保存为"智能收藏夹"
- 🔥 **类型自动识别**: 自动区分文章/视频/图片/文档
- 内容摘要自动生成

**缺失**：

- ❌ 没有预设的"用途型"标签
- ❌ 标签无颜色区分
- ❌ 标签无分组概念

---

### 2. Cubox（国产收藏工具）

**标签系统特点**：

- 基础标签 + 文件夹分类
- **智能文件夹**（核心特色）: 根据条件自动归集

**智能文件夹示例**：

```
- 来自 Medium 的文章
- 来自知乎的回答
- 类型是文章的
- 收藏但没读过的
- 最近 7 天收藏的
```

**亮点功能**：

- 🔥 **AI 摘要**: 自动生成内容摘要
- 🔥 **智能文件夹**: 条件组合自动筛选
- 🔥 **网页标注**: 高亮和批注功能

**与 AnyKeep 对比**：

- Cubox 的智能文件夹 ≈ AnyKeep 的筛选条件组合
- Cubox 无预设用途标签，需用户自建

---

### 3. Eagle（素材管理神器）

**标签系统特点**：

- **多维度标签**: 同一素材可贴多个标签
- **标签分组**: 标签可按类别组织
- **智能标签推荐**: 输入时自动建议已有标签
- **最近使用标签**: 快速批量标记

**标签交叉筛选**：

```
✓ 极简风格
✓ UI 设计
✓ 深色模式
→ 同时满足3个标签的素材
```

**🔥 值得借鉴**：

| Eagle 特性   | AnyKeep 借鉴点                |
| ------------ | ----------------------------- |
| **标签分组** | 用途标签 vs 内容标签 分组展示 |
| **智能推荐** | 输入时推荐已有标签            |
| **最近使用** | 快速选择常用用途标签          |
| **颜色区分** | 不同分组标签用不同颜色        |
| **交叉筛选** | 用途 × 平台 × AI标签 联合筛选 |

---

### 4. Notion（状态属性系统）

**分类机制**：

- **Status 属性**: 预设状态（Not Started / In Progress / Done）
- **Select 属性**: 单选标签（可自定义颜色）
- **Multi-select 属性**: 多选标签
- **Relation + Rollup**: 实现多级标签体系

**Status 属性特点**：

```
┌─────────────────────────────────────┐
│ Status: [🔴 Not Started]            │
│         [🟡 In Progress]            │
│         [🟢 Done]                   │
└─────────────────────────────────────┘
```

- 预设状态 + 可自定义
- 颜色区分
- 支持分组显示

**🔥 值得借鉴**：

| Notion 特性    | AnyKeep 借鉴点                                           |
| -------------- | -------------------------------------------------------- |
| **预设状态**   | 4个预设用途标签（下次分享用/值得复读/优质经验/值得关注） |
| **颜色系统**   | 每个用途标签固定颜色                                     |
| **分组展示**   | 按用途标签分组查看                                       |
| **自定义扩展** | 允许用户添加自定义用途标签                               |

---

### 5. flomo（卡片笔记）

**标签系统特点**：

- 纯标签驱动（无文件夹）
- 标签嵌套（`#父标签/子标签`）
- 每日回顾功能

**回顾机制**：

```
设定回顾条件：
- 排除临时标签
- 只回顾"知识点"标签下的内容
- 随机展示过往笔记
```

**🔥 值得借鉴**：

| flomo 特性   | AnyKeep 借鉴点                         |
| ------------ | -------------------------------------- |
| **标签嵌套** | 可考虑用途标签下再细分                 |
| **每日回顾** | 按用途标签回顾（如每天回顾"值得复读"） |
| **标签统计** | 显示各用途标签数量                     |

---

### 6. Pocket / Instapaper（稍后读）

**Pocket 特点**：

- 标签系统（类似 Gmail）
- 收藏（Favorite）功能
- 归档（Archive）功能
- 已读/未读状态

**Instapaper 特点**：

- 文件夹系统（非标签）
- 喜欢（Like）功能
- 高亮（Highlight）功能
- 归档功能

**缺失**：

- ❌ 无预设用途标签
- ❌ 标签无分类/分组
- ❌ 无颜色区分

## 四、核心借鉴点总结

### 🔥 高优先级借鉴

| 来源产品     | 借鉴功能        | 应用到 AnyKeep                          |
| ------------ | --------------- | --------------------------------------- |
| **Notion**   | Status 预设状态 | 4个预设用途标签 + 固定颜色              |
| **Eagle**    | 标签分组        | 用途标签 vs AI标签 vs 普通标签 分区展示 |
| **Eagle**    | 智能推荐        | 创建时推荐常用/最近用途标签             |
| **Raindrop** | 筛选器组合      | 用途 × 平台 × 排序 联合筛选             |
| **Cubox**    | 智能文件夹      | 保存筛选条件为快捷入口                  |

### ⭐ 中优先级借鉴

| 来源产品   | 借鉴功能 | 应用到 AnyKeep                         |
| ---------- | -------- | -------------------------------------- |
| **flomo**  | 每日回顾 | 按用途标签回顾（如"值得复读"每日推送） |
| **Eagle**  | 最近使用 | 显示最近使用的用途标签                 |
| **Notion** | 分组视图 | 首页按用途标签分组展示                 |

### 💡 创新差异点

AnyKeep 相比竞品的独特优势：

1. **用途标签 + AI标签 双轨制**
   - 竞品要么只有用户标签，要么只有AI标签
   - AnyKeep 两者兼备且清晰区分

2. **预设 + 自定义 结合**
   - 提供 4 个高频用途预设
   - 允许无限自定义扩展

3. **视觉层级清晰**
   - 用途标签（用户意图）优先展示
   - AI 标签（内容分类）辅助展示

## 六、结论

### 市场空白

经过分析，**没有产品**完整实现"用途标签"这一概念：

- Notion 的 Status 最接近，但面向任务管理场景
- 其他产品的标签系统都是**内容分类导向**，而非**用户意图导向**

### AnyKeep 定位

AnyKeep 的用途标签填补了市场空白：

```
传统标签系统                    AnyKeep 用途标签
─────────────                   ────────────────
"这是什么内容？"        →       "我为什么要收藏它？"
React, 前端, 性能               下次分享用, 值得复读

内容属性导向                    用户意图导向
```

### 核心竞争力

1. **预设 + 自定义**: 降低使用门槛，保留灵活性
2. **双轨标签系统**: 用途标签（意图）+ AI标签（内容）
3. **视觉区分**: 颜色编码，一眼识别
4. **筛选联动**: 多维度组合筛选

---

**建议**: 在产品宣传时强调"用途标签"的独特价值——帮助用户回答"我为什么收藏这个"，而不仅仅是"这个内容是什么"。
