## 根因分析

### 1. Folder 类型系统不一致

**问题**: 项目中存在两个 Folder 类型定义：

| 类型              | 位置                                            | 特点                             |
| ----------------- | ----------------------------------------------- | -------------------------------- | ------ |
| `FolderWithStats` | `src/types/domain/folder.ts`                    | Crystal Growth 字段为可选 (`?:`) |
| `FolderWithCount` | `src/components/folders/folder-action-menu.tsx` | Crystal Growth 字段为必填 (`     | null`) |

**TypeScript 行为**:

```typescript
// 可选字段
ai_generation_source?: string | null;  // 类型为 string | null | undefined

// 必填字段
ai_generation_source: string | null;   // 类型为 string | null
```

### 2. Classification 架构变更

V5.5 重构改变了核心类型：

| 旧类型                                                         | 新类型                                          |
| -------------------------------------------------------------- | ----------------------------------------------- |
| `RuleType: "url" \| "title" \| "content" \| "domain" \| "tag"` | `RuleType: "positive" \| "negative"`            |
| `PatternType: "exact" \| "contains" \| ...`                    | `PatternType: "keyword" \| "regex" \| "domain"` |
| `rule.confidence`                                              | 已移除，使用 `rule.priority`                    |

### 3. Supabase 类型生成

Supabase 生成的类型使用 `null`，但 TypeScript 可选字段默认添加 `undefined`。
