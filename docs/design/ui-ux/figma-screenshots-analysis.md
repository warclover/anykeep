## 📸 截图1：首页 - 我的收藏（网格视图）

### 页面结构

**顶部区域**：

```
┌─────────────────────────────────────────────────────────────┐
│ AnyKeep  |  我的收藏                                  [网格] [列表] │
│          |  共 8 条收藏                                           │
│                                                                │
│  🔍 搜索收藏内容，解签或作者...                                 │
│                                                                │
│  [全部] [微信] [小红书] [B站] [知乎]                            │
└─────────────────────────────────────────────────────────────┘
```

**筛选标签栏设计**：

- **"全部"**：黑色背景 + 白色文字（选中态）
- **其他平台**：灰色文字（未选中态）
- 标签采用 pill 样式，圆角设计
- 标签之间有适当间距

**卡片网格布局**：

- 3 列网格，每列间距约 24px
- 卡片设计：
  - **封面**：16:9 比例，占据卡片顶部 60% 空间
  - **标题**：2 行固定高度，超出省略
  - **标签区**：
    - AI 徽章（粉红色/紫色）在最左侧
    - 后跟 2-3 个内容标签（灰色背景）
  - **底部元信息**：作者 + 时间（灰色小字）

**左侧导航栏**：

```
首页     👈 高亮选中
搜索
收藏夹
数据
设置
─────────
深色模式
+ 添加收藏  （黑色按钮，宽度占满）
```

**右上角功能**：

- 网格视图图标（当前激活）
- 列表视图图标

### 设计细节

**颜色方案**：

- 选中态标签：`#000000` 背景 + `#FFFFFF` 文字
- AI 徽章：粉红色 `#FF4081` 或 `#E91E63`
- 卡片阴影：subtle shadow, `0 2px 8px rgba(0,0,0,0.08)`

**间距规范**：

- 顶部标题到筛选栏：24px
- 筛选栏到卡片网格：32px
- 卡片间距（grid gap）：24px
- 卡片内边距：16px

**与当前实现对比**：
| 设计元素 | Figma 设计 | 当前实现 | 差异 |
|---------|-----------|---------|------|
| 顶部筛选栏 | ✅ 有 | ❌ 无 | **需要添加** |
| 视图切换 | ✅ 网格/列表 | ❌ 仅网格 | **需要添加** |
| 封面比例 | 16:9 | 不固定 | **需要调整** |
| 标题高度 | 固定2行 | 动态 | **需要固定** |
| AI 徽章颜色 | 粉红色 | 紫色 | **需要确认** |
| 添加按钮 | 底部黑色 | 顶部蓝色 | **需要调整** |
