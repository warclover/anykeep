## 1. 设计系统概述

### 1.1 设计原则

```
AnyKeep 设计原则
├─ 🎯 效率优先
│  └─ 操作路径最短，核心功能3步内完成
│
├─ 🧘 简洁克制
│  └─ 去除一切不必要的元素，保持界面呼吸感
│
├─ 🤖 智能感知
│  └─ AI增强的视觉反馈，让用户感受到智能
│
└─ 🎨 品质精致
   └─ 细节打磨，动画流畅，图标精美
```

### 1.2 设计语言

**风格定位：** 现代极简 (Modern Minimalism)

- **色彩：** 清新、专业、有温度
- **布局：** 卡片化、留白充足
- **动效：** 微妙、流畅、有意义
- **字体：** 清晰易读、层次分明

## 3. 字体系统

### 3.1 字体家族

```css
/* iOS */
--font-family-ios:
  -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;

/* Android */
--font-family-android: "Noto Sans SC", "Roboto", "Droid Sans", sans-serif;

/* 通用 */
--font-family:
  system-ui, -apple-system, "Segoe UI", "Roboto", "Helvetica Neue", "Arial",
  sans-serif;

/* 数字/代码 */
--font-family-mono: "SF Mono", "Menlo", "Monaco", "Courier New", monospace;
```

### 3.2 字体大小阶梯

```css
/* 标题 */
--font-size-h1: 28px; /* 页面主标题 */
--font-size-h2: 24px; /* 次级标题 */
--font-size-h3: 20px; /* 三级标题 */
--font-size-h4: 18px; /* 四级标题 */

/* 正文 */
--font-size-body-large: 16px; /* 大正文 */
--font-size-body: 15px; /* 标准正文 */
--font-size-body-small: 14px; /* 小正文 */

/* 辅助 */
--font-size-caption: 13px; /* 说明文字 */
--font-size-mini: 12px; /* 最小文字 */
```

### 3.3 字重 (Font Weight)

```css
--font-weight-regular: 400; /* 常规 */
--font-weight-medium: 500; /* 中等（推荐用于标题） */
--font-weight-semibold: 600; /* 半粗体 */
--font-weight-bold: 700; /* 粗体 */
```

### 3.4 行高 (Line Height)

```css
--line-height-tight: 1.2; /* 紧凑（标题） */
--line-height-normal: 1.5; /* 标准（正文） */
--line-height-loose: 1.8; /* 宽松（长文本） */
```

### 3.5 字体使用规范

| 元素          | 字号 | 字重 | 行高 | 颜色               |
| :------------ | :--- | :--- | :--- | :----------------- |
| **页面标题**  | 28px | 600  | 1.2  | `--text-primary`   |
| **卡片标题**  | 16px | 500  | 1.4  | `--text-primary`   |
| **正文**      | 15px | 400  | 1.5  | `--text-primary`   |
| **次要信息**  | 14px | 400  | 1.4  | `--text-secondary` |
| **标签/时间** | 13px | 400  | 1.2  | `--text-tertiary`  |
| **AI摘要**    | 14px | 400  | 1.6  | `--text-secondary` |

```css
--spacing-xs: 4px; /* 0.5x */

--spacing-lg: 24px; /* 3x */
--spacing-xl: 32px; /* 4x */
--spacing-2xl: 40px; /* 5x */

```

### 5.2 页面安全区

```css
/* 页面左右边距 */
--page-padding-horizontal: 16px;

/* 页面顶部安全区（StatusBar + NavBar） */
--safe-area-top: env(safe-area-inset-top);

/* 页面底部安全区（iPhone Home Indicator） */
--safe-area-bottom: env(safe-area-inset-bottom);
```

### 5.3 卡片布局规范

```
卡片结构
┌────────────────────────────────┐
│  [封面图]                       │ ← 16:9 或 1:1
│  ↑ 上边距：0                    │
│  ↓ 下边距：12px                 │
├────────────────────────────────┤
│  [标题]                         │ ← 字号16px，最多2行
│  ↑ 上边距：12px                 │
│  ↓ 下边距：8px                  │
├────────────────────────────────┤
│  [AI摘要]                       │ ← 字号14px，最多3行
│  ↑ 上边距：8px                  │
│  ↓ 下边距：8px                  │
├────────────────────────────────┤
│  #标签1 #标签2                  │ ← 横向滚动
│  ↑ 上边距：8px                  │
│  ↓ 下边距：12px                 │
├────────────────────────────────┤
│  📍小红书 • 3个月前              │ ← 平台标识 + 时间
│  ↑ 上边距：12px                 │
│  ↓ 下边距：12px                 │
└────────────────────────────────┘
   ← 左右内边距：16px →
```

### 5.4 栅格系统

**屏幕宽度：** 375px（iPhone SE基准）
**列数：** 12列
**列间距：** 16px

```
瀑布流布局（首页）
├─ 小屏（<375px）：单列
├─ 标准屏（375-768px）：双列
└─ 大屏（>768px）：三列
```

## 8. 交互动画规范

### 8.1 动画时长标准

```css
/* 极快 - 微小元素 */
--duration-instant: 100ms;

/* 快速 - 小元素 */
--duration-fast: 200ms;

/* 标准 - 常规元素 */
--duration-normal: 300ms;

/* 慢速 - 大元素 */
--duration-slow: 500ms;

/* 缓动函数 */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹性效果 */
```

### 8.2 核心动画场景

#### 收藏成功动画

```css
@keyframes collect-success {
  0% {
    transform: scale(1);
    opacity: 1;
  }
  50% {
    transform: scale(0.95);
  }
  100% {
    transform: scale(0) translateY(-200px);
    opacity: 0;
  }
}

/* 卡片飞向搜索框 */
.card-fly-to-search {
  animation: collect-success 600ms var(--ease-in-out);
}
```

**视觉效果：**

```
1. 卡片微缩（0-300ms）
2. 飞向顶部搜索框（300-600ms）

```

#### 页面转场动画

```css
/* 页面推入 */
@keyframes page-slide-in {
  from {

}
```

## 10. 暗黑模式 (Dark Mode)

### 10.1 暗黑模式色彩

```css
/* 暗黑模式变量 */
@media (prefers-color-scheme: dark) {
  :root {
    /* 背景色 */
    --bg-primary: #121212;
    --bg-secondary: #1e1e1e;
    --bg-tertiary: #2c2c2c;

    /* 文字色 */
    --text-primary: #ffffff;
    --text-secondary: #b0b0b0;
    --text-tertiary: #808080;

    /* 边框色 */
    --border-light: #333333;
    --border-medium: #404040;

    /* 卡片阴影 */
    --shadow-card: 0 2px 8px rgba(0, 0, 0, 0.4);
  }
}
```

### 10.2 暗黑模式适配规范

| 元素         | 浅色模式 | 暗黑模式 | 说明               |
| :----------- | :------- | :------- | :----------------- |
| **页面背景** | #FFFFFF  | #121212  | 纯黑避免烧屏       |
| **卡片背景** | #FAFAFA  | #1E1E1E  | 对比度适中         |
| **主色**     | #2196F3  | #64B5F6  | 暗模式使用更亮的蓝 |
| **文字**     | #1A1A1A  | #FFFFFF  | 高对比度           |
| **分割线**   | #EEEEEE  | #333333  | 低对比度           |

### 10.3 暗黑模式设计要点

```
暗黑模式设计原则
├─ 避免纯黑（#000000）→ 使用 #121212
├─ 降低色彩饱和度 → 主色从500改为400
├─ 增强文字对比度 → 白色文字透明度90%
└─ 减少阴影强度 → 使用更柔和的阴影
```
