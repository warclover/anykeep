---

## 一、设计理念

```
核心原则: 80/20 法则 + 用户自主权

默认模式: 内联紧凑条 (Inline Mode) → 80% 用户偏好极简
可选模式: 浮动入口 + 抽屉 (Drawer Mode) → 20% 用户需要更多控制
切换方式: 设置页 + 组件内快捷切换
```

---

## 二、当前设计问题诊断

| 问题维度     | 具体问题                         | 影响                         |
| ------------ | -------------------------------- | ---------------------------- |
| **视觉设计** | 黄色警示框 → 传递"警告/错误"心智 | 用户产生焦虑感而非期待感     |
| **空间占用** | 向下展开弹窗 → 挤占主内容区      | 打断浏览心流，每次刷新都出现 |
| **加载体验** | 转圈圈在醒目位置 → 强制用户等待  | 即使 0 条消息也有视觉噪音    |
| **信息密度** | 卡片空白过多、层级混乱           | 信息获取效率低               |
| **操作设计** | 确认按钮过大，编辑/拒绝过小      | 操作不平衡，违反 Fitts 定律  |

## 四、模式切换设计

### 4.1 快捷切换入口

**内联模式下**：点击 `[⚙️]` 显示下拉菜单

```
┌─────────────────────┐
│ 🔄 切换到浮动模式    │
│ ⚙️ 通知设置          │
└─────────────────────┘
```

**抽屉模式下**：底部显示 `[切换到内联模式 ↩]`

### 4.2 设置页配置

在 **设置 → 显示偏好** 中添加：

```
┌─────────────────────────────────────────────────────────────────┐
│  AI 分类建议展示方式                                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ○ 内联紧凑条（推荐）                                            │
│    在首页顶部显示一行通知，可展开查看详情                          │
│                                                                 │
│  ○ 浮动按钮 + 侧边抽屉                                           │
│    在右下角显示浮动按钮，点击打开侧边面板                          │
│                                                                 │
│  ☑ 高置信度建议自动确认 (≥90%)                                   │
│    置信度达到 90% 以上的建议将自动确认，无需手动操作                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 八、视觉规格汇总

### 8.1 颜色方案

| 元素     | Light Mode                                        | Dark Mode                             |
| -------- | ------------------------------------------------- | ------------------------------------- |
| 背景渐变 | `from-violet-50 to-indigo-50`                     | `from-violet-950/30 to-indigo-950/30` |
| 边框     | `border-violet-200`                               | `border-violet-800`                   |
| 主文字   | `text-violet-900`                                 | `text-violet-100`                     |
| 次要文字 | `text-violet-600`                                 | `text-violet-400`                     |
| 主按钮   | `bg-violet-600 text-white`                        | `bg-violet-500`                       |
| 浮动按钮 | `bg-gradient-to-br from-violet-500 to-indigo-600` | 同左                                  |

### 8.2 尺寸规格

| 元素                   | 尺寸                       |
| ---------------------- | -------------------------- |
| 内联通知条高度（收起） | 48px                       |
| 内联列表项高度         | 44px                       |
| 浮动按钮尺寸           | 48px × 48px                |
| 侧边抽屉宽度           | 420px (桌面) / 100% (移动) |
| 抽屉内卡片高度         | ~100px                     |

### 8.3 动效规格

| 动效         | 参数                                                |
| ------------ | --------------------------------------------------- |
| 展开/收起    | `duration-200 ease-out`                             |
| 浮动按钮出现 | `scale-0 → scale-100, duration-300`                 |
| 新消息脉冲   | `animate-pulse` (2次后停止)                         |
| 抽屉滑入     | `translateX(100%) → translateX(0), duration-300`    |
| 列表项删除   | `opacity-100 → opacity-0, height → 0, duration-200` |
