# 🎨 设计文档

本目录存放 AnyKeep 项目的产品设计、用户研究和 UI/UX 相关文档。

## 目录说明

### prd/

产品需求文档（Product Requirements Document）。

**存放内容**：

- 完整的产品需求文档
- 功能需求说明
- 用户故事
- 验收标准
- 产品规格说明

**命名示例**：

- `anykeep-prd-v4.2.md`
- `mvp-requirements.md`
- `platform-mapping.md`

---

### ui-ux/

UI/UX 设计规范和原型文档。

**存放内容**：

- UI 设计规范
- 设计系统
- 用户流程图
- 交互原型
- Figma 设计分析

**命名示例**：

- `ui-design-specification.md`
- `user-flow-prototype.md`
- `figma-design-analysis.md`

---

### research/

用户调研、竞品分析和技术调研。

**存放内容**：

- 用户调研报告
- 竞品分析
- 技术选型调研
- 市场分析
- 功能调研

**命名示例**：

- `user-research-report.md`
- `competitor-analysis.md`
- `tech-research-ai-optimization.md`

---
