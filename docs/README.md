## 文档命名规范

### 文件命名规则

1. **使用英文命名**：优先使用英文，便于跨平台兼容
2. **小写字母 + 连字符**：如 `feature-plan.md`、`phase-1-completion.md`
3. **包含日期标识**：如 `weekly-report-2024-12-01.md`、`架构优化1210.md`
4. **语义化命名**：文件名应清晰表达内容

### 文档格式规范

- 所有文档使用 Markdown 格式（`.md`）
- 文档顶部包含标题、日期、作者等元信息
- 使用标准的 Markdown 语法
- 图片使用相对路径引用：`![描述](../assets/screenshots/image.png)`

## 维护指南

### 添加新文档

1. 确定文档类型，选择合适的目录
2. 使用规范的文件命名
3. 在文档顶部添加元信息
4. 更新相关目录的 README（如有必要）

### 归档旧文档

1. 当文档过期或项目阶段完成时，移动到 `archived/` 目录
2. 按年月归档：`archived/YYYY-MM/`
3. 在原目录的 README 中更新文档状态

### 更新文档索引

定期更新此 README 文件，确保：

- 目录结构准确
- 快速导航链接有效
- 重要文档易于发现
