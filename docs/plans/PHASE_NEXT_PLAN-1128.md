## 二、差距分析与风险评估

### 2.1 关键差距

```
高优先级差距 (阻碍核心价值)
├─ F5.2 冷启动引导缺失 → 新用户无法快速理解产品价值
├─ F4.2 Deep Link 不完整 → 无法实现"跳转回源"核心体验
└─ Aha Moment 未优化 → 首次体验可能流失用户

中优先级差距 (影响竞争力)
├─ F1.2 剪贴板嗅探缺失 → 移动端便捷收集体验不足
├─ F3.2 视频时间戳缺失 → 视频内容检索价值降低
└─ F3.3 标签规范化不足 → 标签体系可能混乱

低优先级差距 (可后续迭代)
├─ F1.3 浏览器插件待完善 → PC 端体验可后续优化
└─ Prompt 配置独立化 → 运营效率优化项
```

### 2.2 技术风险

| 风险                 | 概率 | 影响 | 缓解措施                       |
| :------------------- | :--- | :--- | :----------------------------- |
| Deep Link 平台兼容性 | 高   | 中   | 需各平台 Scheme 调研和测试     |
| 视频时间戳提取准确度 | 中   | 中   | 先支持 B 站等有字幕的平台      |
| 剪贴板权限获取       | 中   | 低   | 遵循系统权限规范，提供替代方案 |

### Phase A: 核心体验完善 (Week 1-2)

**目标**: 确保 MVP 核心用户旅程无阻塞

#### A.1 冷启动引导 (F5.2)

**任务描述**: 新用户注册后自动插入 3-5 条高质量示例数据

| 子任务                         | 估时 | 优先级 |
| :----------------------------- | :--- | :----- |
| 设计示例数据集（覆盖主流平台） | 2h   | P0     |
| 实现注册后自动插入逻辑         | 4h   | P0     |
| 添加首次使用引导 UI            | 4h   | P1     |
| 测试各场景                     | 2h   | P0     |

**验收标准**:

- [ ] 新用户注册后首页显示 3-5 条已处理的示例收藏
- [ ] 示例数据包含不同平台（微信、B 站、小红书）
- [ ] 用户可以基于示例立即体验搜索功能

#### A.2 Deep Link 完善 (F4.2)

**任务描述**: 实现点击收藏后跳转到原生 App 的能力

| 子任务                        | 估时 | 优先级 |
| :---------------------------- | :--- | :----- |
| 调研各平台 Deep Link Scheme   | 4h   | P0     |
| 实现 Deep Link 生成逻辑       | 6h   | P0     |
| 收藏详情页"打开原 App"按钮    | 4h   | P0     |
| iOS/Android Capacitor 测试    | 4h   | P0     |
| 降级处理（无 App 时打开网页） | 2h   | P1     |

**平台 Scheme 参考**:

```
B 站: bilibili://video/{bvid}
小红书: xhsdiscover://item/{id}
微信: weixin://dl/business/?...（受限）
抖音: snssdk1128://...
```

**验收标准**:

- [ ] 收藏详情页显示"打开原 App"按钮
- [ ] 点击后成功唤起对应平台 App
- [ ] 未安装 App 时提供浏览器打开方案

#### A.3 Aha Moment 优化

**任务描述**: 确保收藏操作的即时反馈体验

| 子任务                   | 估时 | 优先级 |
| :----------------------- | :--- | :----- |
| 分享接收后立即显示 Toast | 2h   | P0     |
| 添加骨架屏/Shimmer 动画  | 2h   | P0     |
| 实现 WebSocket 实时更新  | 4h   | P1     |
| 测量并优化端到端延迟     | 2h   | P0     |

**验收标准**:

- [ ] 分享链接到收到确认通知 < 200ms
- [ ] AI 处理期间显示优雅的加载状态
- [ ] 处理完成后卡片自动更新

#### A.4 剪贴板智能嗅探 (F1.2)

**任务描述**: App 回到前台时检测剪贴板 URL 并提示收藏

| 子任务                  | 估时 | 优先级 |
| :---------------------- | :--- | :----- |
| 实现剪贴板监听 Hook     | 4h   | P0     |
| 设计浮动提示条 UI       | 2h   | P0     |
| 添加 URL 识别和去重逻辑 | 2h   | P0     |
| 用户偏好设置（开关）    | 2h   | P1     |
| 隐私合规提示            | 2h   | P0     |

**验收标准**:

- [ ] App 回到前台时自动检测剪贴板
- [ ] 检测到 URL 时显示浮动提示条
- [ ] 用户可在设置中关闭此功能
- [ ] 首次使用时显示隐私说明
