## Batch 7: AI 交互 UI (36h)

### 7.1 工具选择器 (10h)

**目标**: 用户可手动选择工具，绕过意图分类

| 工具 | 图标 | 说明                |
| ---- | ---- | ------------------- |
| 自动 | 🤖   | AI 自动判断（默认） |
| 搜索 | 🔍   | 直接执行搜索        |
| 整理 | 📁   | 直接执行整理        |
| 总结 | 📝   | 直接生成总结        |
| 导出 | 📤   | 直接导出            |
| 萃取 | 💡   | 知识萃取            |

**最佳实践方向**:

- ChatGPT 的 GPT 选择器
- YouMind 的工具下拉菜单

### 7.2 快速操作栏 (8h)

**目标**: 消息级别的快捷操作

| 操作     | 功能         | 实现                |
| -------- | ------------ | ------------------- |
| 复制     | 复制消息内容 | navigator.clipboard |
| 重新生成 | 重新执行     | 调用 regenerate API |
| 保存     | 保存到笔记   | 调用 notes API      |
| 导出     | 导出内容     | 复用导出对话框      |
| 👍👎     | 反馈         | 调用 feedback API   |

### 7.3 执行确认组件 (10h)

**目标**: 危险操作前确认

```tsx
<ActionConfirmation
  title="整理方案"
  summary="将移动 12 个书签到「学习笔记」文件夹"
  actions={[
    { type: "move", count: 12, target: "学习笔记" },
    { type: "dedupe", count: 3 },
  ]}
  onConfirm={() => execute()}
  onAdjust={() => openEditor()}
  onCancel={() => cancel()}
/>
```

### 7.4 上下文面板 (8h)

**目标**: 显示/管理引用的内容

### 7B.2 显式工具路由 (10h)

**目标**: 用户手动选择工具时绕过意图分类

```typescript
interface UnifiedRequest {
  message: string;
  conversationId: string;
  explicitTool?: ToolType; // 🆕 用户手动选择的工具
}

// 在 UnifiedEngine 中处理
if (request.explicitTool) {
  // 直接路由到指定工具，跳过意图分类
  return this.executeExplicitTool(request.explicitTool, request.message);
}
```
