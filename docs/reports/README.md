# 📊 开发报告

本目录存放 AnyKeep 项目的各类开发报告、总结和进度文档。

## 目录说明

### weekly/

每周工作总结和进度报告。

**存放内容**：

- 周报（Weekly Report）
- 每周开发总结
- 工作时间统计

**命名示例**：

- `week-1-summary-2024-11-25.md`
- `weekly-report-2024-12-01.md`

---

### phase-completion/

阶段完成报告。

**存放内容**：

- Phase N 完成报告
- 阶段目标达成情况
- 阶段总结和经验教训

**命名示例**：

- `phase-1-completion-report.md`
- `phase-2-completion-report.md`
- `mvp-completion-report.md`

---

### implementation/

功能实现报告。

**存放内容**：

- 单个功能的实现报告
- 技术实现总结
- 遇到的问题和解决方案

**命名示例**：

- `browser-bookmark-implementation-report.md`
- `ai-summary-implementation-report.md`

---

### archived/

历史报告归档。

**存放内容**：

- 过时的进度报告
- 早期的工作总结
- 不再活跃的项目文档

**归档规则**：

- 超过 2 个月的周报自动归档
- 已完成项目的相关报告归档

---

[其他需要说明的内容]
