# 迁移 20251127000005：增强版待整理文件夹（国际化支持）

- ✅ **数据一致性**：增强的唯一约束和检查约束
- ✅ **幂等性**：可安全重复执行
- ✅ **向后兼容**：不影响现有数据

## 🛠️ 故障排除

### 问题 1：迁移执行失败

**症状**：

```
ERROR: duplicate key value violates unique constraint "unique_user_system_folder_active"
```

**原因**：某些用户已有多个 INBOX 系统文件夹

**解决方案**：

```sql
-- 查找重复记录
SELECT user_id, COUNT(*)
FROM public.folders
WHERE is_system = TRUE
  AND system_type = 'INBOX'
  AND deleted_at IS NULL
GROUP BY user_id
HAVING COUNT(*) > 1;

-- 手动清理重复记录（保留最新的）
DELETE FROM public.folders f1
WHERE f1.id NOT IN (
    SELECT MAX(f2.id)
    FROM public.folders f2
    WHERE f2.user_id = f1.user_id
      AND f2.is_system = TRUE
      AND f2.system_type = 'INBOX'
      AND f2.deleted_at IS NULL
    GROUP BY f2.user_id
)
AND f1.is_system = TRUE
AND f1.system_type = 'INBOX'
AND f1.deleted_at IS NULL;
```

### 问题 2：部分用户没有待整理文件夹

**症状**：测试脚本报告有用户缺少待整理文件夹

**解决方案**：

```sql
-- 手动为缺少文件夹的用户创建
INSERT INTO public.folders (user_id, name, is_system, system_type, sort_order)
SELECT
    p.id,
    get_system_folder_name('INBOX', COALESCE(p.settings->>'locale', 'zh-CN')),
    TRUE,
    'INBOX',
    -1
FROM public.profiles p
WHERE NOT EXISTS (
    SELECT 1 FROM public.folders f
    WHERE f.user_id = p.id
      AND f.is_system = TRUE
      AND f.system_type = 'INBOX'
      AND f.deleted_at IS NULL
)
ON CONFLICT (user_id, system_type)
WHERE (is_system = TRUE AND deleted_at IS NULL)
DO NOTHING;
```

### 问题 3：国际化名称显示不正确

**症状**：文件夹名称仍然显示为中文，即使用户设置了其他语言

**可能原因**：

1. 用户的 `profiles.settings->>'locale'` 未正确设置
2. 国际化配置表缺少对应语言

**解决方案**：

```sql
-- 检查用户语言设置
SELECT id, settings->>'locale' as locale FROM public.profiles WHERE id = 'user-id';

-- 检查国际化配置
SELECT * FROM public.system_folder_i18n WHERE locale = 'your-locale';

-- 手动更新用户文件夹名称
UPDATE public.folders
SET name = get_system_folder_name('INBOX', 'en-US')  -- 替换为目标语言
WHERE user_id = 'user-id'
  AND is_system = TRUE
  AND system_type = 'INBOX';
```

## 🔧 自定义配置

```sql
INSERT INTO public.system_folder_i18n (system_type, locale, display_name)

ON CONFLICT (system_type, locale) DO UPDATE
```

### 修改现有语言名称

```sql
-- 修改英文名称
UPDATE public.system_folder_i18n
SET display_name = 'To Sort'
WHERE system_type = 'INBOX' AND locale = 'en-US';

-- 更新所有使用英文的用户的文件夹名称

SET name = 'To Sort'
FROM public.profiles p

  AND f.is_system = TRUE

```


