# 统一认证工具函数实施方案

> 版本：1.0.0
> 日期：2026-02-07
> 状态：待审核

## 1. 背景

### 1.1 问题描述

用户登录后立即访问某些页面时，由于 Supabase session 同步存在延迟，`supabase.auth.getUser()` 可能返回 `null`，导致 API 返回 401 Unauthorized 错误。

### 1.2 已修复案例

| 页面         | 修复方式                           | 提交记录   |
| ------------ | ---------------------------------- | ---------- |
| `/home`      | Server Component 预验证 + 回退机制 | `8971ad8f` |
| `/synthesis` | API 路由添加 V4.2.28 回退机制      | `cf0f68ea` |

### 1.3 问题范围

- **已修复**：2 个
- **潜在问题**：258 个 API 路由文件使用 `supabase.auth.getUser()`

---

## 2. 解决方案

### 2.1 核心思路

创建统一的认证工具函数，实现三级回退机制：

```
1. Middleware 注入的 x-user-id header（最快，~0ms）
2. supabase.auth.getUser()（标准方式，~50-100ms）
3. supabase.auth.getSession()（回退，解决登录后同步延迟）
```

### 2.2 文件结构

```

├── index.ts                      # 统一导出入口

```

## 3. 详细设计

### 3.1 类型定义 (`types.ts`)

```typescript
/**
 * 认证用户信息
 */
export interface AuthenticatedUser {
  /** 用户 ID (UUID) */
  id: string;
  /** 认证来源 */
  source: "header" | "getUser" | "getSession";
}

/**
 * 认证结果
 */
export type AuthResult =
  | { success: true; user: AuthenticatedUser }
  | { success: false; error: "UNAUTHORIZED" | "INVALID_SESSION" };
```

### 3.2 核心函数 (`get-authenticated-user.ts`)

````typescript
/**
 * 统一认证工具函数
 *
 * V4.2.28: 登录后 session 同步延迟的回退机制
 *
 * 认证优先级：
 * 1. Middleware 注入的 x-user-id header（最快）
 * 2. supabase.auth.getUser()（标准方式）
 * 3. supabase.auth.getSession()（回退，解决登录后同步延迟）
 *
 * @example
 * ```typescript
 * // API Route 中使用
 * export async function GET(request: NextRequest) {
 *   const supabase = await createClient();
 *   const userId = await getAuthenticatedUserId(request, supabase);
 *
 *   if (!userId) {
 *     return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
 *   }
 *
 *   // 使用 userId 进行业务操作...
 * }
 * ```
 *
 * @param request - NextRequest 对象（用于读取 Middleware 注入的 header）
 * @param supabase - Supabase 客户端实例
 * @returns 用户 ID 或 null
 */
export async function getAuthenticatedUserId(
  request: NextRequest,
  supabase: SupabaseClient,
): Promise<string | null>;

/**
 * 获取完整认证结果（包含认证来源信息）
 *
 * @param request - NextRequest 对象
 * @param supabase - Supabase 客户端实例
 * @returns 认证结果对象
 */
export async function getAuthenticatedUser(
  request: NextRequest,
  supabase: SupabaseClient,
): Promise<AuthResult>;

/**
 * 简化版：仅通过 Supabase 认证（无 Middleware header）
 *
 * 适用于：
 * - Server Actions（无 request 参数）
 * - 内部调用
 *
 * @param supabase - Supabase 客户端实例
 * @returns 用户 ID 或 null
 */
export async function getAuthenticatedUserIdFromSession(
  supabase: SupabaseClient,
): Promise<string | null>;
````

### 3.3 导出入口 (`index.ts`)

```typescript
export {
  getAuthenticatedUserId,
  getAuthenticatedUser,
  getAuthenticatedUserIdFromSession,
} from "./get-authenticated-user";

export type { AuthenticatedUser, AuthResult } from "./types";
```

## 4. 迁移策略

### 4.1 迁移优先级

#### P0 - 立即迁移（本次实施）

已出现问题或高风险的 API：

| API 路径           | 原因                     |
| ------------------ | ------------------------ |
| `/api/synthesis/*` | 已修复，需重构为统一函数 |

#### P1 - 高优先级（1 周内）

高频使用、非 Keep-Alive 页面的 API：

| API 路径                  | 说明         |
| ------------------------- | ------------ |
| `/api/knowledge-studio/*` | 知识工坊相关 |
| `/api/learning/*`         | 学习中心相关 |
| `/api/monitors/*`         | 监控相关     |
| `/api/distribution/*`     | 分发相关     |

#### P2 - 中优先级（按需迁移）

其他 API，出现问题时迁移或重构时顺便迁移。

### 4.2 迁移步骤

#### 步骤 1：创建工具函数

```bash
# 创建目录和文件
mkdir -p src/lib/auth
touch src/lib/auth/index.ts
touch src/lib/auth/get-authenticated-user.ts
touch src/lib/auth/types.ts
```

#### 步骤 2：迁移 `/api/synthesis/route.ts`

将现有的本地 `getAuthenticatedUserId` 函数替换为统一工具函数：

```diff
- /** UUID 正则表达式 */
- const UUID_REGEX = ...;
-
- async function getAuthenticatedUserId(...) { ... }

+ import { getAuthenticatedUserId } from "@/lib/auth";
```

#### 步骤 3：批量迁移脚本（可选）

对于 P1 优先级的 API，可以使用以下模式进行批量替换：

**查找模式**：

```typescript
const {
  data: { user },
  error: authError,
} = await supabase.auth.getUser();

if (authError || !user) {
  return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
}
```

**替换为**：

```typescript
import { getAuthenticatedUserId } from "@/lib/auth";

const userId = await getAuthenticatedUserId(request, supabase);

if (!userId) {
  return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
}
```

## 附录 B：代码模板

### API Route 迁移模板

```typescript
// 迁移前
import { createClient } from "@/lib/supabase/server";

export async function GET(request: NextRequest) {
  const supabase = await createClient();

  const {
    data: { user },
    error: authError,
  } = await supabase.auth.getUser();

  if (authError || !user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  // 使用 user.id
}

// 迁移后
import { createClient } from "@/lib/supabase/server";
import { getAuthenticatedUserId } from "@/lib/auth";

export async function GET(request: NextRequest) {
  const supabase = await createClient();
  const userId = await getAuthenticatedUserId(request, supabase);

  if (!userId) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  // 使用 userId
}
```
