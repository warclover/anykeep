# AnyKeep 前端功能补全方案

> 创建日期: 2026-02-07

## Context

AnyKeep 项目已实现大量后端 RPC 函数，但缺少对应的前端调用入口。本方案旨在补全这些缺失的前端功能，充分发挥已有的技术投资，提升用户体验。

**问题范围**：

- 8 个高优先级 RPC 函数未被前端调用
- 8 个中优先级 RPC 函数未被充分利用
- 知识图谱、文件夹热度、聚类分析等高价值功能缺少可视化界面

**预期成果**：

- 释放已有后端能力，为用户提供可感知的价值
- 遵循现有架构模式，保持代码一致性

| 类型 | 文件路径                                         |
