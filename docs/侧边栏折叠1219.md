# 侧边栏折叠方案设计

> 日期: 2024-12-19
> 状态: 待实施

## 需求背景

将项目主页左侧菜单做成可折叠/展开的效果，内容区域联动调整。

## 选定方案: A - 图标模式折叠

### 状态流转图

```
                    点击折叠按钮 [«]
    ┌─────────────────────────────────────────┐
    │                                         │
    ▼                                         │
┌───────────┐                          ┌──────┴──────┐
│  折叠态    │  ───悬停侧边栏区域───▶   │   展开态     │
│  (64px)   │                          │   (192px)   │
│  仅图标    │  ◀───鼠标移出 300ms───   │   图标+文字  │
└───────────┘         延迟收起          └─────────────┘
                                              │
                    点击展开按钮 [»]           │
    ┌─────────────────────────────────────────┘
    │
    ▼
  锁定展开态（不再自动折叠）
```

### 动画时序

```
展开动画 (悬停触发):
├─ 0ms    : 检测鼠标进入
├─ 0-200ms: width 64px → 192px (ease-out)
│           opacity 文字 0 → 1
│           main margin-left 64px → 192px
└─ 200ms  : 完成

折叠动画 (鼠标移出):
├─ 0ms    : 检测鼠标移出
├─ 0-300ms: 等待延迟 (防误触)
├─ 300-500ms: width 192px → 64px (ease-in-out)
│             opacity 文字 1 → 0
│             main margin-left 192px → 64px
└─ 500ms  : 完成
```

### 持久化策略

采用 localStorage 持久化：

```typescript
interface SidebarState {
  isCollapsed: boolean; // 是否折叠
  isLocked: boolean; // 是否锁定（用户主动点击展开）
}

const DEFAULT_STATE = {
  isCollapsed: true, // 默认折叠，节省空间
  isLocked: false, // 默认不锁定，支持悬停展开
};
```

## 配置汇总

| 配置项   | 确定值                                 |
| -------- | -------------------------------------- |
| 方案     | A - 图标模式折叠                       |
| 折叠宽度 | 64px                                   |
| 展开宽度 | 192px (现有)                           |
| 展开触发 | 悬停侧边栏区域                         |
| 折叠触发 | 鼠标移出 + 300ms 延迟                  |
| 锁定机制 | 点击 [»] 锁定展开，点击 [«] 解锁并折叠 |
| 持久化   | localStorage 记住折叠/锁定状态         |
| 默认状态 | 折叠 + 未锁定                          |
| 动画时长 | 展开 200ms / 折叠 200ms (延迟后)       |
