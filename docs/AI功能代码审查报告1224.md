**文件**: `src/app/api/agent/confirm/route.ts`

```typescript
// 当前实现
const result = await toolRegistry.execute(
  pendingConfirmation.toolName,
  pendingConfirmation.params,
  context,
);
```

**问题**:

- 该 API 直接调用 `toolRegistry`，只处理 Tool 级别的确认
- 与 `ai-skills/orchestration/confirmation-handler.ts` 完全隔离
- Skills 标记的 `requiresConfirmation` 无法通过此 API 处理
