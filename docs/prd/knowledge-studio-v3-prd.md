## 核心理念

> **三步出稿，专家秘书**
>
> 知识工坊是你的个人专家秘书，三步帮你产出高质量草稿。
> 默认极简，需要时展开——渐进式复杂度设计。

---

## 一、产品定位

### 1.1 极简定义

```
输入内容 → 选择类型 → 获取草稿
```

**就这么简单。**

### 1.2 设计哲学：渐进式复杂度

> **极简不是删除功能，而是隐藏复杂度。**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│         默认路径（80%用户）        高级路径（20%用户）       │
│         ─────────────────         ─────────────────         │
│                                                             │
│         Step 1: 输入              ← 相同                    │
│              ↓                                              │
│         Step 2: 选类型     ───►   [展开] 专业蓝图           │
│              │                    [展开] Briefing 问答      │
│              │                    [展开] 大纲编辑           │
│              ↓                                              │
│         Step 3: 获取结果          ← 相同                    │
│                                                             │
│  ────────────────────────────────────────────────────────── │
│  小白用户：三步搞定               深度用户：需要时展开       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 核心价值

| 你说 | 工坊做 |
|------|--------|
| "帮我写篇公众号文章" | 基于你的素材，生成完整文章 |
| "帮我总结一下这些内容" | 提炼核心要点，结构清晰 |
| "帮我写个简短摘要" | 精简到几百字，保留精华 |
| "帮我出个分析方案" | 专业分析报告，有理有据 |

### 1.4 与 V2 的核心区别

| 维度 | V2（现状） | V3（目标） |
|------|-----------|-----------|
| **流程步骤** | 5-6 步必选 | **3 步默认 + 高级可选** |
| **功能暴露** | 全部外露 | **分层：默认极简 + 高级折叠** |
| **用户心智** | "工具很多，不知道用哪个" | **"说我要什么，直接给我"** |
| **产品定位** | 内容生成工具 | **个人专家秘书** |
| **核心资产** | 可能丢失 | **14 个蓝图等核心能力保留** |

### 3.2 默认层功能（始终可见）

| # | 功能 | 说明 | 必要性 |
|---|------|------|--------|

### 6.3 核心 Hook

```typescript
/**
 * 知识工坊核心 Hook
 */
function useWorkshop() {
  const [step, setStep] = useState<1 | 2 | 3>(1);
  const [input, setInput] = useState<WorkshopInput | null>(null);
  const [config, setConfig] = useState<WorkshopConfig | null>(null);
  const [result, setResult] = useState<WorkshopResult | null>(null);
  const [isGenerating, setIsGenerating] = useState(false);

  // 高级选项状态
  const [showAdvanced, setShowAdvanced] = useState(false);
  const [advanced, setAdvanced] = useState<AdvancedOptions>({
    useBlueprint: false,
    enableBriefing: false,
    enableOutlineEdit: false,
  });

  // 切换高级选项显示
  const toggleAdvanced = () => setShowAdvanced(!showAdvanced);

  // 步骤控制
  const goToStep = (s: 1 | 2 | 3) => setStep(s);
  const nextStep = () => {
    // 如果开启了 Briefing 或 大纲编辑，需要额外步骤
    if (step === 2) {
      if (advanced.enableBriefing && !advanced.briefingAnswers) {
        // 显示 Briefing 面板
        return;
      }
      if (advanced.enableOutlineEdit && !advanced.customOutline) {
        // 先生成大纲，显示编辑面板
        return;
      }
    }
    setStep(prev => Math.min(prev + 1, 3) as 1 | 2 | 3);
  };

  const generate = async () => {
    if (!input || !config) return;
    setIsGenerating(true);
    try {
      const result = await generateContent(input, { ...config, advanced });
      setResult(result);
      setStep(3);
    } finally {
      setIsGenerating(false);
    }
  };

  const reset = () => {
    setStep(1);
    setInput(null);
    setConfig(null);
    setResult(null);
    setShowAdvanced(false);
    setAdvanced({
      useBlueprint: false,
      enableBriefing: false,
      enableOutlineEdit: false,
    });
  };

  return {
    step,
    input,
    config,
    result,
    isGenerating,
    showAdvanced,
    advanced,
    setInput,
    setConfig,
    setAdvanced,
    toggleAdvanced,
    goToStep,
    nextStep,
    generate,
    reset,
  };
}
```

## 九、设计原则

### 9.1 渐进式复杂度原则

| 原则 | 说明 | 实践 |
|------|------|------|
| **默认极简** | 80% 用户不需要高级功能 | 三步默认流程 |
| **按需展开** | 20% 深度用户需要更多控制 | 高级选项折叠 |
| **不丢失价值** | 核心资产保留 | 14 个蓝图、Briefing、大纲编辑 |
| **渐进式学习** | 用户用熟了会探索 | 自然发现高级功能 |

### 9.2 专家秘书原则

| 原则 | 说明 | 实践 |
|------|------|------|
| **懂你所想** | 不需要解释太多 | 输入内容即可推断意图 |
| **专业输出** | 输出质量要高 | 结构清晰、语言专业 |
| **随时待命** | 用完即走，需要再来 | 历史记录随时可查 |
