- **文件**: `src/lib/classification/services/smart-sorting.service.ts`

- **影响**: 待聚类书签（`pending_cluster = true`）永远不会被处理
- **建议修复**: 创建 API `/api/classification/smart-sort` 或定时任务触发

- **文件**: `src/lib/classification/router/cache-manager.ts:564`
- **函数**: `warmupActiveUsers()`
- **问题**: 从未被调用，导致冷启动性能问题

  learningEventHandler,
  initializeLearningEventHandler,
} from "./learning/learning-event-handler";

    initializeLearningEventHandler({

}
