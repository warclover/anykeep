## 1. 项目概述

**AnyKeep** 是一款跨平台智能内容聚合工具，帮助用户统一管理来自微信公众号、B站、小红书、浏览器等多平台的收藏内容。

### 核心价值

| 功能        | 描述                         |
| ----------- | ---------------------------- |
| 一键收藏    | 通过系统分享菜单快速保存内容 |
| AI 智能处理 | 自动生成摘要、标签、分类     |
| 语义搜索    | 基于向量检索的智能搜索       |
| 跨设备同步  | 实时数据同步                 |
| 知识图谱    | 书签间关联关系可视化         |

### 当前阶段

**开发阶段** - 核心功能已基本完成，进入优化和完善阶段。

| 索引                           | 表              | 列        | 说明    |

| `bookmarks_embedding_idx`      | bookmarks       | embedding | IVFFlat |

### 7.3 RLS 策略

所有核心表均启用 Row Level Security，确保用户数据隔离：

```sql
-- 示例：bookmarks 表策略
CREATE POLICY "Users can view own bookmarks" ON bookmarks
  FOR SELECT USING (auth.uid() = user_id);

CREATE POLICY "Users can insert own bookmarks" ON bookmarks
  FOR INSERT WITH CHECK (auth.uid() = user_id);
```

## 8. 核心模块详解

### 8.1 AI Agent 系统

**路径**: `src/lib/ai-agent/`

```
ai-agent/
├── core/                    # 核心逻辑
│   ├── knowledge-agent.ts   # 知识库 Agent
│   ├── agent-memory.ts      # 对话记忆
│   └── types.ts             # 核心类型
├── tools/                   # Tool 实现
│   ├── types.ts             # Tool 类型定义
│   ├── tool-registry.ts     # Tool 注册表
│   ├── query/               # 查询 Tools (8)
│   ├── read/                # 阅读 Tools (1)
│   ├── search/              # 搜索 Tools (2)
│   ├── action/              # 操作 Tools (3)
│   ├── smart-list/          # 智能列表 Tools (3)
│   ├── folder/              # 文件夹 Tools (16)
│   └── export/              # 导出 Tools (3)
└── services/                # 辅助服务
    └── quick-stats.service.ts
```

**核心设计**:

- Vercel AI SDK v5 兼容
- Zod Schema 参数验证
- PendingConfirmation 确认流程
- 风险等级分类 (low/medium/high)

### 8.2 智能分类系统

**路径**: `src/lib/classification/`

```
classification/
├── classifier.ts            # 分类器主逻辑
├── embedding.ts             # 向量嵌入
├── folder-profile.ts        # 文件夹特征
├── similarity.ts            # 相似度计算
├── feedback.ts              # 反馈学习
├── ab-testing.ts            # A/B 测试
└── types.ts                 # 类型定义
```

**分类流程**:

1. 提取书签文本特征
2. 生成 Embedding 向量
3. 计算与文件夹 Profile 相似度
4. 排序候选文件夹
5. 应用置信度阈值
6. 返回分类结果

### 8.3 数据导出系统

**路径**: `src/lib/export/`

```
export/
├── services/
│   └── export.service.ts    # 导出服务
├── formatters/              # 格式化器 (策略模式)
│   ├── csv.formatter.ts
│   ├── markdown.formatter.ts
│   ├── obsidian.formatter.ts
│   ├── json.formatter.ts
│   └── html.formatter.ts
├── utils/                   # 工具函数
├── constants.ts             # 常量配置
└── types.ts                 # 类型定义
```

**设计原则**:

- 策略模式：每种格式独立 Formatter
- 单一职责：服务层/格式化层/UI层分离
- 可扩展：新增格式只需添加 Formatter
