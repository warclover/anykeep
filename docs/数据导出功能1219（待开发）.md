## 1. 功能概述

### 1.1 背景与目标

AnyKeep 当前的数据导出功能较为基础，无法满足知识管理者和技术用户的核心需求：

**用户痛点**：

- 📊 **数据分析用户**：无法导出 CSV 在 Excel/表格中分析
- 📝 **笔记工具迁移**：Markdown 格式不兼容 Obsidian/Notion 的 Frontmatter
- 📁 **批量整理用户**：无法按文件夹/标签筛选导出
- 💾 **数据备份用户**：缺少定期自动备份能力

**设计原则**：

```
聚焦最高频 > 避免大而全
极致体验 > 功能堆砌
解耦设计 > 耦合实现
```

### 1.2 目标用户画像

| 用户类型   | 核心需求                | 频率  |
| ---------- | ----------------------- | ----- |
| 知识管理者 | 导出到 Obsidian/Notion  | 周/月 |
| 数据分析师 | CSV 导出做统计分析      | 月    |
| 技术用户   | JSON API 或批量导出备份 | 季度  |
| 普通用户   | 简单下载备份            | 年    |

## 2. 竞品分析与最佳实践

### 2.1 竞品导出功能对比

| 产品         | CSV | Markdown | HTML | JSON | 筛选导出 | 自动备份 | 特色功能    |
| ------------ | --- | -------- | ---- | ---- | -------- | -------- | ----------- |
| **Notion**   | ✅  | ✅       | ✅   | ❌   | ✅       | ✅(企业) | PDF 导出    |
| **Raindrop** | ✅  | ❌       | ✅   | ❌   | ✅       | ✅(Pro)  | 自动云备份  |
| **Cubox**    | ✅  | ✅       | ✅   | ❌   | ✅       | ❌       | 自定义动作  |
| **Pocket**   | ✅  | ❌       | ❌   | ✅   | ❌       | ❌       | 即将关闭    |
| **Obsidian** | ❌  | ✅       | ✅   | ❌   | N/A      | 本地     | Frontmatter |
| **AnyKeep**  | ❌  | ✅(基础) | ✅   | ✅   | ❌       | ❌       | -           |

### 2.2 竞品最佳实践总结

**Notion 的优秀实践**：

- ✅ 支持导出整个工作区或单个页面
- ✅ Markdown 导出保留完整元数据
- ✅ 大文件异步处理，邮件通知

**Raindrop 的优秀实践**：

- ✅ 两点击导出（选择集合 → 选择格式）
- ✅ 自动备份到 Google Drive/Dropbox
- ✅ 搜索结果可直接导出

**Cubox 的优秀实践**：

- ✅ 自定义快捷动作导出到其他 App
- ✅ 支持批量导出标注为 Markdown
- ✅ URL Schemes 集成第三方应用

**核心借鉴点**：

1. **极简操作**：2-3 步完成导出（Raindrop）
2. **格式完整**：保留所有元数据（Notion）
3. **筛选导出**：支持搜索结果导出（Raindrop）
4. **工具集成**：与笔记工具无缝对接（Cubox）

### 3.1 场景优先级矩阵

基于用户调研和竞品分析，确定最高频场景：

```
                    使用频率
                      ↑
               高     │    ┌─────────────┐
                      │    │ CSV 导出    │ ← P0 最高优先级
                      │    │ 表格分析    │
                      │    └─────────────┘
                      │
                      │    ┌─────────────┐
```

### 3.2 P0 最高频场景详解

#### 场景 1：CSV 导出做数据分析（最高频）

**用户故事**：

> 作为一个知识管理者，我想把收藏导出为 CSV，以便在 Excel 中分析阅读习惯。

**典型流程**：

```
用户选择文件夹/标签 → 点击导出 → 选择 CSV → 下载文件 → Excel 打开分析
```

**CSV 字段需求**（按重要性排序）：

1. `title` - 标题
2. `url` - 链接
3. `folder` - 文件夹
4. `created_at` - 收藏时间
5. `platform` - 来源平台
6. `ai_tags` - AI 标签（逗号分隔）
7. `user_tags` - 用户标签
8. `ai_summary` - AI 摘要（截断）
9. `description` - 描述
10. `author` - 作者

#### 场景 2：Markdown 导出到笔记工具（高频）

**用户故事**：

> 作为 Obsidian 用户，我想把收藏导出为带 Frontmatter 的 Markdown，直接导入我的知识库。

**Obsidian 兼容格式示例**：

```markdown
---
title: "文章标题"
url: "https://example.com/article"
author: "作者名"
platform: "微信公众号"
tags:
  - AI
  - 技术
  - 编程
created: 2025-12-19
folder: "技术/AI"
---

# 文章标题

**AI 摘要**：这是 AI 生成的摘要内容...

**原文链接**：[点击访问](https://example.com/article)

## 我的笔记

用户添加的笔记内容...
```

#### 场景 3：筛选导出（中高频）

**用户故事**：

> 作为用户，我想只导出某个文件夹/平台/时间范围的收藏。

**筛选维度**：

- 📁 按文件夹
- 🏷️ 按标签（AI/用户）
- 📱 按平台
- 📅 按时间范围
- ⭐ 按收藏/已读状态

### 7.2 CSV 格式化器

```typescript
// src/lib/export/formatters/csv-formatter.ts

import type { Bookmark } from "@/types/supabase";
import type { ExportFormatOptions } from "../types";

/** CSV 默认字段 */
const DEFAULT_CSV_FIELDS = [
  "title",
  "url",
  "folder",
  "created_at",
  "platform",
  "ai_tags",
  "user_tags",
  "ai_summary",
  "description",
  "author",
];

/** 字段映射 */
const FIELD_LABELS: Record<string, string> = {
  title: "标题",
  url: "链接",
  folder: "文件夹",
  created_at: "收藏时间",
  platform: "来源平台",
  ai_tags: "AI标签",
  user_tags: "用户标签",
  ai_summary: "AI摘要",
  description: "描述",
  author: "作者",
};

export function formatBookmarksToCSV(
  bookmarks: Array<Bookmark & { folders?: { name: string } | null }>,
  options?: ExportFormatOptions["csv"],
): string {
  const {
    fields = DEFAULT_CSV_FIELDS,
    delimiter = ",",
    includeHeader = true,
    encoding = "utf-8",
  } = options || {};

  const lines: string[] = [];

  // UTF-8 BOM（Excel 中文兼容）
  const bom = encoding === "utf-8" ? "\uFEFF" : "";

  // 表头
  if (includeHeader) {
    const headers = fields.map((f) => FIELD_LABELS[f] || f);
    lines.push(headers.map((h) => escapeCSV(h)).join(delimiter));
  }

  // 数据行
  for (const bookmark of bookmarks) {
    const row = fields.map((field) => {
      const value = getFieldValue(bookmark, field);
      return escapeCSV(value);
    });
    lines.push(row.join(delimiter));
  }

  return bom + lines.join("\n");
}

function getFieldValue(
  bookmark: Bookmark & { folders?: { name: string } | null },
  field: string,
): string {
  switch (field) {
    case "title":
      return bookmark.title || "";
    case "url":
      return bookmark.url || "";
    case "folder":
      return bookmark.folders?.name || "未分类";
    case "created_at":
      return bookmark.created_at
        ? new Date(bookmark.created_at).toLocaleString("zh-CN")
        : "";
    case "platform":
      return bookmark.platform || "";
    case "ai_tags":
      return (bookmark.ai_tags || []).join(", ");
    case "user_tags":
      return (bookmark.user_tags || []).join(", ");
    case "ai_summary":
      // 截断长摘要
      const summary = bookmark.ai_summary || "";
      return summary.length > 200 ? summary.slice(0, 200) + "..." : summary;
    case "description":
      return bookmark.description || "";
    case "author":
      return bookmark.author || "";
    default:
      return "";
  }
}

function escapeCSV(value: string): string {
  if (!value) return "";
  // 包含逗号、引号、换行时需要引号包裹
  if (value.includes(",") || value.includes('"') || value.includes("\n")) {
    return `"${value.replace(/"/g, '""')}"`;
  }
  return value;
}
```

### 7.3 Obsidian Markdown 格式化器

```typescript
// src/lib/export/formatters/obsidian-formatter.ts

import type { Bookmark } from "@/types/supabase";

export function formatBookmarkToObsidian(
  bookmark: Bookmark & { folders?: { name: string } | null },
): string {
  const lines: string[] = [];

  // YAML Frontmatter
  lines.push("---");
  lines.push(`title: "${escapeYaml(bookmark.title)}"`);
  lines.push(`url: "${bookmark.url}"`);

  if (bookmark.author) {
    lines.push(`author: "${escapeYaml(bookmark.author)}"`);
  }

  if (bookmark.platform) {
    lines.push(`platform: "${bookmark.platform}"`);
  }

  // 标签
  const tags = [...(bookmark.ai_tags || []), ...(bookmark.user_tags || [])];
  if (tags.length > 0) {
    lines.push("tags:");
    tags.forEach((tag) => {
      lines.push(`  - ${escapeYaml(tag)}`);
    });
  }

  lines.push(`created: ${bookmark.created_at?.slice(0, 10) || ""}`);

  if (bookmark.folders?.name) {
    lines.push(`folder: "${escapeYaml(bookmark.folders.name)}"`);
  }

  lines.push("---");
  lines.push("");

  // 标题
  lines.push(`# ${bookmark.title}`);
  lines.push("");

  // AI 摘要
  if (bookmark.ai_summary) {
    lines.push("## AI 摘要");
    lines.push("");
    lines.push(bookmark.ai_summary);
    lines.push("");
  }

  // 原文链接
  lines.push(`**原文链接**：[点击访问](${bookmark.url})`);
  lines.push("");

  // 描述
  if (bookmark.description) {
    lines.push("## 描述");
    lines.push("");
    lines.push(bookmark.description);
    lines.push("");
  }

  // 用户笔记
  if (bookmark.notes) {
    lines.push("## 我的笔记");
    lines.push("");
    lines.push(bookmark.notes);
    lines.push("");
  }

  return lines.join("\n");
}

function escapeYaml(value: string): string {
  if (!value) return "";
  return value.replace(/"/g, '\\"');
}

export function formatBookmarksToObsidianZip(
  bookmarks: Array<Bookmark & { folders?: { name: string } | null }>,
): Map<string, string> {
  const files = new Map<string, string>();

  for (const bookmark of bookmarks) {
    const folder = bookmark.folders?.name || "未分类";
    const filename = sanitizeFilename(bookmark.title);
    const path = `${folder}/${filename}.md`;
    const content = formatBookmarkToObsidian(bookmark);
    files.set(path, content);
  }

  return files;
}

function sanitizeFilename(name: string): string {
  return name
    .replace(/[<>:"/\\|?*]/g, "_") // 移除非法字符
    .replace(/\s+/g, " ") // 合并空格
    .trim()
    .slice(0, 100); // 限制长度
}
```

### 7.4 导出服务

```typescript
// src/lib/export/services/export.service.ts

import type { Bookmark } from "@/types/supabase";
import type { ExportConfig, ExportResult, ExportFormat } from "../types";
import { formatBookmarksToCSV } from "../formatters/csv-formatter";
import { formatBookmarkToObsidian } from "../formatters/obsidian-formatter";
import {
  exportBookmarksToMarkdown,
  exportBookmarksToJSON,
} from "@/lib/utils/export";

export class ExportService {
  /**
   * 执行导出
   */
  static export(
    bookmarks: Array<Bookmark & { folders?: { name: string } | null }>,
    config: ExportConfig,
  ): ExportResult {
    const { format, options } = config;

    try {
      let content: string;
      let filename: string;

      switch (format) {
        case "csv":
          content = formatBookmarksToCSV(bookmarks, options?.csv);
          filename = this.generateFilename("csv");
          break;

        case "obsidian":
          // 单文件模式（合并所有书签）
          content = bookmarks
            .map((b) => formatBookmarkToObsidian(b))
            .join("\n---\n\n");
          filename = this.generateFilename("md");
          break;

        case "markdown":
          // 使用现有函数
          content = exportBookmarksToMarkdown(bookmarks, "我的书签");
          filename = this.generateFilename("md");
          break;

        case "json":
          // 使用现有函数
          content = exportBookmarksToJSON(bookmarks);
          filename = this.generateFilename("json");
          break;

        default:
          throw new Error(`不支持的导出格式: ${format}`);
      }

      return {
        success: true,
        filename,
        content,
        count: bookmarks.length,
        format,
      };
    } catch (error) {
      return {
        success: false,
        filename: "",
        content: "",
        count: 0,
        format,
        error: error instanceof Error ? error.message : "导出失败",
      };
    }
  }

  /**
   * 生成导出文件名
   */
  private static generateFilename(ext: string): string {
    const date = new Date();
    const dateStr = date.toISOString().slice(0, 10).replace(/-/g, "");
    const timeStr = date.toTimeString().slice(0, 5).replace(/:/g, "");
    return `anykeep_export_${dateStr}_${timeStr}.${ext}`;
  }

  /**
   * 触发浏览器下载
   */
  static download(result: ExportResult): void {
    if (!result.success || !result.content) return;

    const mimeTypes: Record<ExportFormat, string> = {
      csv: "text/csv",
      markdown: "text/markdown",
      obsidian: "text/markdown",
      json: "application/json",
      html: "text/html",
    };

    const blob = new Blob([result.content as string], {
      type: `${mimeTypes[result.format]};charset=utf-8`,
    });

    const url = URL.createObjectURL(blob);
    const link = document.createElement("a");
    link.href = url;
    link.download = result.filename;
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
    URL.revokeObjectURL(url);
  }
}
```
