## ❌ 遗漏的功能

### 1. 素材评分功能未集成 ⚠️ **高优先级**

**问题描述**：

- 后端 API (`/api/knowledge-studio/materials`) 已实现
- Hook (`useMaterialHealth`) 已实现
- 但前端 UI 未调用和显示评分结果

**影响**：

- 用户无法看到素材质量评分
- 无法根据评分选择高质量素材
- 文档中提到的"评分 ≥60 分建议"无法实现

**需要修改的文件**：

- `src/components/knowledge-studio/material-selector.tsx`
- `src/app/(main)/knowledge-studio/knowledge-studio-page-client.tsx`

**实现建议**：

```typescript
// 在 MaterialSelector 组件中：
1. 导入 useMaterialHealth Hook
2. 在选择素材后自动调用 analyzeHealth
3. 显示每个素材的评分和质量等级（🌟/👍/📝/⚠️）
4. 显示评分维度（相关度、深度、新鲜度、可信度）
5. 显示改进建议（可选）
```

---

### 2. 报告列表页面缺失 ⚠️ **中优先级**

**问题描述**：

- 后端 API (`/api/knowledge-studio/reports`) 已实现（GET 列表）
- 但没有前端页面展示用户生成的所有报告

**影响**：

- 用户无法查看历史报告
- 无法管理已生成的报告
- 只能通过"查看报告"按钮访问最新生成的报告

**需要创建的文件**：

- `src/app/(main)/knowledge-studio/reports/page.tsx`
- `src/app/(main)/knowledge-studio/reports/reports-page-client.tsx`

**功能需求**：

- 报告列表（分页）
- 按蓝图类型筛选
- 按时间排序
- 搜索功能
- 删除报告
- 快速编辑入口

---

### 3. 配额不足提示和引导 ⚠️ **中优先级**
