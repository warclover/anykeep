> 状态：待实现
> 优先级：高

---

## 问题描述

### 现象

整理中心执行整理操作后，整理前后的统计数据完全一致，未发生任何变化：

- 未分类：1087 → 1087
- 重复项：16 → 16
- 无标签：894 → 894
- 长期未读：0 → 0

### 根本原因

**AI 整理只做"分析建议"，未执行数据库更新**

问题流程：

```
1. 点击"一键整理"
   ↓
2. 发送消息给 AI："帮我一键整理收藏"
   ↓
3. AI 分析数据，返回文本建议 ← ⚠️ 只到这里
   ↓
4. ❌ 未调用任何数据库更新 API
   ↓
5. 获取"整理后"快照 → 数据当然没变
```

**证据**：

- `src/components/organize/organize-page-client.tsx` 中，整理操作只是通过 `sendMessage()` 发送文本给 AI
- AI Skills 的 organize 模块只导出了 `SnapshotManager` 和 `SagaOrchestrator`，**缺少实际的数据库更新逻辑**
- 对比健康诊断面板的操作（合并/删除/重命名文件夹）是直接调用 API 的

---

## 解决方案：统一服务层架构

### 设计目标

让按钮直接调用和 AI 对话都能使用同一套业务逻辑，避免代码重复。

### 当前架构问题

```
┌──────────────┐              ┌──────────────┐
│  按钮点击     │              │  AI 对话     │
└──────┬───────┘              └──────┬───────┘
       │                             │
       ↓                             ↓
┌─────────────────┐          ┌─────────────────────┐
│  API Routes     │          │  AI Tools/Skills    │
│  (独立实现逻辑)  │          │  (独立实现逻辑)      │  ← ❌ 逻辑重复

         ↓                             ↓
    ┌────────────────────────────────────┐
    │         Supabase Client            │
```

**现状**：项目已有 120+ Tools 和 30+ Skills，但业务逻辑分散在 API/Tools/Skills 三处。

## 代码示例

### 1. 服务层 (`src/lib/services/health/health.service.ts`)

```typescript
import { createClient } from "@/lib/supabase/server";
import type { SupabaseClient } from "@supabase/supabase-js";

export interface DeleteDuplicatesInput {
  duplicateIds: string[];
  keepId: string;
  userId: string;
}

export interface DeleteDuplicatesResult {
  deletedCount: number;
  preservedId: string;
  message: string;
}

export class HealthService {
  constructor(private supabase: SupabaseClient) {}

  /**
   * 删除重复书签 (统一业务逻辑)
   * - API 调用: await healthService.deleteDuplicates(...)
   * - Tool 调用: await healthService.deleteDuplicates(...)
   */
  async deleteDuplicates(
    input: DeleteDuplicatesInput,
  ): Promise<DeleteDuplicatesResult> {
    const { duplicateIds, keepId, userId } = input;

    // 1. 验证权限
    const { data: bookmarks } = await this.supabase
      .from("bookmarks")
      .select("id")
      .in("id", [...duplicateIds, keepId])
      .eq("user_id", userId);

    if (!bookmarks || bookmarks.length !== duplicateIds.length + 1) {
      throw new Error("部分书签不存在或无权操作");
    }

    // 2. 执行删除 (软删除)
    const { error } = await this.supabase
      .from("bookmarks")
      .update({ deleted_at: new Date().toISOString() })
      .in("id", duplicateIds)
      .eq("user_id", userId);

    if (error) throw error;

    return {
      deletedCount: duplicateIds.length,
      preservedId: keepId,
      message: `已删除 ${duplicateIds.length} 个重复书签`,
    };
  }

  /**
   * 智能分类未分类书签
   */
  async categorizeUncategorized(userId: string): Promise<{
    categorizedCount: number;
    message: string;
  }> {
    // 1. 获取未分类书签
    const { data: uncategorized } = await this.supabase
      .from("bookmarks")
      .select("id, title, url, ai_summary")
      .eq("user_id", userId)
      .is("folder_id", null)
      .is("deleted_at", null);

    if (!uncategorized || uncategorized.length === 0) {
      return { categorizedCount: 0, message: "没有未分类的书签" };
    }

    // 2. 调用分类逻辑 (可复用现有 AI 分类能力)
    // TODO: 集成现有分类器

    return {
      categorizedCount: uncategorized.length,
      message: `已分类 ${uncategorized.length} 个书签`,
    };
  }

  /**
   * 为无标签书签自动打标签
   */
  async autoTagBookmarks(userId: string): Promise<{
    taggedCount: number;
    message: string;
  }> {
    // 1. 获取无标签书签
    const { data: untagged } = await this.supabase
      .from("bookmarks")
      .select("id, title, url, ai_summary")
      .eq("user_id", userId)
      .or("user_tags.is.null,user_tags.eq.{}")
      .is("deleted_at", null);

    if (!untagged || untagged.length === 0) {
      return { taggedCount: 0, message: "没有无标签的书签" };
    }

    // 2. 调用标签生成逻辑
    // TODO: 集成现有 AI 标签能力

    return {
      taggedCount: untagged.length,
      message: `已为 ${untagged.length} 个书签添加标签`,
    };
  }
}

// 工厂函数
export async function createHealthService(): Promise<HealthService> {
  const supabase = await createClient();
  return new HealthService(supabase);
}
```

### 2. API 适配层 (`src/app/api/health/duplicates/route.ts`)

```typescript
import { NextResponse } from "next/server";
import { createHealthService } from "@/lib/services/health/health.service";
import { getAuthUser } from "@/lib/supabase/auth";

export async function POST(request: Request) {
  try {
    const user = await getAuthUser();
    if (!user) {
      return NextResponse.json({ error: "未授权" }, { status: 401 });
    }

    const body = await request.json();

    // 调用服务层 (统一逻辑)
    const healthService = await createHealthService();
    const result = await healthService.deleteDuplicates({
      duplicateIds: body.duplicateIds,
      keepId: body.keepId,
      userId: user.id,
    });

    return NextResponse.json(result);
  } catch (error) {
    return NextResponse.json(
      { error: error instanceof Error ? error.message : "操作失败" },
      { status: 500 },
    );
  }
}
```

### 3. Tool 适配层 (`src/lib/ai-agent/tools/health/delete-duplicates.tool.ts`)

```typescript
import { z } from "zod";
import { createHealthService } from "@/lib/services/health/health.service";
import type { Tool, ToolResult } from "../types";

const paramsSchema = z.object({
  duplicateIds: z.array(z.string()).describe("要删除的重复书签 ID 列表"),
  keepId: z.string().describe("要保留的书签 ID"),
});

type Params = z.infer<typeof paramsSchema>;

export const deleteDuplicatesTool: Tool<Params> = {
  definition: {
    name: "delete_duplicates",
    description: "删除重复的书签，保留指定的一个",
    parameters: paramsSchema,
    category: "action",
    requiresConfirmation: true,
    estimatedDurationMs: 500,
  },

  async execute(params, context): Promise<ToolResult> {
    // 确认机制
    if (!context.confirmed) {
      return {
        success: true,
        data: {
          __pendingConfirmation: {
            message: `确认删除 ${params.duplicateIds.length} 个重复书签？`,
            details: {
              duplicateIds: params.duplicateIds,
              keepId: params.keepId,
            },
          },
        },
      };
    }

    // 调用服务层 (统一逻辑)
    const healthService = await createHealthService();
    const result = await healthService.deleteDuplicates({
      duplicateIds: params.duplicateIds,
      keepId: params.keepId,
      userId: context.userId,
    });

    return { success: true, data: result };
  },
};
```

### 4. Hook 层 (`src/hooks/domain/organize/use-organize-actions.ts`)

```typescript
import { useCallback } from "react";
import { toast } from "sonner";

export function useOrganizeActions() {
  const deleteDuplicates = useCallback(
    async (duplicateIds: string[], keepId: string) => {
      try {
        const response = await fetch("/api/health/duplicates", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ duplicateIds, keepId }),
        });

        if (!response.ok) {
          throw new Error("删除失败");
        }

        const result = await response.json();
        toast.success(result.message);
        return result;
      } catch (error) {
        toast.error("删除重复书签失败");
        throw error;
      }
    },
    [],
  );

  const categorizeUncategorized = useCallback(async () => {
    try {
      const response = await fetch("/api/health/categorize", {
        method: "POST",
      });

      if (!response.ok) {
        throw new Error("分类失败");
      }

      const result = await response.json();
      toast.success(result.message);
      return result;
    } catch (error) {
      toast.error("智能分类失败");
      throw error;
    }
  }, []);

  const autoTagBookmarks = useCallback(async () => {
    try {
      const response = await fetch("/api/health/auto-tag", {
        method: "POST",
      });

      if (!response.ok) {
        throw new Error("标签生成失败");
      }

      const result = await response.json();
      toast.success(result.message);
      return result;
    } catch (error) {
      toast.error("自动打标签失败");
      throw error;
    }
  }, []);

  return {
    deleteDuplicates,
    categorizeUncategorized,
    autoTagBookmarks,
  };
}
```
