## 2. 新旧架构对比

### 2.1 组件职责对比

| 职责      | 旧架构 (HomePageClient)    | 新架构 (分层)                   |
| --------- | -------------------------- | ------------------------------- |
| 数据获取  | 直接调用 `useBookmarksSWR` | `HomeDataProvider` 封装         |
| 状态管理  | 分散的 `useState`          | `HomePageProvider` 集中管理     |
| 视图模式  | `useHomeViewMode` Hook     | `useHomeViewMode` Hook (不变)   |
| CRUD 操作 | `useHomeMutations` Hook    | `useHomeMutations` Hook (不变)  |
| 批量操作  | `useHomeBatch` Hook        | `useHomeBatch` Hook (不变)      |
| UI 渲染   | 混合在主组件中             | `HomeView` + `HomeContent` 分离 |
| 对话框    | 混合在主组件中             | `HomeDialogs` 独立组件          |
| 代码行数  | 1042 行                    | 容器 ~100 行，各层分离          |

### 2.2 Props 传递对比

```typescript
// 旧架构：HomePageClient Props
interface HomePageClientProps {
  initialBookmarks?: BookmarkWithFolder[];
  error?: string;
  urlFolder?: string;
  urlPlatform?: string;
  smartListId?: number | null;
  userSettings?: UserSettings;
}

// 新架构：HomePageClientLayered Props (相同)
interface HomePageClientLayeredProps {
  initialBookmarks?: BookmarkWithFolder[];
  error?: string;
  urlFolder?: string;
  urlPlatform?: string;
  smartListId?: number | null;
  userSettings?: UserSettings;
}

// ✅ Props 完全兼容，无需修改调用方
```

### 2.3 数据流对比

```typescript
// 旧架构数据流
HomePageClient
  └─ useBookmarksSWR({ platform, sort, folder, usageTags })
      └─ bookmarks, isLoading, hasMore, ...
          └─ 直接在组件中使用

// 新架构数据流
HomePageClientLayered
  └─ HomeDataProvider
      └─ useBookmarksSWR({ platform, sort, folder, usageTags })
          └─ 暴露给子组件
              └─ HomeView
                  └─ useHomeData()
                      └─ bookmarks, isLoading, hasMore, ...
```

## 4. 风险评估

### 4.1 风险矩阵

| 风险项           | 概率 | 影响 | 等级  | 缓解措施                      |
| ---------------- | ---- | ---- | ----- | ----------------------------- |
| Props 不兼容     | 低   | 高   | 🟡 中 | Props 完全相同，兼容          |
| Context 状态丢失 | 低   | 高   | 🟡 中 | HomePageProvider 已支持初始值 |
| 事件监听失效     | 中   | 中   | 🟡 中 | UIEventBus 双向同步已实现     |
| 懒加载组件闪烁   | 低   | 低   | 🟢 低 | Suspense fallback 已配置      |
| 类型错误         | 低   | 中   | 🟢 低 | TypeScript 编译时检查         |
| 性能回退         | 低   | 中   | 🟢 低 | memo + useCallback 已优化     |

### 4.2 关键风险点详解

#### 风险 1: URL 参数同步问题

**问题**: HomePageProvider 的 `initialXXX` props 只在初始化时生效，后续 URL 参数变化可能不同步

**现状**:

```typescript
// home-page-client-layered.tsx
<HomePageProvider
  initialPlatform={urlPlatformParam}
  initialFolder={urlFolderParam}
  initialUsageTags={parsedUsageTags}
>
```

**缓解措施**:

- `HomeView` 已有 URL 参数同步逻辑 (第 78-91 行)
- `HomePageContext` 使用 UIEventBus 双向同步
- 验证时重点测试平台/文件夹切换

#### 风险 2: 滚动容器 ref 传递

**问题**: 虚拟滚动需要 `customScrollParent` ref

**现状**:

- `HomeContent` 内部管理 `scrollContainerRef` (第 365-374 行)
- 各虚拟列表组件已正确传递 `customScrollParent`

**状态**: ✅ 无风险

#### 风险 3: 乐观更新失效

**问题**: `updateCacheItem` 和 `removeCacheItem` 可能未正确传递

**现状**:

- `HomeDataProvider` 暴露了完整的缓存操作接口
- `HomeView` 正确使用 `useHomeData` 获取这些方法

**状态**: ✅ 无风险
