### 2.2 新增规则设计

```typescript
// 规则 S1: 收藏动作信号
// "收藏过"、"保存过"、"存过" → 搜索历史收藏
{
  pattern: /(收藏|保存|存)(过|了).{0,20}(的|一篇|那个)?/,
  type: "query",
  subType: "search",
  weight: 88,
}

// 规则 S2: 平台名称识别
// B站、微信、小红书、知乎、抖音 等
{
  pattern: /(B站|bilibili|微信|公众号|小红书|知乎|抖音|掘金|CSDN|GitHub)/i,
  type: "query",
  subType: "search",
  weight: 85,
}

// 规则 S3: 媒体类型查询
// 视频、文章、图片、链接
{
  pattern: /(收藏|保存).{0,5}(的)?.{0,5}(视频|文章|图片|链接|笔记)/,
  type: "query",
  subType: "search",
  weight: 86,
}

// 规则 S4: 时间范围查询
// 上周、本月、最近、昨天
{
  pattern: /(上周|本周|本月|昨天|今天|最近).{0,5}(收藏|保存|添加)(了|的)?/,
  type: "query",
  subType: "search",
  weight: 87,
}

// 规则 S5: 文件夹/分类查询
// "XX文件夹里有什么"
{
  pattern: /.{1,10}(文件夹|分类|标签)(里|中|下)?(有|是)?什么/,
  type: "query",
  subType: "search",
  weight: 84,
}

// 规则 S6: 分类筛选查询
// "所有技术类的"
{
  pattern: /(所有|全部).{0,5}(技术|学习|工作|生活|娱乐)(类|的)/,
  type: "query",
  subType: "search",
  weight: 83,
}
```

| 用例                 | 当前分类 | 预期分类      | 问题分析       |
| -------------------- | -------- | ------------- | -------------- |

| "快速过一遍这些内容" | chitchat | create:digest | "过一遍"未识别 |
| "帮我列出关键点"     | query    | create:digest | "关键点"未识别 |
| "提取要点"           | -        | create:digest | "提取"+"要点"  |

### 3.2 新增规则设计

```typescript
// 规则 D1: 要点/关键点信号
{
  pattern: /(看看|列出|提取|总结).{0,5}(要点|关键点|重点|核心)/,
  type: "create",
  subType: "digest",
  weight: 78,
}

// 规则 D2: 快速浏览信号
// "过一遍"、"扫一眼"、"浏览"
{
  pattern: /(快速|迅速)?.{0,3}(过一遍|扫一眼|浏览|翻阅)/,
  type: "create",
  subType: "digest",
  weight: 76,
}

// 规则 D3: 每篇/分别处理信号（强化）
{
  pattern: /(每篇|每个|分别|各自).{0,5}(的)?.{0,5}(要点|摘要|概要|内容)/,
  type: "create",
  subType: "digest",
  weight: 79,
}
```

## 四、Synthesis 边界优化

### 4.1 待修复用例

| 用例                 | 当前分类 | 预期分类         | 问题分析   |
| -------------------- | -------- | ---------------- | ---------- |
| "把最近五篇整合一下" | query    | create:synthesis | 时间词干扰 |
| "帮我总结一下这几篇" | -        | create:synthesis | 模式不够强 |

### 4.2 新增规则设计

```typescript
// 规则 Y1: "整合一下" 独立模式
// 时间词 + 整合 → synthesis（优先级高于 query）
{
  pattern: /(最近|前).{0,5}(几|[一二三四五六七八九十\d]+).{0,3}(篇|个|条).{0,5}(整合|合并|综合)/,
  type: "create",
  subType: "synthesis",
  weight: 97, // 高于时间查询规则
}

// 规则 Y2: "总结一下这几篇" 增强
{
  pattern: /(帮我)?总结.{0,3}(一下)?.{0,5}(这几篇|这些|它们)/,
  type: "create",
  subType: "synthesis",
  weight: 94,
}
```

### 4.3 消歧规则补充

```typescript
// 时间词 + 整合动词 → synthesis 优先
{
  id: "query-vs-synthesis-time-fusion",
  conflicts: ["query", "create"],
  pattern: /(最近|前).{0,10}(整合|合并|综合|融合)/,
  winner: "create",
  priority: 110,
  reason: "时间词+整合动词 → 内容合成而非时间查询",
}
```
