# AnyKeep 功能入口优化方案

> **版本**: v1.1
> **日期**: 2026-01-08
> **状态**: ✅ 已审核通过
> **作者**: PM Agent (John)
> **审核人**: Xiafe

## 问题诊断总结

### 1. 调研结果统计

| 维度                  | 数量  | 说明                 |
| --------------------- | ----- | -------------------- |
| 主应用页面            | 40 个 | 含子页面             |
| 侧边栏菜单项          | 45+   | 5 大分组             |
| AI Skills             | 25 个 | 7 原子 + 18 编排     |
| 没有直接入口的 Skills | 10 个 | 只能通过 AI 对话触发 |
| 入口层级 ≥3 的功能    | 8 个  | 需要多次点击才能到达 |

### 2. 发现的核心问题

#### A. 入口太深（藏在二三级菜单）

| 功能           | 当前入口路径                        | 层级 | 问题             |
| -------------- | ----------------------------------- | ---- | ---------------- |
| 浏览器书签导入 | 首页 → 更多菜单(⋯) → 导入浏览器书签 | 3级  | 新用户不易发现   |
| Skills 浏览器  | 侧边栏 → 开发者工具 → Skills 浏览器 | 3级  | 被误认为调试工具 |
| 批量导入       | 首页 → 更多菜单(⋯) → 批量导入       | 3级  | 重要功能入口太深 |
| AI 设置        | 侧边栏 → 设置 → AI 配置             | 3级  | 高级功能不易触达 |

#### B. 没有 UI 入口的 AI Skills（10 个）

这些 Skills 有完整实现但用户无法直接访问：

| Skill ID                 | 名称         | 功能价值           | 现状          |
| ------------------------ | ------------ | ------------------ | ------------- |
| `learning-path`          | 学习路径助手 | 规划学习进度和路径 | ❌ 无入口     |
| `reading-planner`        | 阅读规划助手 | 制定阅读计划       | ❌ 无入口     |
| `periodic-report`        | 周期报告助手 | 生成周报/月报      | ❌ 无入口     |
| `share-bundle`           | 分享包助手   | 生成可分享内容包   | ❌ 无入口     |
| `knowledge-extract`      | 知识提取助手 | 提取关键知识点     | ❌ 无入口     |
| `wechat-digest`          | 微信阅读摘要 | 微信文章专属摘要   | ❌ 无入口     |
| `bilibili-transcript`    | B站字幕提取  | 提取视频字幕       | ❌ 无入口     |
| `inbox-digest`           | 收件箱摘要   | 未读/通知摘要      | ❌ 无入口     |
| `content-change-monitor` | 内容变更监控 | 监控页面变化       | ❌ 无入口     |
| `insight-report`         | 洞察报告助手 | 活跃度分析和趋势   | ❌ 无独立入口 |

#### C. 功能分散隐藏

| 功能            | 问题描述                                 |
| --------------- | ---------------------------------------- |
| TTS 语音朗读    | 只在书签卡片有按钮，无"我的音频"集中管理 |
| 快速添加        | 仅首页可用，其他页面无法快速添加         |
| 智能列表        | 在可折叠子菜单中，不够醒目               |
| 24 个 AI Skills | 用户不知道有这么多能力可用               |

### 方案 1：新增「数据导入」统一入口页面

**优先级**: P0（高）
**路径**: `/import`
**入口**: 侧边栏 → 整理工具 → 数据导入

#### 问题解决

- 将浏览器书签导入从三级菜单提升到一级入口
- 整合所有导入相关功能，统一入口

- `BrowserBookmarkImportDialog` → 浏览器书签导入

### 方案 6：顶部栏快速添加优化

**优先级**: P2（中）

#### 问题

快速添加功能仅在首页显示，其他页面无法快速添加书签。

#### 方案

1. **全局悬浮快速添加按钮** - 在所有页面右下角显示悬浮按钮
2. **快捷键支持** - `Ctrl/Cmd + K` 打开快速添加面板
3. **用户可配置** - 在设置中提供开关选项，默认开启

#### 设置项设计

```typescript
// 用户偏好设置
interface QuickAddSettings {
  showFloatingButton: boolean; // 显示悬浮按钮，默认 true
  enableKeyboardShortcut: boolean; // 启用快捷键，默认 true
  floatingButtonPosition: "bottom-right" | "bottom-left"; // 按钮位置，默认右下
}
```
