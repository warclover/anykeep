# 收藏夹页面 UI 升级方案

> 📅 创建日期：2024-12-19
> 🎯 方案类型：方案 A - 双栏分类导航布局
> 👤 设计者：Sally (UX Expert)

---

## 一、设计目标

### 1.1 核心问题

- 当前卡片尺寸过小（96×176px），信息密度低
- 颜色基于 ID 随机分配，无语义关联
- 文件夹层级关系（parent_id）在 UI 中未体现
- 分组区分不够明显，视觉层次扁平
- 操作菜单仅 hover 显示，移动端体验差

### 1.2 设计目标

1. **清晰的信息层级**：双栏布局，左侧导航 + 右侧内容
2. **直观的分类体系**：树形结构展示文件夹层级
3. **语义化的颜色系统**：颜色与分组强绑定
4. **高效的操作体验**：快捷操作栏始终可见
5. **优秀的响应式设计**：移动端自适应

│  Header: 收藏夹标题 + 统计 + 操作按钮                                    │
├──────────────────────┬──────────────────────────────────────────────────┤
│                      │                                                  │
│   左侧导航面板        │   右侧内容区域                                    │

### 2.2 尺寸规格

| 区域     | 桌面端     | 平板端       | 移动端    |
| -------- | ---------- | ------------ | --------- |
| 左侧导航 | 280px 固定 | 240px 可折叠 | 全屏抽屉  |
| 右侧内容 | flex-1     | flex-1       | 100%      |
| 卡片尺寸 | 200×120px  | 180×110px    | 100% 宽度 |
| 卡片间距 | 16px       | 12px         | 12px      |

### 2.3 响应式断点

```typescript
const BREAKPOINTS = {
  mobile: 640, // < 640px: 单栏布局，导航抽屉
  tablet: 1024, // 640-1024px: 可折叠导航

};
```

## 三、组件设计

### 3.1 左侧导航面板 (FolderNavPanel)

```tsx
// 组件结构
<FolderNavPanel>
  {/* 系统文件夹 - 置顶 */}
  <SystemFolderSection>
    <FolderNavItem folder={inbox} highlight />
  </SystemFolderSection>

  {/* 分组列表 - 可折叠 */}
  <FolderGroupList>
    {groups.map((group) => (
      <FolderGroupSection key={group.key}>
        <GroupHeader
          icon={group.icon}
          label={group.label}
          count={group.count}
        />
        <FolderTree folders={group.folders} />
      </FolderGroupSection>
    ))}
  </FolderGroupList>

  {/* 底部操作 */}
  <NavFooter>
    <ArchivedFoldersLink />
    <CreateFolderButton />
  </NavFooter>
</FolderNavPanel>
```

### 3.4 快捷操作栏 (QuickActionsBar)

```
┌─────────────────────────────────────────────────────────────┐
│  🔍 搜索文件夹...          [排序 ▾]  [网格 | 列表]  [+ 新建] │
└─────────────────────────────────────────────────────────────┘
```

功能：

- **搜索**：实时过滤当前分组的文件夹
- **排序**：名称 / 收藏数 / 创建时间 / 更新时间
- **视图切换**：网格视图 / 列表视图
- **新建**：快速创建文件夹

## 六、风险控制

### 6.1 功能保障清单

| 功能       | 现有组件             | 处理方式           |
| ---------- | -------------------- | ------------------ |
| 创建文件夹 | CreateFolderDialog   | 保留不变           |
| 重命名     | RenameFolderDialog   | 保留不变           |
| 合并       | MergeFolderDialog    | 保留不变           |
| 删除       | DeleteFolderDialog   | 保留不变           |
| 操作菜单   | FolderActionMenu     | 保留，集成到新卡片 |
| 分组折叠   | Collapsible          | 迁移到导航面板     |
| 批量锁状态 | API + useEffect      | 保留逻辑           |
| 乐观更新   | useState + callbacks | 保留逻辑           |

### 6.2 回滚策略

1. 保留原 `folders-page-client.tsx` 为 `folders-page-client.backup.tsx`
2. 新布局使用 Feature Flag 控制（可选）
3. 每个 Phase 完成后进行功能验证
