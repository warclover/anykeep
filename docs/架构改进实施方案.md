## 一、核心原则

### 1.1 安全性原则

| 原则         | 说明                             | 检查方法                  |
| ------------ | -------------------------------- | ------------------------- |
| **零破坏**   | 不修改已实现功能的核心逻辑       | 回归测试通过              |
| **渐进式**   | 每个阶段独立可回滚               | Git 分支隔离              |
| **向后兼容** | 旧 API/接口保留适配期            | 废弃警告而非删除          |
| **类型安全** | 重构过程保持 TypeScript 严格模式 | `npm run type-check` 通过 |

### 1.2 技术原则

| 原则              | 说明                         |
| ----------------- | ---------------------------- |
| **Strangler Fig** | 新旧代码并存，逐步替换       |
| **Feature Flag**  | 新功能通过开关控制，风险可控 |
| **模块解耦**      | 单一职责，依赖注入，接口隔离 |
| **性能优先**      | 每个改动需有性能基准对比     |

#### 5.3 依赖注入模式

**Context 注入**:

```typescript
// features/bookmark/context.ts
import { createContext, useContext } from "react";
import type { BookmarkService } from "./types";

const BookmarkContext = createContext<BookmarkService | null>(null);

export function BookmarkProvider({
  children,
  service,
}: {
  children: React.ReactNode;
  service: BookmarkService;
}) {
  return (
    <BookmarkContext.Provider value={service}>
      {children}
    </BookmarkContext.Provider>
  );
}

export function useBookmarkService() {
  const context = useContext(BookmarkContext);
  if (!context) {
    throw new Error("useBookmarkService must be used within BookmarkProvider");
  }
  return context;
}
```

## 四、风险控制

### 4.1 风险矩阵

| 风险                | 可能性 | 影响 | 缓解措施                 |
| ------------------- | ------ | ---- | ------------------------ |
| Import 路径更新遗漏 | 中     | 中   | TypeScript 编译检查 + CI |
| API 调用兼容性问题  | 中     | 高   | 保留旧路由 30 天 + 监控  |
| 性能回归            | 低     | 高   | 性能基准对比 + 灰度发布  |
| 模块依赖循环        | 中     | 中   | 依赖分析工具 + 代码审查  |

### 4.2 回滚策略

**每个 Phase 独立分支**:

```bash
git checkout -b refactor/phase-0-cleanup
git checkout -b refactor/phase-1-hooks
git checkout -b refactor/phase-2-api
# ...
```

**回滚命令**:

```bash
# 回滚单个 Phase
git revert --no-commit <phase-commit>..HEAD
git commit -m "Revert: Phase X due to [reason]"

# 紧急回滚（硬重置）
git reset --hard <safe-commit>
git push --force-with-lease
```

### 4.3 质量门禁

每个 Phase 合并前必须满足：

- [ ] `npm run type-check` 通过
- [ ] `npm run lint` 无错误
- [ ] `npm run build` 成功
- [ ] 核心功能手动测试通过
- [ ] 性能指标无明显下降
