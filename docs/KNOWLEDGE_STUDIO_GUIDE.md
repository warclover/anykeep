## 功能概述

知识工坊 2.0 是一款 **AI 驱动的知识报告生成工具**，帮助用户将收藏的内容转化为结构化的知识报告。

### 核心能力

| 功能            | 说明                           |
| --------------- | ------------------------------ |
| 🎨 **蓝图生成** | 5 种风格模板，一键生成专业报告 |
| 📊 **素材评分** | 智能分析素材质量，优化内容选择 |
| ✏️ **聊天编辑** | 对话式修改报告，AI 协助润色    |
| 📈 **学习追踪** | 记录内化进度，可视化学习成果   |
| 📑 **模板管理** | 自定义报告模板，复用高效       |

## 快速开始

### 第一步：进入知识工坊

1. 点击侧边栏「学习中心」→「知识工坊」
2. 或直接访问 `/knowledge-studio/templates`

### 第二步：选择素材

1. 从收藏列表中选择 2-10 个相关书签
2. 系统会自动评估素材质量
3. 建议选择评分 ≥60 分（良好）的素材

### 第三步：选择蓝图

选择一种报告风格：

- ✍️ **博主** - 个人化叙事，适合分享观点
- ⚖️ **辩论家** - 正反论证，引用支撑
- 🎓 **费曼** - 简化解释，通俗易懂
- 🧵 **推文串** - 分段展开，适合社交分享
- 📚 **教程** - 步骤化讲解，含代码示例

### 第四步：生成报告

1. 点击「生成报告」按钮
2. 等待 AI 处理（通常 20-80 秒）
3. 查看生成的报告内容

### 第五步：编辑优化

使用聊天式编辑功能：

- 选中段落，选择编辑模式
- 输入修改指令，AI 自动润色
- 接受或拒绝修改建议

## 素材选择与评分

### 评分维度

系统从 4 个维度评估素材质量：

| 维度          | 权重 | 说明                       |
| ------------- | ---- | -------------------------- |
| 🔗 **相关度** | 35%  | 与其他素材的语义相关性     |
| 📖 **深度**   | 30%  | 内容的深度和丰富程度       |
| ⏰ **新鲜度** | 20%  | 基于收藏时间和内容更新时间 |
| 🏛️ **可信度** | 15%  | 来源的权威性               |

### 质量等级

| 评分   | 等级   | 图标 | 建议             |
| ------ | ------ | ---- | ---------------- |
| 80-100 | 优秀   | 🌟   | 优先使用         |
| 60-79  | 良好   | 👍   | 推荐使用         |
| 40-59  | 一般   | 📝   | 可以使用         |
| 0-39   | 待改进 | ⚠️   | 建议补充更多素材 |

### 选择建议

1. **数量**：建议选择 3-8 个素材，太少内容单薄，太多难以聚焦
2. **相关性**：选择主题相近的素材，避免跨度太大
3. **质量**：优先选择评分 ≥60 分的素材
4. **多样性**：适当包含不同来源和视角

## 报告生成

### 生成流程

```
选择素材 → 选择蓝图 → 配置参数 → AI 生成 → 预览报告
```

### 配置参数

| 参数           | 选项         | 说明             |
| -------------- | ------------ | ---------------- |
| **目标长度**   | 短 / 中 / 长 | 控制报告篇幅     |
| **引用追踪**   | 开启 / 关闭  | 自动标注引用来源 |
| **自定义指令** | 文本输入     | 额外的写作要求   |

### 长度指南

| 长度 | 字数范围     | 段落数   |
| ---- | ------------ | -------- |
| 短   | 500-800 字   | 3-5 段   |
| 中   | 1000-1500 字 | 6-10 段  |
| 长   | 2000-3000 字 | 12-18 段 |

### 引用标注

启用引用追踪后，报告中会自动标注来源：

```markdown
根据 [来源 1] 的分析，这一趋势正在加速...

---

**引用来源**
[1] 《文章标题》- 平台名称 (2024-12-01)
```

## 聊天式编辑

生成报告后，可以使用聊天式编辑功能进行润色和修改。

### 编辑模式

| 模式         | 图标 | 说明               |
| ------------ | ---- | ------------------ |
| **重写**     | ✏️   | 完全重写选中段落   |
| **扩展**     | 📝   | 添加更多细节和解释 |
| **简化**     | ✨   | 简化表达，更易理解 |
| **调整语气** | 🎭   | 改变写作风格和语气 |
| **自定义**   | 💬   | 按照你的指示修改   |

### 语气选项

| 语气            | 适用场景           |
| --------------- | ------------------ |
| 正式 (formal)   | 商业报告、学术文章 |
| 轻松 (casual)   | 博客、社交媒体     |
| 学术 (academic) | 研究论文、综述     |
| 友好 (friendly) | 教程、入门指南     |

### 使用方法

1. **选择段落**：点击要修改的段落
2. **选择模式**：从编辑面板选择修改模式
3. **输入指令**：（可选）输入具体修改要求
4. **查看差异**：AI 生成修改后显示对比
5. **确认修改**：接受或拒绝修改

### 对话记忆

系统采用滑动窗口机制管理对话上下文：

- 保留最近 3 轮对话完整内容
- 早期对话自动压缩为摘要
- 每次编辑考虑前后段落上下文

## 常见问题

### Q1: 为什么素材评分较低？

**可能原因**：

- 素材内容较短或信息密度低
- 素材来源权威性不足
- 与其他素材相关性不高
- 收藏时间较久

**解决方案**：

- 补充更多相关素材
- 选择信息更丰富的内容
- 确保素材主题一致

### Q2: 生成速度慢怎么办？

**影响因素**：

- 素材数量（越多越慢）
- 目标长度（长报告耗时更多）
- 蓝图类型（教程型最慢）

**建议**：

- 首次使用选择较短长度
- 素材控制在 5 个以内
- 网络环境良好时使用

### Q3: 如何提高报告质量？

**技巧**：

1. 选择高评分素材（≥60 分）
2. 确保素材主题聚焦
3. 使用自定义指令补充要求
4. 善用聊天编辑进行润色
5. 多次迭代优化

### Q4: 配额用完了怎么办？

**选项**：

- 等待下月配额重置
- 升级到 Pro 会员
- 申请配额补偿（如有符合条件的情况）

### Q5: Pro 功能有哪些？

**Pro 专属**：

- 辩论家、费曼、教程蓝图
- 更高的月配额（1000 点）
- 高级自定义模板
- 优先处理队列
- 导出为多种格式
