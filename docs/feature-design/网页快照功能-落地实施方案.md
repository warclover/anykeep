## 二、解耦设计原则

### 2.1 设计目标

**核心原则**: 快照功能作为独立模块，实现**零侵入**现有功能。

```
┌─────────────────────────────────────────────────────────────────────┐
│                       现有功能模块 (保持不变)                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐ │
│  │  书签管理   │  │  文件夹管理  │  │  智能分类   │  │   AI 摘要   │ │
│  │ (bookmarks) │  │  (folders)  │  │(classification)│  │(ai_summary)│ │
│  └─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘ │
│         ▲                                                            │
│         │ 只读引用 (bookmark_id)                                      │
│         │                                                            │
│  ┌──────┴──────────────────────────────────────────────────────────┐ │
│  │                    快照模块 (新增，独立)                          │ │
│  │  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐              │ │
│  │  │  snapshot   │  │  snapshot   │  │  snapshot   │              │ │
│  │  │   .service  │  │ .processor  │  │    .api     │              │ │
│  │  └─────────────┘  └─────────────┘  └─────────────┘              │ │
│  └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 解耦策略矩阵

| 层级         | 解耦策略                                | 影响现有代码 |
| ------------ | --------------------------------------- | ------------ |
| **数据库**   | 独立新表 `bookmark_snapshots`，外键引用 | ❌ 无        |
| **API**      | 独立路由 `/api/snapshots/*`             | ❌ 无        |
| **服务层**   | 独立模块 `src/lib/snapshot/`            | ❌ 无        |
| **前端组件** | 独立目录 `components/snapshot/`         | ❌ 无        |
| **任务队列** | 复用 job_queue，新增任务类���           | ⚠️ 扩展枚举  |
| **Cron**     | 复用处理器，新增 switch 分支            | ⚠️ 新增分支  |

## 三、任务类型设计

### 3.1 扩展 job_queue.type 枚举

需要修改 `20251209000004_add_job_queue.sql` 中的 CHECK 约束：

```sql
-- 新增快照相关任务类型
ALTER TABLE job_queue DROP CONSTRAINT IF EXISTS job_queue_type_check;

ALTER TABLE job_queue ADD CONSTRAINT job_queue_type_check
  CHECK (type IN (
    -- 现有类型
    'process_inbox_cache',
    'check_rename_candidates',
    'check_split_candidates',
    'check_merge_candidates',
    'generate_monthly_report',
    'update_folder_profiles',
    'cleanup_expired_data',
    -- 新增快照类型
    'create_snapshot_basic',      -- 创建基础快照 (Readability)
    'create_snapshot_standard',   -- 创建标准快照 (完整 HTML)
    'create_snapshot_full',       -- 创建完整快照 (含截图)
    'retry_failed_snapshot',      -- 重试失败的快照
    'cleanup_expired_snapshots'   -- 清理过期快照
  ));
```

### 3.2 任务载荷规范

```typescript
// 快照任务载荷类型
interface SnapshotJobPayload {
  bookmark_id: number; // 目标书签 ID
  url: string; // 目标 URL
  snapshot_type: "basic" | "standard" | "full";
  retry_count?: number; // 当前重试次数
  priority?: "low" | "normal" | "high"; // 优先级标记
}

// 清理任务载荷
interface CleanupSnapshotJobPayload {
  days_old?: number; // 过期天数 (默认 30)
  batch_size?: number; // 批次大小 (默认 100)
}
```

### 3.3 任务优先级规则

| 任务类型                    | priority 值 | 说明           |
| --------------------------- | ----------- | -------------- |
| `create_snapshot_basic`     | 0           | 普通优先级     |
| `create_snapshot_standard`  | 1           | Pro 用户稍高   |
| `create_snapshot_full`      | 2           | Pro+ 用户最高  |
| `retry_failed_snapshot`     | -1          | 重试优先级最低 |
| `cleanup_expired_snapshots` | -2          | 清理任务最低   |

## 四、数据库表结构

### 4.1 迁移文件: `20251212000001_add_bookmark_snapshots.sql`

```sql
-- =============================================================================
-- Migration: Add Bookmark Snapshots Table
-- Description: 网页快照存储表，支持三层快照架构
-- Version: V4.2.1
-- =============================================================================

-- -----------------------------------------------------------------------------
-- 1. 创建 bookmark_snapshots 表
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS public.bookmark_snapshots (
    id BIGSERIAL PRIMARY KEY,
    bookmark_id BIGINT NOT NULL REFERENCES public.bookmarks(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,

    -- 快照类型 (与 job_queue type 对应)
    snapshot_type VARCHAR(20) NOT NULL DEFAULT 'basic'
        CHECK (snapshot_type IN ('basic', 'standard', 'full')),

    -- 状态管理 (与 job_queue status 保持语义一致)
    status VARCHAR(20) NOT NULL DEFAULT 'pending'
        CHECK (status IN ('pending', 'processing', 'completed', 'failed', 'expired')),
    error_message TEXT,
    retry_count INT DEFAULT 0,
    max_retries INT DEFAULT 3,

    -- 存储信息 (Supabase Storage)
    storage_bucket VARCHAR(50) DEFAULT 'snapshots',
    storage_path TEXT,                  -- 相对路径: {user_id}/{bookmark_id}/{timestamp}
    file_size BIGINT,                   -- 文件大小 (bytes)
    content_hash VARCHAR(64),           -- SHA256 哈希 (用于去重)

    -- Layer 1: 基础快照内容 (Readability 提取，直接存储)
    readable_title VARCHAR(500),
    readable_content TEXT,              -- HTML 格式正文
    readable_text_content TEXT,         -- 纯文本正文 (用于搜索)
    readable_excerpt TEXT,              -- 摘要片段 (300字以内)
    readable_byline VARCHAR(200),       -- 作者信息
    readable_word_count INT,            -- 字数统计

    -- Layer 2+: 高级快照 (存储在 Storage)
    html_storage_path TEXT,             -- 完整 HTML 路径
    screenshot_storage_path TEXT,       -- 截图路径
    screenshot_width INT,
    screenshot_height INT,
    mhtml_storage_path TEXT,            -- MHTML 存档路径

    -- 元数据
    original_url TEXT NOT NULL,
    final_url TEXT,                     -- 最终 URL (处理重定向后)
    captured_at TIMESTAMPTZ,            -- 快照捕获时间

    -- 时间管理
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    expires_at TIMESTAMPTZ,             -- 过期时间 (免费用户 30 天)

    -- 关联任务
    job_id UUID REFERENCES job_queue(id) ON DELETE SET NULL
);

-- -----------------------------------------------------------------------------
-- 2. 索引优化
-- -----------------------------------------------------------------------------

-- 用户查询索引
CREATE INDEX idx_snapshots_user_id ON public.bookmark_snapshots(user_id);

-- 书签关联索引 (唯一约束：一个书签只有一个有效快照)
CREATE UNIQUE INDEX idx_snapshots_bookmark_unique
    ON public.bookmark_snapshots(bookmark_id)
    WHERE status NOT IN ('failed', 'expired');

-- 状态查询索引
CREATE INDEX idx_snapshots_status ON public.bookmark_snapshots(status);

-- 去重查询索引
CREATE INDEX idx_snapshots_content_hash ON public.bookmark_snapshots(content_hash)
    WHERE content_hash IS NOT NULL;

-- 过期清理索引
CREATE INDEX idx_snapshots_expires_at ON public.bookmark_snapshots(expires_at)
    WHERE expires_at IS NOT NULL AND status = 'completed';

-- 全文搜索索引 (可选，用于快照内容搜索)
CREATE INDEX idx_snapshots_text_search ON public.bookmark_snapshots
    USING gin(to_tsvector('chinese', COALESCE(readable_title, '') || ' ' || COALESCE(readable_text_content, '')));

-- -----------------------------------------------------------------------------
-- 3. RLS 策略
-- -----------------------------------------------------------------------------

ALTER TABLE public.bookmark_snapshots ENABLE ROW LEVEL SECURITY;

-- 用户查看自己的快照
CREATE POLICY "Users can view own snapshots"
    ON public.bookmark_snapshots
    FOR SELECT
    TO authenticated
    USING (auth.uid() = user_id);

-- 用户创建自己的快照 (通过书签关联)
CREATE POLICY "Users can create own snapshots"
    ON public.bookmark_snapshots
    FOR INSERT
    TO authenticated
    WITH CHECK (
        auth.uid() = user_id
        AND EXISTS (
            SELECT 1 FROM public.bookmarks
            WHERE id = bookmark_id AND user_id = auth.uid()
        )
    );

-- 用户更新自己的快照
CREATE POLICY "Users can update own snapshots"
    ON public.bookmark_snapshots
    FOR UPDATE
    TO authenticated
    USING (auth.uid() = user_id)
    WITH CHECK (auth.uid() = user_id);

-- 用户删除自己的快照
CREATE POLICY "Users can delete own snapshots"
    ON public.bookmark_snapshots
    FOR DELETE
    TO authenticated
    USING (auth.uid() = user_id);

-- -----------------------------------------------------------------------------
-- 4. 扩展 bookmarks 表
-- -----------------------------------------------------------------------------

-- 添加快照关联字段
ALTER TABLE public.bookmarks
    ADD COLUMN IF NOT EXISTS has_snapshot BOOLEAN DEFAULT FALSE,
    ADD COLUMN IF NOT EXISTS snapshot_status VARCHAR(20) DEFAULT NULL
        CHECK (snapshot_status IS NULL OR snapshot_status IN ('pending', 'processing', 'completed', 'failed')),
    ADD COLUMN IF NOT EXISTS last_snapshot_at TIMESTAMPTZ;

-- 快照状态索引
CREATE INDEX IF NOT EXISTS idx_bookmarks_has_snapshot
    ON public.bookmarks(has_snapshot)
    WHERE has_snapshot = TRUE AND deleted_at IS NULL;

-- 5. 扩展 job_queue 任务类型

-- 添加新约束 (包含快照任务类型)

        'check_split_candidates',

-- -----------------------------------------------------------------------------
-- 6. 辅助函数
-- -----------------------------------------------------------------------------

-- 计算用户快照存储使用量
CREATE OR REPLACE FUNCTION get_user_snapshot_storage(p_user_id UUID)
RETURNS BIGINT AS $$
BEGIN
    RETURN COALESCE(
        (SELECT SUM(file_size) FROM bookmark_snapshots
         WHERE user_id = p_user_id AND status = 'completed'),
        0
    );
END;
$$ LANGUAGE plpgsql;

-- 检查用户是否可以创建新快照 (配额检查)
CREATE OR REPLACE FUNCTION can_create_snapshot(
    p_user_id UUID,
    p_estimated_size BIGINT DEFAULT 102400  -- 默认预估 100KB
)
RETURNS BOOLEAN AS $$
DECLARE
    v_membership VARCHAR(20);
    v_current_usage BIGINT;
    v_quota BIGINT;
BEGIN
    -- 获取用户会员类型
    SELECT membership_type INTO v_membership
    FROM profiles WHERE id = p_user_id;

    -- 设置配额 (bytes)
    v_quota := CASE v_membership
        WHEN 'PRO' THEN 524288000    -- 500MB
        ELSE 52428800                -- 50MB
    END;

    -- 获取当前使用量
    v_current_usage := get_user_snapshot_storage(p_user_id);

    RETURN (v_current_usage + p_estimated_size) <= v_quota;
END;
$$ LANGUAGE plpgsql;

-- 更新时间戳触发器
CREATE OR REPLACE FUNCTION update_snapshot_timestamp()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

```typescript
// src/lib/snapshot/processors/basic.processor.ts

import { Readability } from "@mozilla/readability";
import { JSDOM } from "jsdom";
import { createHash } from "crypto";

export class BasicSnapshotProcessor {
  async process(job: SnapshotJob): Promise<SnapshotResult> {
    const { bookmark_id, url, user_id } = job.payload;

    // 1. 更新状态为 processing
    await this.updateSnapshotStatus(bookmark_id, "processing");

    // 2. 获取 HTML
    const response = await fetch(url, {
      headers: {
        "User-Agent": "AnyKeep Bot/1.0 (https://anykeep.com)",
        Accept: "text/html",
        "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
      },
      signal: AbortSignal.timeout(30000), // 30s 超时
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }

    const html = await response.text();
    const finalUrl = response.url; // 处理重定向

    // 3. Readability 解析
    const dom = new JSDOM(html, { url: finalUrl });
    const reader = new Readability(dom.window.document);
    const article = reader.parse();

    if (!article) {
      throw new Error("Readability: Unable to parse article content");
    }

    // 4. 计算内容哈希 (用于去重)
    const contentHash = createHash("sha256")
      .update(article.textContent || "")
      .digest("hex");

    // 5. 检查去重
    const existingSnapshot = await this.findByContentHash(contentHash);
    if (existingSnapshot) {
      // 复用现有快照内容
      return this.reuseSnapshot(bookmark_id, existingSnapshot);
    }

    // 6. 计算文件大小 (估算)
    const estimatedSize =
      Buffer.byteLength(article.content, "utf8") +
      Buffer.byteLength(article.textContent || "", "utf8");

    // 7. 保存快照
    await this.saveSnapshot({
      bookmark_id,
      user_id,
      snapshot_type: "basic",
      status: "completed",
      readable_title: article.title,
      readable_content: article.content,
      readable_text_content: article.textContent,
      readable_excerpt: article.excerpt,
      readable_byline: article.byline,
      readable_word_count: article.length,
      original_url: url,
      final_url: finalUrl,
      content_hash: contentHash,
      file_size: estimatedSize,
      captured_at: new Date().toISOString(),
      expires_at: this.calculateExpiresAt(user_id),
    });

    // 8. 更新 bookmark 状态
    await this.updateBookmarkSnapshotStatus(bookmark_id, "completed");

    return { success: true, contentHash };
  }

  private async calculateExpiresAt(userId: string): Promise<string | null> {
    const profile = await this.getProfile(userId);
    if (profile.membership_type === "PRO") {
      return null; // 永久保存
    }
    // 免费用户 30 天后过期
    const expiresAt = new Date();
    expiresAt.setDate(expiresAt.getDate() + 30);
    return expiresAt.toISOString();
  }
}
```

### 7.2 URL 安全

```typescript
// src/lib/snapshot/utils/url-validator.ts

const BLOCKED_HOSTS = [
  "localhost",
  "127.0.0.1",
  "0.0.0.0",
  "::1",
  "169.254.", // Link-local
  "10.", // Private
  "172.16.", // Private
  "192.168.", // Private
];

const BLOCKED_PROTOCOLS = ["file:", "ftp:", "javascript:", "data:"];

export function validateSnapshotUrl(url: string): {
  valid: boolean;
  error?: string;
} {
  try {
    const parsed = new URL(url);

    // 协议检查
    if (!["http:", "https:"].includes(parsed.protocol)) {
      return { valid: false, error: "Only HTTP/HTTPS URLs are allowed" };
    }

    // 主机名检查 (防止 SSRF)
    const hostname = parsed.hostname.toLowerCase();
    for (const blocked of BLOCKED_HOSTS) {
      if (hostname.startsWith(blocked) || hostname === blocked) {
        return {
          valid: false,
          error: "Internal/private hosts are not allowed",
        };
      }
    }

    // 端口检查 (只允许默认端口)
    if (parsed.port && !["80", "443", ""].includes(parsed.port)) {
      return { valid: false, error: "Non-standard ports are not allowed" };
    }

    return { valid: true };
  } catch {
    return { valid: false, error: "Invalid URL format" };
  }
}
```

```sql
-- 获取用户快照统计
SELECT
    COUNT(*) AS total_count,
    COUNT(*) FILTER (WHERE status = 'completed') AS completed_count,
    COUNT(*) FILTER (WHERE status = 'pending') AS pending_count,
    COALESCE(SUM(file_size) FILTER (WHERE status = 'completed'), 0) AS total_size

-- 检查是否可以创建新快照

            AND (SELECT COUNT(*) FROM bookmark_snapshots WHERE user_id = $1 AND status = 'completed') < 1000
        ELSE
            (SELECT COUNT(*) FROM bookmark_snapshots WHERE user_id = $1 AND status IN ('pending', 'processing')) < 5
```

```typescript
// hooks/use-snapshot.ts
export function useSnapshot(bookmarkId: number) {
  const [snapshot, setSnapshot] = useState<Snapshot | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  // 自动轮询 pending/processing 状态
  useEffect(() => {
    if (snapshot?.status === "pending" || snapshot?.status === "processing") {
      const interval = setInterval(refetch, 3000);
      return () => clearInterval(interval);
    }
  }, [snapshot?.status]);

  return { snapshot, isLoading, error, refetch };
}
```

- [ ] 配额检查生效 (免费用户限制)

## 十二、风险与缓解

| 风险             | 可能性 | 影响 | 缓解措施                      |
