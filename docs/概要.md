# 产品质量与试验管控场景人工智能平台 — 研发立项技术报告（概要版）

**文档版本**：V2.0 | **编制日期**：2026年3月 | **概要字数**：约 3000 字

---

## 一、项目定位与价值主张

本项目面向产品质量管理与试验管控全业务链条，以国产大语言模型（LLM）与多模态大模型（LMM）为技术底座，构建覆盖**数据治理—模型训练—智能体编排—业务应用**四层能力的垂直领域人工智能平台。

**核心定位**：不仅是降本增效工具，更是企业的**「质量与知识大脑」**。  
（1）**隐性知识资产化**：将试验报告、质量问题单、老师傅经验等非结构化知识，通过知识图谱与 GraphRAG 转化为可复用、可传承的企业私有资产，缓解人员流动带来的经验断层。（2）**质量成本（COQ）杠杆**：通过 AI 全量检测与跨工序根因推断，从源头阻断质量隐患；挽回一次重大质量事故的隐性损失，往往即可覆盖平台建设成本。（3）**全流程智能辅助**：实现试验流程智能辅助、质量检测自动化覆盖、态势预测与风险预警，提升管控效率与决策水平。

---

## 二、项目范围与方案亮点

**建设范围**（六方面）：基础数据准备（数据前置工作）；垂直领域数据集制作；数据知识工程工具链；专业大模型训练与评测工具链；智能体工程工具链与应用；安全管控与评测体系。

**五大差异化亮点**（相对行业同质化「大模型 + RAG + Agent」方案）：

| 维度     | 本方案                                                        | 同质化方案         |
| -------- | ------------------------------------------------------------- | ------------------ |
| 部署架构 | 云边端三级协同，边缘断网自治（知识蒸馏 3B–7B 边缘 SLM）       | 仅云端，断网即失能 |
| 检索增强 | GraphRAG（向量 + 知识图谱双通道，产品—零部件—工序—缺陷—机理） | 传统向量 RAG       |
| 用户交互 | 流体升级（L1 即时执行 → L2 Agent Bait → L3 幽灵指针）         | 聊天框交互         |
| 成本控制 | Intent Router 三级路由，Token 成本降低 70%+                   | 全量调用大模型     |
| 操作安全 | 四重防护 + 事务沙箱 + Undo Log 一键回滚                       | 仅指令拒识         |

## 三、研究背景与立项必要性

**行业痛点**：试验报告撰写周期长；质量检测依赖人工经验；根因分析效率低；试验资源利用率不高；标准规范检索困难。国家智能制造与人工智能规划明确要求推进 AI 在质量管控领域的深度应用。国产大模型（DeepSeek、Qwen）与 RAG、Multi-Agent 等工程范式已成熟，处于从通用能力向垂直行业转化的关键窗口期。立项必要性体现在业务需求迫切、政策导向明确、技术可行、先发优势显著四个方面。

---

## 四、项目目标与量化指标

**总体目标**：实现从数据治理、模型训练、智能体编排到业务应用的端到端闭环，使质量管控与试验管理从人工驱动转向 AI 辅助智能决策。

**核心量化目标**：

- **效率与成本**：试验/质量报告生成效率提升 ≥3 倍，试验方案执行率提高 ≥30%，综合试验成本降低 ≥35%，AI 运营 Token 成本降低 ≥70%。
- **质量与准确度**：关键工序 AI 检验覆盖率 ≥80%，质量根因自动分析准确率 ≥80%，边缘断网检测保持率 ≥80%。
- **安全与合规**：任务指令拒识率 ≥92%，高危操作回滚成功率 ≥99%。

---

## 五、总体技术架构（四层 + 云边端）

采用**数据—模型—智能体—应用**四层纵向架构，叠加**云—边—端**三级横向部署：云端 72B+ 大模型负责复杂推理与训练，边缘 3B–7B 蒸馏小模型负责实时质检与断网自治，终端负责数据采集与轻量交互。设计原则包括分层解耦、云边端协同、安全纵深（含事务沙箱）、智能路由、零摩擦交互（流体升级）等。数据层构建工业知识图谱与 GraphRAG；模型层提供 CPT/SFT/RLHF 及知识蒸馏全流程；智能体层提供 Agent Builder、Intent Router、Multi-Agent 及事务沙箱；应用层落地试验辅助、质量检测、态势预测、根因分析等业务，并采用流体升级 UX。

---

## 六、核心建设内容概要

**数据层**：基础数据准备（摸底、标准与清洗规则）；垂直领域数据集制作（标注规范、训练/验证/测试及评测集）；多模态解析引擎、清洗与标注平台；三大类专业数据集沉淀；工业知识图谱（产品—零部件—工序—缺陷—机理）与 GraphRAG 双通道检索。

**模型层**：基于国产基座（DeepSeek-V3/Qwen-2.5）的 CPT、SFT、RLHF/DPO 全栈训练；领域与安全评测体系；云边端知识蒸馏工具链；NVIDIA 与华为昇腾双硬件路线；推理服务（vLLM/MindIE）与 API 网关、意图路由。

**智能体层**：Agent Builder（自然语言/拖拽编排）；Intent Router（轻量分类 + 三级路由）；工具集（GraphRAG、ERP/MES 接口、沙箱与 Undo Log）；Multi-Agent 协同框架；8 类业务 Agent（规划调度、检索辅助、分析生成、预测决策）。

**安全**：四重防护（前置拦截、模型对齐、后置审计、事务沙箱回滚）；安全拒识评测集（≥4,000 条）；沙箱预演与 Undo Log 一键回滚。

## 七、技术路线与实施计划

**策略**：分阶段、渐进式，每阶段明确里程碑与交付物。

- **阶段一（1–6 月）**：基础数据准备与垂直数据集、解析引擎、标注平台、工业知识图谱 V1.0、GraphRAG V1.0、领域语料与基座 CPT、**标准检索助手 V0.5（Quick Win，M3 交付）**、安全评测集 V1.0。
- **阶段二（7–12 月）**：SFT/RLHF、知识蒸馏与边缘 SLM、Agent Builder 与 Intent Router、事务沙箱、首批业务 Agent、云端与边缘推理服务。
- **阶段三（13–18 月）**：Multi-Agent 框架、8 类 Agent 矩阵、根因分析 Agent V2.0、流体升级 UX、知识图谱 V2.0、四重安全体系、边缘断网验证。
- **阶段四（19–24 月）**：生产部署、培训与效果评估、KPI 达标验证、持续优化。

## 九、资源需求与项目预算

**算力**：提供 **NVIDIA（方案 A）** 与 **华为昇腾（方案 B）** 双路线；训练 8–16 卡 A100/Atlas 800T，云端推理 A100 L40S/Atlas 800I，边缘 Jetson Orin/Atlas 200I；通用硬件含图数据库与数据处理服务器。  
**人力**：见上「团队建设」，信创适配时增加昇腾适配 2–3 人、信创测试 1 人。  
**数据**：试验标准/规范 3,000+ 份，历史试验与质量根因数据数万条，产线视觉与环境数据 TB 级。

**预算（建设期 24 个月）**：人力 2,200–2,800 万元；算力与硬件方案 A 1,500–2,500 万、方案 B 1,200–2,200 万；软件与许可 100–300 万；数据与标注 150–400 万；外部服务与咨询 80–200 万；预备费 5%–10%。  
**合计**：方案 A 约 4,030–6,200 万元，方案 B 约 3,730–5,900 万元。信创全栈时建议人力预算上浮 15%–20%；云租赁时建议首年 OpEx 约 300–600 万。

## 十、风险与应对要点

**R1 数据风险**：设立数据准入红线，M1 设置核心数据质量体检，关键字段缺失率 >20% 则不启动模型训练（Go/No-Go）；专家在环参与清洗与标注。  
**R2 模型风险**：快速验证 + 迭代优化，保留 2–3 个候选基座，预留阶段四迭代时间。  
**R3 安全风险**：四重防护、安全评测集扩充、安全红队、高危场景人工确认。  
**R4 集成风险**：**非侵入式旁路挂载**，平台作为现有 IT 的 Copilot，优先只读接口/RPA，不改变核心系统事务逻辑。  
**R5 算力风险**：NVIDIA + 昇腾双路线，供应受阻可切换；提前锁定算力或弹性租用。  
**R6–R8**：人才梯队与文档化、需求变更管理、技术预研与缓冲时间。

## 十一、信创合规适配

本章说明在信创要求下需调整的环节及国产替代方案。  
**评估**：AI 芯片/OS 为必须替换；数据库与中间件建议替换；大模型（DeepSeek/Qwen）与应用层已满足。  
**适配**：算力采用华为昇腾 910B/310P、Atlas 系列；OS 采用 openEuler/麒麟；数据库与图库采用 openGauss/达梦/人大金仓与 NebulaGraph/HugeGraph；AI 框架采用 MindSpore/torch_npu 等。  
**策略**：「通用先行，信创平移」— 阶段一通用路线验证，阶段二昇腾并行适配，阶段三信创全面切换。  
**结论**：方案具备信创全栈适配能力，核心 AI 能力与业务指标不受信创替换影响，五大差异化亮点与硬件解耦，竞争优势可保留。

**可行性结论**：技术可行、业务价值明确、实施路径可控、安全保障到位、差异化优势显著，具备立项条件。
