# 微信公众号历史收藏导入功能方案

**文档版本**: V1.0
**日期**: 2025-12-01
**状态**: 待审核

---

## 一、需求背景

### 1.1 用户痛点

- 微信收藏夹中积累了大量公众号文章，但缺乏有效管理
- 微信收藏容量有限（2GB），无法永久保存
- 微信收藏缺少搜索和分类功能，查找困难
- 无法将微信收藏内容与其他平台收藏统一管理

### 1.2 功能目标

- 支持用户将微信收藏的公众号文章导入到 AnyKeep
- 保留文章标题、内容、作者、发布时间等元数据
- 支持批量导入和增量同步
- 独立功能模块，与其他功能解耦

## 二、竞品调研结果

### 2.1 主要竞品方案

| 产品                   | 技术方案            | 优点                 | 缺点                   |
| ---------------------- | ------------------- | -------------------- | ---------------------- |
| **腾讯 IMA**           | 微信小程序接收分享  | 官方支持，用户体验好 | 需开发小程序           |
| **Cubox**              | 服务号接收分享      | 简单快捷             | 需认证服务号           |
| **Notion 剪藏**        | 第三方小程序/公众号 | 无需自建服务         | 依赖第三方             |
| **微信公众号采集助手** | 浏览器插件抓取      | 可批量下载           | 仅限 PC 端，需手动操作 |
| **开源爬虫方案**       | 模拟登录后台爬取    | 可获取完整数据       | 不稳定，易被封禁       |

### 2.2 技术路径分析

#### 方案 A：微信小程序接收分享（推荐）

**原理**：用户在微信中查看公众号文章时，通过"分享到 AnyKeep 小程序"实现收藏

**优点**：

- ✅ 用户体验最佳，符合微信使用习惯
- ✅ 可获取文章完整 URL 和基本信息
- ✅ 官方支持，稳定可靠
- ✅ 支持实时收藏和历史导入

**缺点**：

- ❌ 需开发并上线微信小程序
- ❌ 历史收藏需用户逐条分享（无法批量导入历史）

**技术要点**：

- 使用小程序 `wx.onShareAppMessage` 接收分享
- 通过 WebView 打开公众号文章，解析内容
- 支持图文、视频、音频等多种格式

---

#### 方案 B：浏览器插件 + 网页版微信（备选）

**原理**：开发浏览器插件，在用户访问网页版微信时批量抓取收藏文章

**优点**：

- ✅ 可批量导入历史收藏
- ✅ 一次性解决历史数据问题

**缺点**：

- ❌ 微信网页版功能受限，可能无法访问收藏夹
- ❌ 仅限 PC 端使用
- ❌ 需用户手动安装插件

**技术要点**：

- Chrome Extension Manifest V3
- 需处理微信登录态和反爬虫策略
- 解析微信收藏接口（如存在）

---

#### 方案 C：手动导出 + 文件导入（兜底方案）

**原理**：用户手动将微信收藏分享到文件传输助手或导出为 HTML，然后上传到 AnyKeep

**优点**：

- ✅ 无需开发小程序或插件
- ✅ 开发成本低

**缺点**：

- ❌ 用户体验差，操作繁琐
- ❌ 无法保证数据格式统一

**技术要点**：

- 支持解析微信分享的链接
- 支持上传 HTML/TXT 文件并解析

---

### 2.3 推荐方案

**阶段 1（MVP）**: 方案 A（微信小程序） + 方案 C（手动导入）的组合

- 优先开发微信小程序实现实时收藏
- 提供简单的 URL 导入功能作为历史收藏的兜底方案

**阶段 2（优化）**: 增加方案 B（浏览器插件）

- 为 PC 用户提供批量导入历史收藏的能力

## 三、功能设计

### 3.1 核心功能

#### 3.1.1 实时收藏（微信小程序）

**用户流程**：

1. 用户在微信中打开公众号文章
2. 点击右上角"…" → "分享到 AnyKeep"
3. 小程序自动抓取文章信息并保存

**后端处理**：

1. 接收小程序传来的文章 URL
2. 爬取文章内容（标题、正文、图片、作者等）
3. 使用 AI 生成摘要和标签
4. 保存到数据库

#### 3.1.2 URL 导入（Web 端）

**用户流程**：

1. 用户复制公众号文章链接
2. 在 AnyKeep Web 端粘贴 URL
3. 系统自动抓取并保存

**批量导入**：

- 支持一次粘贴多个 URL（换行分隔）
- 显示导入进度和成功/失败状态

#### 3.1.3 浏览器插件批量导入（Phase 2）

**用户流程**：

1. 安装 AnyKeep Chrome 插件
2. 访问微信网页版或 PC 微信导出的数据
3. 点击"批量导入微信收藏"
4. 插件自动识别并导入

### 3.2 数据模型

#### 3.2.1 表结构设计

**wechat_articles** 表（专用于微信公众号文章）

```sql
CREATE TABLE wechat_articles (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,

  -- 文章基本信息
  title TEXT NOT NULL,
  author TEXT,                    -- 公众号名称
  author_avatar TEXT,             -- 公众号头像
  content TEXT,                   -- 文章正文（HTML）
  content_text TEXT,              -- 文章纯文本（用于搜索）
  url TEXT NOT NULL,              -- 文章原始 URL
  cover_image TEXT,               -- 封面图

  -- 微信特有字段
  publish_time TIMESTAMPTZ,       -- 发布时间
  biz TEXT,                       -- 公众号 BIZ 参数
  mid TEXT,                       -- 文章 MID
  idx TEXT,                       -- 文章索引
  sn TEXT,                        -- 文章签名

  -- AI 增强
  summary TEXT,                   -- AI 摘要
  tags TEXT[],                    -- AI 标签
  rating INTEGER,                 -- 评级（1-3）
  embedding VECTOR(1536),         -- 向量嵌入

  -- 元数据
  import_source TEXT DEFAULT 'miniprogram', -- 导入来源：miniprogram/url/plugin
  imported_at TIMESTAMPTZ DEFAULT NOW(),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),

  -- 关联到通用 bookmarks 表
  bookmark_id UUID REFERENCES bookmarks(id) ON DELETE SET NULL,

  -- 索引
  UNIQUE(user_id, url)
);

-- 索引
CREATE INDEX idx_wechat_articles_user_id ON wechat_articles(user_id);
CREATE INDEX idx_wechat_articles_author ON wechat_articles(author);
CREATE INDEX idx_wechat_articles_publish_time ON wechat_articles(publish_time DESC);
CREATE INDEX idx_wechat_articles_embedding ON wechat_articles USING ivfflat(embedding vector_cosine_ops);
```

**关联关系**：

- 每条微信文章记录同时创建一条 `bookmarks` 记录
- `wechat_articles.bookmark_id` 指向 `bookmarks.id`
- 删除时级联删除

#### 3.3.3 文章抓取服务

**Supabase Edge Function: `crawl-wechat-article`**

功能：

1. 接收文章 URL
2. 使用无头浏览器（Puppeteer/Playwright）抓取内容
3. 解析 HTML，提取标题、正文、图片等
4. 处理图片（下载到 Supabase Storage）
5. 调用 AI 生成摘要和标签
6. 返回结构化数据

技术要点：

- 使用 Deno + Puppeteer
- 处理微信防盗链（图片需转存）
- 处理反爬虫策略（User-Agent、Cookie）

```javascript
// pages/index/index.js
Page({
  onShareAppMessage(options) {
    // 用户分享时触发
    return {
      title: "保存到 AnyKeep",
      path: "/pages/index/index",
      imageUrl: "/images/share-cover.png",
    };
  },

  onLoad(options) {

      this.importArticle(options.url);
    }
  },

  async importArticle(url) {
    wx.showLoading({ title: "导入中..." });

    try {
      const res = await wx.request({
        url: "https://anykeep.com/api/wechat/import/miniprogram",
        method: "POST",
        data: { url },
        header: {
          Authorization: `Bearer ${this.data.token}`,

      if (res.data.success) {
        wx.showToast({ title: "导入成功", icon: "success" });
        wx.navigateTo({ url: "/pages/import-success/index" });
      }
    } catch (error) {
      wx.showToast({ title: "导入失败", icon: "error" });
    } finally {
      wx.hideLoading();
    }
  },
});
```

### 4.4 Edge Function 实现

**文件**: `supabase/functions/crawl-wechat-article/index.ts`

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import puppeteer from "https://deno.land/x/puppeteer@16.2.0/mod.ts";

serve(async (req) => {
  try {
    const { url } = await req.json();

    // 启动无头浏览器
    const browser = await puppeteer.launch({
      headless: true,
      args: ["--no-sandbox"],
    });

    const page = await browser.newPage();
    await page.setUserAgent(
      "Mozilla/5.0 (iPhone; CPU iPhone OS 14_0 like Mac OS X)",
    );

    // 访问文章
    await page.goto(url, { waitUntil: "networkidle2" });

    // 提取内容
    const article = await page.evaluate(() => {
      const title = document.querySelector("#activity-name")?.textContent;
      const author = document.querySelector("#js_name")?.textContent;
      const content = document.querySelector("#js_content")?.innerHTML;
      const coverImage = document.querySelector("#js_cover")?.src;

      return {
        title,
        author,
        content,
        coverImage,
        contentText: document.querySelector("#js_content")?.textContent,
      };
    });

    await browser.close();

    return new Response(JSON.stringify({ success: true, data: article }), {
      headers: { "Content-Type": "application/json" },
    });
  } catch (error) {
    return new Response(
      JSON.stringify({ success: false, error: error.message }),
      {
        status: 500,
        headers: { "Content-Type": "application/json" },
      },
    );
  }
});
```

#### 4.5.1 URL 导入组件

**位置**: `src/components/wechat-article/url-import.tsx`

```typescript
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Textarea } from '@/components/ui/textarea';
import { Progress } from '@/components/ui/progress';

export function WechatUrlImport() {
  const [urls, setUrls] = useState('');
  const [importing, setImporting] = useState(false);
  const [progress, setProgress] = useState(0);

  const handleImport = async () => {
    setImporting(true);

    const urlList = urls.split('\n').filter(u => u.trim());

    const response = await fetch('/api/wechat/import/url', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ urls: urlList })
    });

    const result = await response.json();

    // 显示结果
    setImporting(false);
  };

  return (
    <div className="space-y-4">
      <Textarea
        placeholder="粘贴微信公众号文章链接，每行一个"
        value={urls}
        onChange={(e) => setUrls(e.target.value)}
        rows={10}
      />

      {importing && (
        <Progress value={progress} />
      )}

      <Button onClick={handleImport} disabled={importing}>
        {importing ? '导入中...' : '开始导入'}
      </Button>
    </div>
  );
}
```

### 6.1 主要风险

| 风险项               | 影响 | 概率 | 应对措施                                 |
| -------------------- | ---- | ---- | ---------------------------------------- |
| **微信反爬虫策略**   | 高   | 中   | 使用无头浏览器模拟真实访问，添加重试机制 |
| **文章内容无法访问** | 中   | 中   | 提示用户文章可能已删除，支持手动重试     |
| **图片防盗链**       | 中   | 高   | 下载图片到自有存储，替换图片 URL         |
| **小程序审核不通过** | 高   | 低   | 提前准备审核资料，符合微信规范           |
| **抓取性能问题**     | 中   | 中   | 使用队列系统异步处理，限制并发数         |

### 6.2 技术难点

1. **微信文章动态渲染**：部分内容通过 JavaScript 加载，需使用 Puppeteer 等待渲染完成
2. **图片处理**：微信图片有防盗链，需下载后转存到 Supabase Storage
3. **视频和音频**：需特殊处理，可能无法直接获取源文件
4. **并发控制**：批量导入时需控制并发数，避免触发反爬虫

### 6.3 解决方案

**图片处理流程**：

1. 抓取文章时识别所有图片 URL
2. 下载图片到临时目录
3. 上传到 Supabase Storage
4. 替换 HTML 中的图片 URL
5. 保存处理后的 HTML

**并发控制**：

```typescript
// 使用 p-limit 限制并发
import pLimit from "p-limit";

const limit = pLimit(3); // 最多 3 个并发请求

const tasks = urls.map((url) => limit(() => crawlArticle(url)));

await Promise.all(tasks);
```

## 九、FAQ

**Q1: 导入后的文章会永久保存吗？**
A: 是的，文章内容和图片都会保存到 AnyKeep 的服务器，即使原文删除也不影响。

**Q2: 可以导入多少篇文章？**
A: Free 版限制 500 篇，Pro 版无限制。

**Q3: 导入的文章支持全文搜索吗？**
A: 支持。Pro 版还支持语义搜索。

**Q4: 导入的文章可以编辑吗？**
A: 可以。用户可以编辑标题、标签、评级等信息。

**Q5: 支持哪些公众号文章？**
A: 支持所有公开的微信公众号文章（未被删除或设置访问限制的）。
