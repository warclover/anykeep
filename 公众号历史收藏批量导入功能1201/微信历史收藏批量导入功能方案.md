# 微信历史收藏批量导入功能方案

**文档版本**: V1.0
**日期**: 2025-12-01
**状态**: 待审核

---

## 一、需求背景

### 1.1 核心需求

用户希望**一次性批量导入**已存储在微信收藏夹中的所有历史收藏内容到 AnyKeep，而不是逐条手动导入。

### 1.2 与现有功能的区别

| 功能         | 现有（单篇导入） | 新增（批量历史导入） |
| ------------ | ---------------- | -------------------- |
| **导入方式** | 分享/URL 粘贴    | 批量数据提取         |
| **数据来源** | 实时分享         | 历史收藏数据库       |
| **数量级**   | 单篇或少量       | 数百至数千条         |
| **技术难度** | 低               | 高（需解密数据库）   |
| **用户操作** | 每次手动操作     | 一次性批量处理       |

### 1.3 用户价值

- ✅ **省时省力**：一次性导入所有历史收藏，无需逐条操作
- ✅ **数据迁移**：将微信收藏完整迁移到 AnyKeep
- ✅ **备份保存**：永久保存收藏内容，不受微信限制
- ✅ **统一管理**：与其他平台收藏统一管理

## 二、技术调研结果

### 2.1 微信收藏数据存储机制

#### 2.1.1 数据存储位置

**Windows PC 微信**：

```
C:\Users\{用户名}\Documents\WeChat Files\{wxid}\Msg\
├── Favorite.db          # 收藏数据库（加密）
├── FTSFavorite.db       # 收藏全文搜索索引
├── Multi\               # 媒体文件存储
│   ├── Favorite\        # 收藏的图片、视频等
│   └── ...
```

**Mac 微信**：

```
~/Library/Containers/com.tencent.xinWeChat/Data/Library/Application Support/com.tencent.xinWeChat/{version}/
└── {wxid}/Favorite/
```

#### 2.1.2 数据库结构

**Favorite.db** 主要表结构：

| 表名       | 用途       | 关键字段                                             |
| ---------- | ---------- | ---------------------------------------------------- |
| `Favorite` | 收藏主表   | LocalId, Type, SourceType, Title, Url, Desc, FavTime |
| `FavItems` | 收藏项详情 | LocalId, FavId, Type, Data                           |
| `FavTags`  | 标签关联   | FavId, Tag                                           |

**关键字段说明**：

- `Type`: 收藏类型（1=网页链接, 2=图片, 3=视频, 5=文件, 14=公众号文章等）
- `SourceType`: 来源类型
- `Url`: 公众号文章 URL
- `Data`: 收藏内容数据（XML 或 JSON 格式）
- `FavTime`: 收藏时间（时间戳）

#### 2.1.3 数据库加密

- 微信使用 **SQLCipher** 加密 SQLite 数据库
- 密钥存储在内存中，需通过内存读取获取
- 密钥长度：32 字节（64 位十六进制字符串）

### 2.2 现有解决方案调研

#### 方案 A：开源工具 - PyWxDump（★★★★★ 推荐）

**项目地址**: https://github.com/xaoyaoo/PyWxDump

**功能特点**：

- ✅ 自动获取微信数据库密钥
- ✅ 解密所有微信数据库（包括 Favorite.db）
- ✅ 支持导出为 HTML、CSV、JSON 格式
- ✅ 提供 Python API 和命令行工具
- ✅ 支持批量导出聊天记录和收藏
- ✅ 持续维护，Star 数 5k+

**技术原理**：

1. 通过内存读取获取微信数据库密钥
2. 使用密钥解密 SQLite 数据库
3. 解析数据库内容并导出

**使用方式**：

```bash
# 安装
pip install pywxdump

# 获取密钥并解密数据库
pywxdump decrypt

# 导出收藏
pywxdump export --type favorite --format json
```

#### 方案 B：开源工具 - WeChatMsg

**项目地址**: https://github.com/LC044/WeChatMsg

**功能特点**：

- ✅ 图形界面，操作简单
- ✅ 支持导出聊天记录和收藏
- ✅ 导出格式：HTML、Word、CSV
- ✅ 可还原聊天界面
- ❌ 不支持 API 调用，仅 GUI

#### 方案 C：手动提取方案

**步骤**：

1. 用户手动找到 `Favorite.db` 文件
2. 使用工具获取密钥
3. 解密数据库
4. 手动导出数据

**缺点**：操作复杂，不适合普通用户

## 三、技术方案设计

### 3.1 整体架构

我们设计**三阶段实施方案**，从简单到复杂，逐步增强功能：

```
阶段 1：文件上传方案（MVP）
用户使用 PyWxDump 导出 → 上传 JSON/CSV → AnyKeep 解析导入

阶段 2：桌面工具方案（增强）
提供官方桌面工具 → 一键提取并上传 → 自动导入

阶段 3：无缝集成方案（完整）
开发微信插件/服务 → 后台自动同步 → 实时更新
```

### 3.2 阶段 1：文件上传方案（推荐 MVP）

**位置**: `src/lib/wechat-favorite/parser.ts`

```typescript
export interface FavoriteExportData {
  version: string;
  exportTime: string;
  totalCount: number;
  favorites: FavoriteItem[];
}

export interface FavoriteItem {
  id: string;
  type: "article" | "image" | "video" | "file" | "text";
  title: string;
  url?: string;
  author?: string;
  desc?: string;
  content?: string;
  coverImage?: string;
  favTime: number;
  tags?: string[];
  sourceType?: string;
  attachments?: Attachment[];
}

export class WechatFavoriteParser {
  /**
   * 解析上传的 JSON 文件
   */
  async parseJsonFile(file: File): Promise<FavoriteExportData> {
    const text = await file.text();
    const data = JSON.parse(text);

    // 验证数据格式
    this.validateData(data);

    return data;
  }

  /**
   * 验证数据格式
   */
  private validateData(data: any): void {
    if (!data.version || !data.favorites || !Array.isArray(data.favorites)) {
      throw new Error("无效的导出文件格式");
    }

    // 检查必需字段
    for (const item of data.favorites) {
      if (!item.type || !item.title) {
        throw new Error("收藏项缺少必需字段");
      }
    }
  }

  /**
   * 过滤公众号文章类型
   */
  filterArticles(data: FavoriteExportData): FavoriteItem[] {
    return data.favorites.filter(
      (item) =>
        item.type === "article" && item.url?.includes("mp.weixin.qq.com"),
    );
  }
}
```

**（3）批量导入处理器**

**位置**: `src/lib/wechat-favorite/batch-importer.ts`

```typescript
import { WechatFavoriteParser } from "./parser";
import { WechatArticleCrawler } from "../wechat-article/crawler";
import { supabase } from "@/lib/supabase/client";

export interface ImportResult {
  total: number;
  succeeded: number;
  failed: number;
  errors: { title: string; error: string }[];
  duplicates: number;
}

export class WechatFavoriteBatchImporter {
  private parser = new WechatFavoriteParser();
  private crawler = new WechatArticleCrawler();

  /**
   * 批量导入收藏
   */
  async importFromFile(file: File, userId: string): Promise<ImportResult> {
    // 1. 解析 JSON 文件
    const data = await this.parser.parseJsonFile(file);

    // 2. 筛选公众号文章
    const articles = this.parser.filterArticles(data);

    // 3. 批量处理
    const result: ImportResult = {
      total: articles.length,
      succeeded: 0,
      failed: 0,
      errors: [],
      duplicates: 0,
    };

    // 4. 并发处理（限制并发数为 5）
    const limit = 5;
    for (let i = 0; i < articles.length; i += limit) {
      const batch = articles.slice(i, i + limit);

      await Promise.allSettled(
        batch.map(async (item) => {
          try {
            await this.importSingleArticle(item, userId);
            result.succeeded++;
          } catch (error: any) {
            result.failed++;
            result.errors.push({
              title: item.title,
              error: error.message,
            });
          }
        }),
      );

      // 进度通知（可选）
      const progress = Math.round(((i + batch.length) / articles.length) * 100);
      console.log(`导入进度: ${progress}%`);
    }

    return result;
  }

  /**
   * 导入单篇文章
   */
  private async importSingleArticle(
    item: FavoriteItem,
    userId: string,
  ): Promise<void> {
    // 1. 去重检测
    const { data: existing } = await supabase
      .from("wechat_articles")
      .select("id")
      .eq("user_id", userId)
      .eq("url", item.url)
      .single();

    if (existing) {
      throw new Error("文章已存在");
    }

    // 2. 如果有 URL，尝试爬取完整内容
    let fullContent = item.content;
    if (item.url && !fullContent) {
      try {
        const article = await this.crawler.crawl(item.url);
        fullContent = article.content;
      } catch (error) {
        console.warn("爬取失败，使用原始内容", error);
      }
    }

    // 3. 保存到数据库
    const { error } = await supabase.from("wechat_articles").insert({
      user_id: userId,
      title: item.title,
      author: item.author,
      content: fullContent || item.desc,
      url: item.url,
      cover_image: item.coverImage,
      publish_time: new Date(item.favTime * 1000).toISOString(),
      import_source: "batch_upload",
      tags: item.tags || [],
    });

    if (error) throw error;
  }
}
```

**（4）API 路由**

**位置**: `src/app/api/wechat-favorite/batch-import/route.ts`

```typescript
import { NextRequest, NextResponse } from "next/server";
import { createServerClient } from "@/lib/supabase/server";
import { WechatFavoriteBatchImporter } from "@/lib/wechat-favorite/batch-importer";

export async function POST(request: NextRequest) {
  try {
    // 1. 验证用户登录
    const supabase = createServerClient();
    const {
      data: { user },
    } = await supabase.auth.getUser();

    if (!user) {
      return NextResponse.json({ error: "未登录" }, { status: 401 });
    }

    // 2. 获取上传文件
    const formData = await request.formData();
    const file = formData.get("file") as File;

    if (!file) {
      return NextResponse.json({ error: "缺少文件" }, { status: 400 });
    }

    // 3. 执行批量导入
    const importer = new WechatFavoriteBatchImporter();
    const result = await importer.importFromFile(file, user.id);

    return NextResponse.json({
      success: true,
      data: result,
    });
  } catch (error: any) {
    console.error("批量导入失败", error);
    return NextResponse.json(
      { success: false, error: error.message },
      { status: 500 },
    );
  }
}
```

## 九、FAQ

**Q1: 为什么不能直接读取微信数据库？**
A: 微信数据库是加密的，需要获取密钥才能解密。出于安全考虑，我们让用户在本地使用工具解密，而不是要求用户提供密钥。

**Q2: 导入后的数据可以编辑吗？**
A: 可以。导入后的文章与手动收藏的文章完全相同，支持编辑标题、标签、评级等。

**Q3: 支持导入哪些类型的收藏？**
A: 阶段 1 主要支持公众号文章。图片、视频、文件等其他类型的收藏暂不支持。

**Q4: 导入的文章会占用 Free 版的配额吗？**
A: 是的。Free 版限制 500 篇收藏，Pro 版无限制。

**Q5: 导入失败怎么办？**
A: 我们会提供详细的失败原因和重试入口。常见失败原因包括：文章已删除、URL 无效、网络超时等。
