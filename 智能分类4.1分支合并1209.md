## 2. 分类系统版本对照

| 版本     | 服务类                              | 核心文件                                       | 描述                                                                      |
| -------- | ----------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------- |
| **V2**   | `ClassificationService`             | `services/classification.service.ts`           | 原版多匹配器聚合（无分层）                                                |
| **V3**   | `ClassificationService` + 5层匹配器 | `container.ts` → `getV3Matchers()`             | V2 增强版：k-NN直接锁定、指纹、标签、向量、通用分类                       |
| **V4**   | `TieredClassificationService`       | `v3/services/tiered-classification.service.ts` | 分层编排：Tier0 纠错缓存 → Tier1 快速匹配 → Tier2 AI确认 → Tier3 自动创建 |
| **V4.1** | `SimpleClassificationService`       | `services/simple-classification.service.ts`    | **统一向量搜索 + 标签增强 + AI选择题模式，解决冷启动**                    |

**当前生产环境**：

- `integration.ts` 的 `classifyBookmarkV2()` → `ClassificationContainer.getClassificationService()` → **V3**

**目标**：

- 使用 **V4.1** 替代 V3 作为默认分类服务
- 保留版本切换能力（环境变量）
- 标记旧代码为 Deprecated

---

## 3. V4.1 核心优势

| 特性       | V3                  | V4.1                           |
| ---------- | ------------------- | ------------------------------ |
| 冷启动支持 | ❌ 新文件夹无法匹配 | ✅ name_embedding 支持         |
| 向量搜索   | 多次查询            | 单次统一查询 (profile + name)  |
| 标签增强   | 基于匹配器权重      | +5%~+15% 直接加分              |
| 决策阈值   | 多层复杂判断        | 单阈值 70% 自动归类            |
| AI 调用    | 每次都调用          | 仅低置信度时调用（选择题模式） |
