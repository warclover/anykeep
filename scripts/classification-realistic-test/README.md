# 智能分类系统 - 真实用户模拟测试

## 快速开始

```bash
# 安装依赖（使用项目根目录的依赖）
cd ../..

# 运行完整测试
npm run test:classification:realistic

# 快速测试（少量数据）
npm run test:classification:realistic -- --quick

# 详细日志
npm run test:classification:realistic -- --verbose
```

## 测试报告

测试报告保存在 `reports/classification-realistic-test/` 目录下。
