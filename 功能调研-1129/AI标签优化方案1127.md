# AI标签优化方案 - 2025-11-27

## 📋 需求概述

### 用户痛点

1. **标签准确度不足**：AI 生成的标签过于笼统，不够精准
2. **无法预览和编辑**：创建收藏时看不到 AI 生成的标签，无法及时调整
3. **标签与文件夹关联弱**：标签没有很好地支持文件夹分类和归集

### 目标

1. 提高 AI 标签的准确度和实用性
2. 在创建收藏时显示 AI 标签，允许用户编辑
3. 基于标签优化文件夹推荐逻辑

---

## 🔍 当前实现分析

### 现状

- **标签生成时机**：后端创建收藏时自动生成（[src/app/api/bookmarks/route.ts:202-242](src/app/api/bookmarks/route.ts#L202-L242)）
- **标签输入方式**：前端只有一个文本框，用户手动输入（[src/components/bookmark/create-bookmark-dialog.tsx:544-560](src/components/bookmark/create-bookmark-dialog.tsx#L544-L560)）
- **标签质量**：Prompt 已优化，要求"领域+技术+场景"三层结构

### 问题

1. **用户体验差**：
   - 用户在创建时看不到 AI 标签
   - 需要保存后才能看到生成的标签
   - 如果标签不准确，需要编辑收藏才能修改

2. **标签准确度**：
   - 虽然 Prompt 已要求三层结构，但缺少具体示例
   - 没有针对不同内容类型（文章/教程/视频）定制
   - 缺少对现有文件夹名称的参考

3. **文件夹关联弱**：
   - 文件夹推荐基于标签，但标签不够精准
   - 没有利用用户已有标签历史

### **方案1：提高标签准确度** ⭐ (立即可行)

#### 1.1 优化标签生成 Prompt

在 `ai-generator.ts` 的 `buildPrompt` 函数中，针对标签部分进行优化：

```typescript
function buildPrompt(
  title: string,
  description?: string,
  content?: string,
  existingFolderNames?: string[], // 新增：参考用户现有文件夹

  // 构建文件夹参考信息

  if (existingFolderNames && existingFolderNames.length > 0) {
```

#### 1.2 内容类型识别 + 定制化标签

```typescript
/**
 * 识别内容类型

function detectContentType(title: string, description?: string):
  'article' | 'tutorial' | 'video' | 'tool' | 'course' {
  const text = `${title} ${description || ''}`.toLowerCase();

  // 教程类
  if (
    text.includes('教程') ||
    text.includes('如何') ||
    text.includes('实战') ||
    text.includes('入门') ||
    text.includes('step by step')
  ) {
    return 'tutorial';
  }

  // 视频类
  if (
    title.includes('视频') ||
    text.includes('bilibili') ||
    text.includes('youtube') ||
    text.includes('【') // 视频标题常用括号
  ) {
    return 'video';
  }

  // 工具类
  if (
    text.includes('工具') ||
    text.includes('插件') ||
    text.includes('软件') ||
    text.includes('app')
  ) {
    return 'tool';
  }

  // 课程类
  if (
    text.includes('课程') ||
    text.includes('训练营') ||
    text.includes('专栏')
  ) {
    return 'course';
  }

  return 'article';
}

/**
```

### **方案2：创建时显示和编辑 AI 标签** 🚀 (核心功能)

#### 2.1 实时生成 AI 标签（前端调用）

在 `create-bookmark-dialog.tsx` 中，当用户输入标题和描述后，实时调用 AI 生成标签：

```typescript
export function CreateBookmarkDialog({...}) {
  // 新增状态
  const [aiTags, setAiTags] = useState<string[]>([]);  // AI 生成的标签
  const [isGeneratingTags, setIsGeneratingTags] = useState(false);
  const [selectedTags, setSelectedTags] = useState<Set<string>>(new Set());  // 用户选中的标签

  /**
   * 实时生成 AI 标签
   * 当标题和描述都填写后，自动触发
   */
  const generateAITags = useCallback(async () => {
    if (!title || title.length < 3) {
      return;
    }

    setIsGeneratingTags(true);

    try {
      const response = await fetch('/api/bookmarks/generate-tags', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          title,
          description,
        }),
      });

      if (!response.ok) {
        throw new Error('生成标签失败');
      }

      const data = await response.json();
      const generatedTags = data.data.tags;

      setAiTags(generatedTags);

      // 默认选中所有 AI 标签
      setSelectedTags(new Set(generatedTags));

      toast.success('AI 已生成标签建议');
    } catch (error) {
      console.error('Generate tags error:', error);
      // 静默失败，不干扰用户体验
    } finally {
      setIsGeneratingTags(false);
    }
  }, [title, description]);

  /**
   * 当标题或描述变化时，延迟生成标签
   */
  useEffect(() => {
    const timer = setTimeout(() => {
      if (title && title.length >= 3) {
        generateAITags();
      }
    }, 1500);  // 用户停止输入1.5秒后触发

    return () => clearTimeout(timer);
  }, [title, description, generateAITags]);

  /**
   * 切换标签选中状态
   */
  const toggleTag = (tag: string) => {
    setSelectedTags(prev => {
      const next = new Set(prev);
      if (next.has(tag)) {
        next.delete(tag);
      } else {
        next.add(tag);
      }
      return next;
    });
  };

  /**
   * 添加自定义标签
   */
  const addCustomTag = (tag: string) => {
    const trimmed = tag.trim();
    if (trimmed && !aiTags.includes(trimmed)) {
      setAiTags(prev => [...prev, trimmed]);
      setSelectedTags(prev => new Set([...prev, trimmed]));
    }
  };

  // ... 其他代码
}
```

#### 2.3 创建后端 API 接口

新建 `src/app/api/bookmarks/generate-tags/route.ts`：

```typescript
/**
 * POST /api/bookmarks/generate-tags
 * 仅生成标签（不创建收藏）
 */
import { NextRequest } from "next/server";
import { createClient } from "@/lib/supabase/server";
import { generateAIContent } from "@/lib/utils/ai-generator";
import {
  successResponse,
  unauthorizedError,
  internalError,
} from "@/lib/utils/api-response";

export async function POST(request: NextRequest) {
  try {
    // 验证用户身份
    const supabase = await createClient();
    const {
      data: { user },
      error: authError,
    } = await supabase.auth.getUser();

    if (authError || !user) {
      return unauthorizedError();
    }

    // 解析请求体
    const body = await request.json();
    const { title, description } = body;

    if (!title || title.trim().length === 0) {
      return Response.json(
        { success: false, error: { message: "标题不能为空" } },
        { status: 400 },
      );
    }

    // 获取用户现有文件夹（用于标签参考）
    const { data: folders } = await supabase
      .from("folders")
      .select("name")
      .eq("user_id", user.id)
      .eq("is_system", false)
      .is("deleted_at", null);

    const folderNames = folders?.map((f) => f.name) || [];

    // 生成 AI 标签
    const result = await generateAIContent({
      title,
      description,
      existingFolderNames: folderNames, // 传递文件夹名称
    });

    return successResponse({ tags: result.tags });
  } catch (error) {
    console.error("Generate tags error:", error);
    return internalError("生成标签失败");
  }
}
```

### **方案3：基于标签优化文件夹推荐** 📁

#### 3.1 标签-文件夹匹配算法优化

在 `ai-generator.ts` 的 `generateFallbackFolderRecommendation` 函数中：

```typescript
function generateFallbackFolderRecommendation(
  title: string,
  tags: string[],
  existingFolders: ExistingFolder[],
): FolderRecommendation {
  if (existingFolders.length === 0) {
    const suggestedName = tags[0] || extractKeyword(title) || "我的收藏";
    return {
      folderId: null,
      folderName: suggestedName,
      confidence: 40,
      reason: "暂无文件夹，建议创建新文件夹",
      suggestNew: true,
    };
  }

  // 🚀 优化的匹配算法
  let bestMatch: ExistingFolder | null = null;
  let bestScore = 0;
  let matchReason = "";

  for (const folder of existingFolders) {
    const folderNameLower = folder.name.toLowerCase();
    let score = 0;
    const matchDetails: string[] = [];

    // 1. 标签完全匹配（最高权重）
    for (const tag of tags) {
      const tagLower = tag.toLowerCase();
      if (folderNameLower === tagLower) {
        score += 80;
        matchDetails.push(`标签"${tag}"完全匹配`);
      } else if (folderNameLower.includes(tagLower)) {
        score += 50;
        matchDetails.push(`标签"${tag}"部分匹配`);
      } else if (tagLower.includes(folderNameLower)) {
        score += 40;
        matchDetails.push(`文件夹名包含在标签"${tag}"中`);
      }
    }

    // 2. 标题关键词匹配（次要权重）
    const titleWords = title.toLowerCase().split(/\s+/);
    for (const word of titleWords) {
      if (word.length > 1 && folderNameLower.includes(word)) {
        score += 15;
      }
    }

    // 3. 语义相似度（基于关键词）
    const semanticKeywords = {
      前端: ["react", "vue", "javascript", "css", "html", "web"],
      后端: ["java", "python", "node", "api", "database", "server"],
      设计: ["figma", "ui", "ux", "用户体验", "交互"],
      产品: ["需求", "功能", "用户研究", "pm", "prd"],
      数据: ["分析", "sql", "pandas", "可视化", "bi"],
    };

    for (const [category, keywords] of Object.entries(semanticKeywords)) {
      if (folderNameLower.includes(category)) {
        for (const tag of tags) {
          if (keywords.some((kw) => tag.toLowerCase().includes(kw))) {
            score += 25;
            matchDetails.push(`语义关联：${tag} → ${category}`);
          }
        }
      }
    }

    if (score > bestScore) {
      bestScore = score;
      bestMatch = folder;
      matchReason = matchDetails.join("；");
    }
  }

  // 根据得分决定推荐策略
  if (bestMatch && bestScore >= 40) {
    return {
      folderId: bestMatch.id,
      folderName: bestMatch.name,
      confidence: Math.min(90, bestScore),
      reason: matchReason || "基于标签匹配",
      suggestNew: false,
    };
  }

  // 得分不足，建议新建文件夹
  const suggestedName = tags[0] || extractKeyword(title) || "未分类";
  return {
    folderId: null,
    folderName: suggestedName,
    confidence: 30,
    reason: "没有找到高度匹配的文件夹，建议新建",
    suggestNew: true,
  };
}
```
